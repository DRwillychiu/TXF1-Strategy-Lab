# S15 BBReversion — 策略描述

## 概述
- **完整名稱**：BBReversion
- **類別**：B 類 — 價格結構型
- **方向**：★雙向
- **週期**：60 分鐘
- **核心理念**：價格觸及布林帶極端位置時，搭配 RSI 超買超賣確認與 SMA60 趨勢過濾，進行均值回歸交易。目標為回歸至布林中軌，利用統計回歸特性獲利。

## 核心邏輯
策略基於均值回歸原理：價格偏離布林帶2倍標準差（上軌或下軌）為統計極端事件，搭配 RSI 雙重確認超買超賣狀態。關鍵創新在於加入 SMA60 趨勢過濾——做多時要求大趨勢向上（SMA60 上升），做空時要求大趨勢向下（SMA60 下降），確保回歸方向與大趨勢一致，提高勝率。停利目標為布林中軌而非固定 ATR 倍數。

## 進場條件
### 做多
1. 空手狀態（v_Prev_MP = 0）
2. 前根收盤 < 布林下軌（極端超賣）
3. RSI < 30（超賣確認）
4. SMA60 上升中（大趨勢向上）

### 做空
1. 空手狀態（v_Prev_MP = 0）
2. 前根收盤 > 布林上軌（極端超買）
3. RSI > 70（超買確認）
4. SMA60 下降中（大趨勢向下）

## 出場條件
1. **停損**：進場價 ± ATR × 1.5
2. **停利**：布林中軌（均值回歸目標）
3. **時間出場**：持倉超過 5 根 K 棒（300 分鐘）
4. **盤末出場**：13:40 強制平倉

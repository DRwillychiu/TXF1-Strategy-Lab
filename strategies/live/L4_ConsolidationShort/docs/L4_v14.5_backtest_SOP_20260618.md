# L4 v14.5 MC12 4 配置 A/B 測試 SOP

**用途**：用同一份 `L4_ConsolidationShort.pla` 跑 4 個 input 配置，獨立驗證 Filter A 與 Filter B 的效果
**預估時間**：總共 60-90 分鐘
**重要警告**：**MC12 input 持久化陷阱** — 第一次必須「完全移除舊版 + 重新從 .pla 載入」
**結果**：4 份 xlsx 匯出到 Downloads（建議命名見下）

## 一、4 配置總覽

| 順序 | 配置名 | Strong_Long_Filter_On | Fast_BreakExit_On | 目的 |
|------|--------|----------------------|-------------------|------|
| 1 | **v14.4 復刻** | **false** | **false** | baseline（應接近原 +239K）|
| 2 | **A 獨立**（Strong Long Block）| **true** | false | 算 A 獨立貢獻 |
| 3 | **B 獨立**（Fast BreakExit）| false | **true** | 算 B 獨立貢獻 |
| 4 | **v14.5 完整** | **true** | **true** | 預設配置（兩者疊加效果）|

### 增量分析公式

```
A 獨立貢獻  = 配置 2 PnL - 配置 1 PnL
B 獨立貢獻  = 配置 3 PnL - 配置 1 PnL
A+B 總和    = 配置 4 PnL - 配置 1 PnL

對照：
  若 A + B 加總 ≈ A+B 總和 → 兩者正交（互不影響）
  若 A + B 加總 > A+B 總和 → 兩者有重疊（部分 redundant）
  若 A + B 加總 < A+B 總和 → 兩者有互補（疊加效果更好）
```

## 五、常見問題

### Q1: 配置 1 的 PnL 不等於原 v14.4 的 +239K
**原因**：可能是 input 沒改對。檢查：
- Strong_Long_Filter_On 真的是 False?
- Fast_BreakExit_On 真的是 False?
- 其他 input 都用預設?

### Q2: A only 樣本反而變多
**原因**：Strong_Long_Filter_On 設反了。
**正解**：true = 過濾，false = 不過濾。

### Q3: B only 沒出現 CS_FastBreakExit 標籤
**原因**：
- a) `Fast_BreakExit_On` 設為 False
- b) 0.5 ATR Buffer 太大，沒觸發
- c) 確認 verify ResetStrategy 重新計算

### Q4: 4 個配置的 PnL 都類似
**意涵**：
- 可能改進無效
- 可能 input 沒生效（input persistence）
- 解決：完全移除策略 → 重新從 .pla 載入

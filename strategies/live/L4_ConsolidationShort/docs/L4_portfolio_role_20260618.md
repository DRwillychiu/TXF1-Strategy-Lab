# L4 Portfolio 戰略角色說明

**寫於**：2026-06-18
**目的**：從 portfolio 視角解釋 L4 為何即使年化僅 3.7% 仍有保留價值
**讀者對象**：用戶（未來檢視 portfolio 配置）+ 任何接手的 Claude
**前置文件**：[L4 v14.4 深度績效剖析](L4_v14.4_deep_analysis_20260618.md)

---

## 一、核心命題

**L4 不是「絕對報酬機」，是「Tail Risk Hedge（尾部風險對沖）」。**

評判 L4 不應該用單獨指標（如年化報酬、夏普），而應該用：
1. **它在 L1/L3/L5 套牢時做什麼**
2. **它在黑天鵝事件時做什麼**
3. **它對整體 portfolio MDD 的貢獻**

---

## 二、L4 在 6 隻策略 portfolio 中的位置

### 2.1 方向覆蓋矩陣

| 策略 | 方向 | 性質 | 主要 alpha 行情 |
|------|------|------|----------------|
| L1 TrendLong | 多 | 趨勢延續 | 上漲趨勢 |
| L2 TrendShort | 空 | 趨勢延續 | 下跌趨勢 |
| L3 ConsolidationLong | 多 | 區間多 | 盤整偏多 |
| **L4 ConsolidationShort** | **空** | **反轉做空** | **盤整破壞 + 假突破失敗** |
| L5 BreakoutLong | 多 | 突破多 | 區間突破上 |
| S1 NightMomentum | 多 | 夜盤 gap | 夜盤 + 隔夜 gap up |

**4 多 / 2 空 的不對稱結構**：
- 多單覆蓋：L1 + L3 + L5 + S1 = 4 隻
- 空單覆蓋：L2 + **L4** = 2 隻
- L4 是 portfolio 中**僅有的兩隻空頭策略之一**

### 2.2 為何需要保留 L4（即使年化 3.7%）

| 假設情境 | 沒有 L4 | 有 L4 |
|---------|--------|------|
| 多頭年（如 2024 H2）| L1/L3/L5/S1 大賺 | L4 小虧但其他壓倒性贏 |
| 平靜盤整（如 2024 H1）| 多單微利 | L4 抓盤整 CS_SP 100% WR 補貼 |
| **黑天鵝崩跌（2025-04）** | **多單全套牢** | **L4 抓 +273K 救援** |
| 慢熊（如 2022）| 多單套牢，空單應補 | L4 失靈（-51K）— 弱點 |

**結論**：L4 在 **3 種市況中有效**，在 **1 種市況失靈**。即使失靈年份也只虧 -51K，遠小於其在黑天鵝事件中的 +273K。

## 三、L4 與 L2 TrendShort 的互補性

L4 和 L2 都是空頭，但**抓的是不同類型的下跌**：

| 維度 | L4 ConsolidationShort | L2 TrendShort |
|------|---------------------|--------------|
| 入場時機 | 盤整破壞「假突破」反轉 | ATR 突破後跟單 |
| 持倉時間 | < 1 天 | 跨日波段 |
| 最佳市況 | 盤整末期 + 短期下跌 | 確認下跌趨勢 |
| 黑天鵝表現 | ⭐⭐⭐ 抓瞬間反轉 | ⭐⭐ 跟趨勢晚進場 |
| MDD | -12.87% | (未測，預估較大) |
| WR | 58% | 40.5% |
| PF | 1.41 | 2.88 |

### 互補性圖示

```
時間軸 →
┌──盤整──┬──盤整破壞──┬──趨勢確認──┬──趨勢延續──┬──趨勢結束──┐
                ↑              ↑                          
              L4 入場         L2 入場                     
            (反轉做空)      (跟單做空)                    
                
L4 抓「轉折瞬間」      L2 抓「持續下跌」
短打速戰             波段拉長
```

**兩者組合 = 完整覆蓋下跌行情的不同階段**。

## 四、L4 的「保險」價值量化

### 4.1 保險費 vs 賠付率

| 指標 | 數值 |
|------|------|
| 6 年累積保費（虧損的年）| -109,400（2021/2022/2024 虧損年合計）|
| 6 年累積賠付（賺錢的年）| +348,000（2020/2023/2025 賺錢年合計）|
| 淨保險賠付 | **+238,600** |
| 最大單筆賠付 | +273,000（2025-04-07 川普關稅）|

**含義**：L4 6 年付了 11 萬保費，拿回 35 萬賠付，淨賺 24 萬。
雖然年化僅 3.7%，但相當於**「免費的保險還倒貼」**。

### 4.2 對 portfolio MDD 的貢獻

假設 portfolio 6 隻策略各 1 口配置：

```
2025-04-07 川普關稅震撼日：
  L1 TrendLong   : 持有多單 → 全部套牢
  L3 Consol Long : 持有多單 → 套牢
  L5 Breakout    : 持有多單 → 套牢
  S1 Night       : 隔夜 gap down 收割
  L2 TrendShort  : 可能還沒進場（趨勢未確認）
  L4 v14.4       : ★ +273,000 NTD

→ 沒 L4：當日 portfolio 全套牢
→ 有 L4：273K 對沖掉約 60-80% 多單虧損
```

**這是 L4 真實價值的展現**。

## 五、L4 的弱點（誠實面對）

### 5.1 2022 熊市失靈

**事實**：6 年最大跌年，L4 反而虧 -51K。

**原因**：
- L4 設計是「假突破反轉」
- 熊市中假突破多，但**反彈後繼續跌的多**
- 「反彈鎖利」邏輯失效

**影響**：
- 在連續 6 個月以上的單邊下跌中，L4 是 portfolio 的拖累
- 此時應該靠 L2 TrendShort 補位

### 5.2 對單一事件依賴

**事實**：2025 +294K 中 +273K 來自單一事件。

**意涵**：
- 不能假設「L4 每年都有黑天鵝救」
- 平常年份 L4 年化可能只 -10K ~ +30K

### 5.3 CS_BreakExit 結構性虧損

**事實**：20 筆 0% WR -378K

**v14.5 已著手修正**（Filter A + Filter B 雙模組）。

## 六、L4 配置建議

### 6.1 倉位建議

| 資金規模 | L4 建議口數 | 理由 |
|---------|----------|------|
| 100 萬 | 0-1 口 | MDD -12.87%，最少 18 萬保證金 |
| 200 萬 | 1 口 | 安全配置 |
| 500 萬 | 1-2 口 | 可加倉，但邊際效應遞減 |
| 1000 萬+ | 2 口上限 | 樣本不夠支持更大倉位 |

**重點**：**L4 倉位不應該超過 L1 + L3 + L5 + S1 多單總倉位的 1/3**。
- 它是對沖性質，不是主力獲利策略
- 倉位過大反而降低整體報酬

### 6.2 何時應該停用 L4

| 情境 | 建議 |
|------|------|
| 確認進入連續 3 個月以上單邊下跌 | **臨時停用 L4**，靠 L2 跟單 |
| Daily MA 連續多周持平 + 低波動 | 保持 L4 |
| 進入歷史新高破壞期 | **加倍關注 L4**（黑天鵝高發期）|

### 6.3 L4 與其他策略的衝突管理

L4 與 L1/L3/L5/S1 同時持倉時：
- **方向衝突屬正常**（L4 空、其他多）
- 不需互相鎖定
- 但要注意「每隻策略 1 口 = portfolio 淨曝險可能突然轉換」

## 七、L4 vs Buy and Hold 對照

| 指標 | L4 6 年 | Buy and Hold |
|------|--------|-------------|
| 淨利 | +238,600 | +2,621,547 |
| 年化 | 3.71% | 27% |
| MDD | -12.87% | ~-28%（台股長期）|
| 持倉佔比 | < 10%（多數時段空手）| 100% |
| 黑天鵝對沖 | ✅ | ❌ |
| 心理壓力 | 低（持倉短）| 高（持續曝險）|

**結論**：
- 純看報酬，B&H 遠贏 L4
- 純看 MDD，L4 遠贏 B&H
- 純看心理，L4 遠贏 B&H
- **L4 不是要打敗 B&H，是要「補 B&H 的盲點」**

## 九、給用戶的 portfolio 配置建議

**結論**：**保留 L4，但要正確理解其角色**。

```
✅ 保留 L4 的條件：
  - 你接受「年化 3.7% + 黑天鵝保險」的定位
  - 你有 L1/L3/L5 多單需要對沖
  - 你的資金 ≥ 100 萬

❌ 砍掉 L4 的條件：
  - 你只想要絕對報酬
  - 你資金 < 100 萬無法承擔保證金
  - 你已有其他更強的對沖機制（選擇權 / 現金部位）
```

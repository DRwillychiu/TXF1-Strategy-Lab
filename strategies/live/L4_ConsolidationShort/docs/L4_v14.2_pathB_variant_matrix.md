## 一、L3 災難回顧與差異分析

### L3 變體 D 失敗原因
| 維度 | L3 變體 D | L4 v14.2 規劃 |
|------|----------|--------------|
| 策略類型 | 純區間（盤整箱底/中接球做多） | 盤整反轉（Wyckoff Spring 做空） |
| BE 門檻 | **+50 pts** | **+60 ~ +80 pts** |
| 正常箱內震盪 | 經常觸及 +50 pts 後回檔 | 較少觸及 +60 pts 後仍非真反轉 |
| BE 觸發後典型路徑 | 回到進場價（箱底支撐） | 若再上去就是真突破（CS_BreakExit） |
| 實證結果 | 100 筆 CL_BE 0% 勝率，截斷 96 筆到價獲利 | **見下方模擬** |

### 為何 L4 不會重蹈覆轍

**關鍵差異 — MFE 達 +60 pts 後的「真實」分布**：

| 出場類型 | 筆數 | 平均 MFE | 平均最終 PnL | 含義 |
|----------|------|----------|--------------|------|
| CS_SL（趨勢拉開） | 31 | +281 pts | **+198 pts** | 達 +60 後通常繼續走，最終大贏 |
| CS_TimeExit | 11 | +154 pts | **+59 pts** | 達 +60 後微幅獲利出場 |
| **CS_BreakExit** | **8** | **+108 pts** | **-108 pts** | **達 +60 後反向爆掉** |

**MFE ≥ +60 pts 的 50 筆交易中，只有 8/50 = 16% 是 CS_BreakExit。其餘 42 筆最終全是獲利或微幅獲利。**

對比 L3 變體 D：MFE 達 +50 pts 的 100+ 筆中，幾乎全是箱內震盪、最終會回測中線——所以 BE 截斷後全變零勝率。

**結論：L4 的 +60 pts MFE 是「真行情訊號」（84% 機率延續或微幅獲利），而 L3 的 +50 pts 是「箱內噪音」。閾值物理意義完全不同。**

## 四、v14.2 變體矩陣（建議 A/B 測試組合）

### Input 開關設計

```powerlanguage
inputs:
    { Path A — Night entry block }
    Night_Block_On(false),        { true = block 02:00-04:00 entries }

    { Path B — Breakeven (simple lock) }
    BE_Trigger_Pts(0),            { 0 = off. Suggested: 60, 80, 100 }
    BE_Offset_Pts(5),             { floor = Entry + Offset when BE armed }

    { Path B — StopProfit (peak watermark, L1-style) }
    SP_Trigger_Pts(0),            { 0 = off. Suggested: 60, 80, 100 }
```

## 六、出場標籤新增

| 標籤 | 觸發條件 | 優先級 |
|------|----------|--------|
| **CS_BE** | BE 已 armed 且 v_Stop_Level 被 BE floor 覆蓋而觸發 | 同 CS_SL（Stop） |
| **CS_SP** | SP armed 且 v_Stop_Level 被 SP floor 覆蓋而觸發 | 同 CS_SL（Stop） |
| **CS_NightBlock** | （不需要——直接拒收進場，無 entry signal） | — |

> CS_BE 和 CS_SP 都是「停損訊號被保護層往上覆蓋後觸發」的標籤。技術上仍是 BuyToCover Stop 單，只是 Stop 價是被 BE/SP 計算出來的。

## 七、A/B 測試方法論

### 測試流程
1. **A**（baseline）→ 確認與 v14.1 績效完全一致（無迴歸）
2. **B**（Night only）→ 驗證 Path A 預估 +120,800
3. **C** vs **D** → 確認 BE 與 SP 哪個機制更適合 L4
4. **F**（A+D）→ 預估最佳組合
5. **G**（A+SP保守）→ 風險最低備案

### 通過裁定的條件
- ✅ 淨利提升 ≥ 100,000
- ✅ MDD 不變或改善
- ✅ 勝率不顯著下降（≥ 40%）
- ✅ 新增的 CS_BE / CS_SP 標籤勝率 ≥ 50%（不能是 L3 那種 0% 災難）
- ✅ Top-10 贏家保留率 ≥ 80%（不能截斷大贏家）

### 否決的條件
- ❌ CS_BE 或 CS_SP 勝率 < 30%（L3 詛咒重演）
- ❌ Top-10 贏家保留率 < 70%（截斷太多）
- ❌ MDD 惡化 > 10%

## 進場邏輯

```
條件（全部滿足）：
① 45M 收盤穿越突破 MA61 + ATR(20) × 2.0（向上突破）
② 週線過濾：週線收盤 > 20MA 或 週線收盤 > 60MA（OR 邏輯）
③ 目前無持倉（MP = 0）
→ Buy next bar at Market
```

**設計思路：**
- MA61 = 約 60 小時均線，作為趨勢基準
- ATR × 2.0 = 需要突破夠大的距離才進場，過濾小幅波動
- 週線 OR 過濾 = 大方向必須偏多，但用 OR（而非 AND）讓趨勢早期就能進場
- Crosses Over = 只在穿越當根進場，不重複進場

## 出場邏輯

### 初始停損（P3 V2.5：雙層保護 + 進場凍結）
```
進場當根 K 棒收盤計算一次，之後整筆交易鎖死不動（v_SL_Locked）：

凍結停損 = Max(
    EntryPrice - 45M_ATR(20) × 1.5,   ← 45M ATR 停損
    EntryPrice - Daily_ATR(20) × 0.5   ← 日線 ATR 上限
)
取兩者較高值 → 較嚴格的停損
```
> **V2.5 修正（2026-06-12）**：舊版每根 K 棒用「當下 ATR」重算停損 →
> 持倉中 ATR 變動會讓初始停損漂移（用戶實盤 reload 親眼觀察到停損改變）。
> 初始停損是進場那一刻決定的生死線，不應隨行情變動。
> 修正模式比照 L2 的 SL_Locked / S1 的 v_EntryATR 凍結。

### 獲利回檔保護（P7 StopProfit，V2.6 — 移植自 L2 SECTION 12）
```
啟動：收盤價獲利 ≥ 250 點（stopProfitPoints_Long）
峰值：posbleProfit_Long = max(Close - 進場價)，只升不降
鎖定地板 = 進場價 + 峰值 × 45%（容忍回吐 55%）
一旦武裝，永不解除（獲利回落跌破 250 點，地板停在原位不撤）

Final_Exit = Max( MA55-50 追蹤, 凍結初始停損, SP 地板 )
→ 三個地板全部只升不降，有效停損單向上移
→ 武裝後地板必然高於進場價 → 跑出 250 點的單不可能再贏轉虧（保本內建）
```
> 與 L2 的差異僅架構：L2 用出場優先級鏈（獨立 Stop 單），L1 併入單一停損地板
> （Max 取最嚴者），效果相同。L2 的 TTP（1.5% 反彈出場）不移植——MA55 追蹤
> 已扮演該角色。
> 數據依據（469 筆 MFE 審計）：83 筆曾 +100 點仍虧損（-152 萬）；MFE≥250 點
> 回吐中位 50%、P90 112%；Top 10 終點回吐最大僅 28% → 55% 容忍不傷肥尾。
> 樂觀界改善 +193 萬；路徑級觸發成本須 MC9 A/B 定案。

### 追蹤停損（P4：MA55 追蹤）
```
追蹤停損 = MA55 - 50 點
Final_Exit = Max(追蹤停損, 初始停損)
```
- MA55 會隨趨勢上升 → 停損自動收緊
- TrailOffset = 50 點 = 給趨勢回調空間
- 初始停損是「地板」，追蹤停損不會低於它

### 假日前歸零鐵律（P5 v3，2026-06-12 重建）
```
規格（用戶裁示）：每個市場休市日之前，前夕夜盤收盤 05:00 前絕對平倉、維持 0 部位。

實作：
① Holiday_Tail[] = 最後交易日 + 1 曆日（= 前夕夜盤午夜後 K 棒的日期戳）
② Tail 當天（00:00-05:00 棒）：封鎖新進場
③ Time ≥ 03:45 強制市價出場 → 45 分 K 成交於 03:45，最遲 04:30 重試
   → 05:00 收盤前保證歸零
④ 部位可持有到前夕夜盤尾段（讓利潤奔跑到最後一刻），不提前犧牲行情
⑤ 颱風臨時停市無法預編碼 → Manual_Kill_Switch + 連假前人工檢查
⑥ Fail-safe 視界保護：Date > Registry_Valid_Until（目前 1270101）
   → 超出已驗證的假日登錄範圍 = 未來假日不可知
   → 自動封鎖進場 + 平掉持倉（TL_RegistryEnd）+ 圖表紅字警告（到期前 30 天）
   → 忘記維護的後果從「沉默留倉風險」變成「策略自動空手 + 滿屏警告」
```
> 舊版（前夕 13:30 平倉）的三個問題已修正：午夜尾段無保護、不擋進場、
> 2026 批次日期錯誤。歷史上四次抱倉跨假（含 2026-05-01 凌晨進場抱過勞動節）
> 在新版下不可能再發生。

5. **市場曝險僅 33%**：大部分時間不持倉，等待突破

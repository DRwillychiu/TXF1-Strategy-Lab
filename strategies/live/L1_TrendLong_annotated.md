## 進場邏輯

```
條件（全部滿足）：
① 60M 收盤穿越突破 MA61 + ATR(20) × 2.0（向上突破）
② 週線過濾：週線收盤 > 20MA 或 週線收盤 > 60MA（OR 邏輯）
③ 目前無持倉（MP = 0）
→ Buy next bar at Market
```

**設計思路：**
- MA61 = 約 60 小時均線，作為趨勢基準
- ATR × 2.0 = 需要突破夠大的距離才進場，過濾小幅波動
- 週線 OR 過濾 = 大方向必須偏多，但用 OR（而非 AND）讓趨勢早期就能進場
- Crosses Over = 只在穿越當根進場，不重複進場

## 出場邏輯

### 初始停損（P3：雙層保護）
```
停損 = Max(
    EntryPrice - ATR(20) × 1.5,      ← 60M ATR 停損
    EntryPrice - Daily_ATR(20) × 0.5  ← 日線 ATR 上限
)
取兩者較高值 → 較嚴格的停損
```

### 追蹤停損（P4：MA55 追蹤）
```
追蹤停損 = MA55 - 50 點
Final_Exit = Max(追蹤停損, 初始停損)
```
- MA55 會隨趨勢上升 → 停損自動收緊
- TrailOffset = 50 點 = 給趨勢回調空間
- 初始停損是「地板」，追蹤停損不會低於它

### 假日前歸零鐵律（P5 v3，2026-06-12 重建）
```
規格（用戶裁示）：每個市場休市日之前，前夕夜盤收盤 05:00 前絕對平倉、維持 0 部位。

實作：
① Holiday_Tail[] = 最後交易日 + 1 曆日（= 前夕夜盤午夜後 K 棒的日期戳）
② Tail 當天（00:00-05:00 棒）：封鎖新進場
③ Time ≥ 03:45 強制市價出場 → 45 分 K 成交於 03:45，最遲 04:30 重試
   → 05:00 收盤前保證歸零
④ 部位可持有到前夕夜盤尾段（讓利潤奔跑到最後一刻），不提前犧牲行情
⑤ 颱風臨時停市無法預編碼 → Manual_Kill_Switch + 連假前人工檢查
⑥ Fail-safe 視界保護：Date > Registry_Valid_Until（目前 1270101）
   → 超出已驗證的假日登錄範圍 = 未來假日不可知
   → 自動封鎖進場 + 平掉持倉（TL_RegistryEnd）+ 圖表紅字警告（到期前 30 天）
   → 忘記維護的後果從「沉默留倉風險」變成「策略自動空手 + 滿屏警告」
```
> 舊版（前夕 13:30 平倉）的三個問題已修正：午夜尾段無保護、不擋進場、
> 2026 批次日期錯誤。歷史上四次抱倉跨假（含 2026-05-01 凌晨進場抱過勞動節）
> 在新版下不可能再發生。

3. **假日風控模組**：硬編碼假日日期陣列，長假前自動平倉

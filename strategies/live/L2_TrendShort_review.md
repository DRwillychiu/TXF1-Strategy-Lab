- **63% 的進場死在初始停損**（52 筆，-834,800）——與 L1 同為趨勢策略的成本引擎

## 五、V5.2 假日模組規格（60 分 K 時序推導）

```
夜盤 60 分 K 尾段棒序（休市日凌晨）：00:00 → 01:00 → 02:00 → 03:00 → 04:00 → 05:00收盤

Holiday_Flat_Time = 0300：
  03:00 棒收盤觸發 → 下一棒開盤 03:00 成交（BuyToCover Market）
  未成 → 04:00 棒重試 → 04:00 成交
  → 05:00 收盤前保證 0 部位，留一次重試（同 L1 的 03:45/45分K 邏輯，按格線重推）

進場封鎖：尾段日（00:00-05:00）禁止 SellShort
出場優先級：插入 Priority 0（高於 TS_WeeklyExit）：
  0a TS_Kill（手動）→ 0b TS_RegistryEnd（視界 fail-safe）→ 0c TS_Holiday（尾段歸零）
日期登錄：與 L1 共用同一份 63 筆 Holiday_Tail（期交所官方驗證）
視界：Registry_Valid_Until = 1270101，超過即封鎖+平倉+圖表 30 天紅字
```

**部署優勢**：L2 自 2025 年底以來零交易（2026 全年休眠中）→ **大概率正空手，可立即部署**，不受 L1 的「等出場」限制。仍須在 MC9 確認無持倉後操作。

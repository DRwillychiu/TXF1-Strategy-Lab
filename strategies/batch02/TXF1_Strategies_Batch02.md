## 核心論述：指數位階論

台指期在 45000+ 的位階下，同樣 3% 的波動 = 1350 點 = 270,000 NTD。而在 10000 位階時僅 300 點 = 60,000 NTD。因此：

1. **固定點數停損已過時** — 必須使用 ATR-based 或 %Close 自適應停損
2. **極端行情將更頻繁** — 日均振幅從 88 點（10000 位階）擴大到 815 點（45000 位階）
3. **策略組合必須覆蓋崩跌/急彈** — Batch01 缺乏閃崩捕捉與逆勢抄底能力

## S6: FlashCrashMomentum — 閃崩動量做空

### 設計邏輯
針對 6/5 類型的急速崩跌行情。當價格加速度（N根K棒跌幅/ATR）突破門檻，且成交量爆發（當根量/20根均量 > 2x），做空捕捉崩跌延伸利潤。

### 賺什麼錢
捕捉指數急速崩跌時的動量延伸。高位階下同 % 崩跌 = 更大點數利潤，5M 級別可快速捕捉並離場。

### 參數設定
| 參數 | 預設值 | 說明 |
|------|--------|------|
| AccelBars | 5 | 加速度計算回溯 |
| AccelThresh | 3.0 | 加速度門檻(ATR倍數) |
| VolSpikeRatio | 2.0 | 量爆發倍率 |
| ATRLen | 14 | ATR週期 |
| StopATRMult | 2.0 | 停損ATR倍數 |
| TargetATRMult | 3.0 | 停利ATR倍數 |
| ExitBars | 10 | 最大持倉K棒 |

### MC12 設定
- **商品**: TXF1
- **週期**: 5分鐘
- **Data2**: 不需要
- **交易時段**: 日盤 08:45-13:30 + 夜盤 15:00-04:30

### 日線回測備註
日線觸發 179 次但 PF 0.73 虧損，因為日線無法捕捉「閃崩」的瞬時加速度特徵。5M 數據下預期交易次數減少但勝率提升。

## S7: BullPullbackLong — 多頭回檔做多

### 設計邏輯
多頭趨勢（日線收盤 > MA20）中，當 15M RSI(6) 跌破 15、連續 3 根下跌、且價格偏離 MA 超過 2.5 倍 ATR，判定為急跌過度回檔，做多抄底。

### 賺什麼錢
多頭趨勢中的急跌反彈利潤。高位階下回檔幅度更大（同 2% 回檔 = 900 點），ATR 自適應停損確保風險可控。

### 參數設定
| 參數 | 預設值 | 說明 |
|------|--------|------|
| RSILen | 6 | RSI週期 |
| RSIOversold | 15 | RSI超賣門檻 |
| ConsecDownBars | 3 | 連續下跌K棒數 |
| DevATRMult | 2.5 | 偏離ATR倍數 |
| ATRLen | 14 | ATR週期 |
| MA_Len | 20 | 趨勢均線 |
| StopATRMult | 2.0 | 停損 |
| TargetATRMult | 3.0 | 停利 |

### MC12 設定
- **商品**: TXF1
- **週期**: 15分鐘
- **Data2**: 日線（趨勢過濾）
- **注意**: Data2 引用使用 `[1]` 索引

### 日線回測備註
日線 0 筆交易。RSI(6)<15 + 3 根連跌 + 偏離>2.5ATR 同時成立在日線上極為罕見。15M 數據將大幅增加觸發頻率。

## S8: BearBounceSell — 空頭反彈放空

### 設計邏輯
S7 的鏡像。空頭趨勢（日線收盤 < MA20）中，當 15M RSI(6) 突破 85、連續 3 根上漲、偏離 MA 超過 2.5 倍 ATR，判定為反彈過度，放空。

### 賺什麼錢
空頭趨勢中的過度反彈利潤。反彈後再跌的慣性在空頭市場中高度可靠。

### 參數設定
| 參數 | 預設值 | 說明 |
|------|--------|------|
| RSILen | 6 | RSI週期 |
| RSIOverbought | 85 | RSI超買門檻 |
| ConsecUpBars | 3 | 連續上漲K棒數 |
| DevATRMult | 2.5 | 偏離ATR倍數 |
| ATRLen | 14 | ATR週期 |
| MA_Len | 20 | 趨勢均線 |
| StopATRMult | 2.0 | 停損 |
| TargetATRMult | 3.0 | 停利 |

### MC12 設定
- **商品**: TXF1
- **週期**: 15分鐘
- **Data2**: 日線（趨勢過濾）

### 日線回測備註
同 S7，日線 0 筆交易。需 15M 驗證。

## S9: VolExplosion — 波動率爆發順勢

### 設計邏輯
監控 ATR(14) / ATR(50) 比率，當短期波動率暴增至基線的 2.5 倍以上，代表市場從盤整進入爆發。根據近 3 根 K 棒動量方向決定做多/做空。

### 賺什麼錢
波動率壓縮→爆發的順勢延伸利潤。類似布林通道收縮後爆發，但使用 ATR 比率更穩健。

### 參數設定
| 參數 | 預設值 | 說明 |
|------|--------|------|
| ATRLen | 14 | 短期ATR |
| BaselineLen | 50 | 基線ATR |
| ATRRatio | 2.5 | 爆發倍率門檻 |
| MomBars | 3 | 動量回溯 |
| StopATRMult | 1.5 | 停損 |
| TargetATRMult | 2.5 | 停利 |
| ExitBars | 15 | 最大持倉 |

### MC12 設定
- **商品**: TXF1
- **週期**: 5分鐘
- **Data2**: 不需要

### 日線回測備註
日線 0 筆交易。ATR(14)/ATR(50) > 2.5 在日線上極罕見。5M 數據中短期 ATR 波動更劇烈，預期觸發頻率合理。

## S10: AdaptiveBreakout — 位階自適應突破

### 設計邏輯
經典 N 根 K 棒高低點突破，核心創新在停損機制：`MinList(ATR*mult, Close*pct%)`，取 ATR 停損與百分比停損的較小值，確保無論指數位階如何變化，停損都保持合理。

### 賺什麼錢
通道突破後的趨勢延伸利潤。ATR 自適應停損讓策略在 10000~50000 任何位階都能正確運作。

### 參數設定
| 參數 | 預設值 | 說明 |
|------|--------|------|
| BreakoutBars | 20 | 突破回溯N根 |
| ATRLen | 14 | ATR週期 |
| StopATRMult | 2.0 | 停損ATR倍數 |
| StopPctCap | 0.015 | 停損%上限(1.5%) |
| TargetATRMult | 3.0 | 停利ATR倍數 |
| MinVolRatio | 1.0 | 最低量倍率 |

### MC12 設定
- **商品**: TXF1
- **週期**: 30分鐘
- **Data2**: 不需要（可選加日線做趨勢確認）

### 日線回測結果 ✅

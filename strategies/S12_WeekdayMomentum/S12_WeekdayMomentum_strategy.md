# S12 WeekdayMomentum — 策略描述

## 概述
- **完整名稱**：WeekdayMomentum
- **類別**：E 類 — 統計型
- **方向**：★雙向
- **週期**：日線
- **核心理念**：利用週間動量慣性效應，當週一與週二連續出現同方向的漲跌幅超過門檻時，於週三進場延續該方向，捕捉週間趨勢延續的統計優勢。

## 核心邏輯
策略基於統計觀察：週一二連續同向動量（漲幅或跌幅 > 0.3%）往往在週三延續。透過 SMA20 趨勢過濾確認大方向一致，避免逆勢操作。日線級別操作，每週最多觸發一次交易。

## 進場條件
### 做多
1. 空手狀態（v_Prev_MP = 0）
2. 週三（DayOfWeek = 3）
3. 週一漲幅 > 0.3% + 週二漲幅 > 0.3%
4. 前根收盤 > SMA20

### 做空
1. 空手狀態（v_Prev_MP = 0）
2. 週三（DayOfWeek = 3）
3. 週一跌幅 > 0.3% + 週二跌幅 > 0.3%
4. 前根收盤 < SMA20

## 出場條件
1. **停損**：進場價 ± ATR × 1.5
2. **停利**：進場價 ± ATR × 2.0（R:R = 1.33:1）
3. **盤末出場**：13:25 強制平倉

## 風險備註
- 基線績效為負，需透過優化找到穩定參數區間
- 日線級別交易頻率低，每週最多一筆
- 連假週可能無法湊齊週一二三，需注意假期排程
- 統計型策略需注意過擬合風險

# S2 v0.5 部分驗證 — Long-only 確認有效但 TP 未改

**分析日**：2026-06-17
**用戶實際跑的版本**：**Naive + Long_Only_Mode（TargetMult 仍 1.5）**
**關鍵發現**：S2 vs Buy and Hold 落後 **56 倍**

## 一、用戶實際跑了什麼

### Inputs 設定（從 xlsx 設定 sheet）

| Input | 預期 v0.5 預設 | 實際跑值 | 一致? |
|-------|------------|-------|------|
| Long_Only_Mode | **True (1)** | **1** | ✅ 生效 |
| TargetMult | **1.0** | **1.5** | ❌ 沒改 |
| Compression_On | True | **False** | ❌ 沒改 |
| BB_Filter_On | True | **False** | ❌ 沒改 |
| ATR_Filter_On | True | **False** | ❌ 沒改 |
| Confirm_On | True | **False** | ❌ 沒改 |
| VolFilter_On | True | **False** | ❌ 沒改 |
| BE_On / Trail_On / SP_On | True | **False** | ❌ 沒改 |
| BreakOffset_Mode | 1 | **5** | ⚠️ (= 走 else, 同 0) |

**結論**：用戶 MC12 上的 inputs **仍是上次 Naive 跑的設定** + **新加的 Long_Only_Mode 自動帶預設 true**。

### 這證明 MC12 input persistence trap

```
v0.5 .pla 載入時:
  舊 inputs (來自之前 Naive 跑) → 全部保留
  新 input (Long_Only_Mode) → 用 .pla 預設值 True
  改過預設的 input (TargetMult 1.5→1.0) → 仍用舊值 1.5
```

→ **必須「完全移除策略」才能讓 .pla 預設值生效**。

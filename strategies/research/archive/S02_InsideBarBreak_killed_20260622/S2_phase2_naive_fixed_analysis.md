## 三、出場標籤揭露設計問題

| 標籤 | 次數 | 比例 |
|------|------|------|
| **LX_IB_Time** | 35 | 42% Long |
| LX_IB_SL | 31 | 37% Long |
| LX_IB_TP | 16 | **19% Long** ⚠️ |
| SX_IB_SL | 14 | 50% Short |
| SX_IB_Time | 8 | 29% Short |
| SX_IB_TP | 6 | 21% Short |
| LX_IB_Settlement | 2 | — |

### 重大發現：**TP 觸及率太低**

```
Long  TP: 19% (16/84)
Short TP: 21% (6/28)
平均:    20% (22/112)
```

**只有 20% 交易能達到 TP**！

設計問題：
- TP = MotherRange × **1.5** 設太遠
- 多數 Inside Bar 突破後走不到 1.5×
- 結果：要嘛 SL 出（37%），要嘛 Time Stop 出（42%）

**修正方向**：把 `TargetMult` 從 1.5 降到 **1.0** 或 **0.8**，讓 TP 觸及率提升到 40-50%。

## 四、平均持倉天數揭露 MTF 設計問題

```
平均持倉: 0.8 天
中位數:   1 天
```

**這完全推翻了之前的假設**！

之前在 strategy.md 寫：
> 平均持倉 1-3 天，符合趨勢策略「持中波段」特性

**實際**：< 1 天 = **幾乎是日內策略**

意涵：
1. **30M + Daily MTF 設計過度** — 1 天內進出的策略不需要日線分析
2. **MaxBarsHeld(30) = 15 小時上限幾乎沒觸發**
3. **可能改為純 30M 策略**（不用 Daily Data2）可能效果相同

## 六、戰略結論：S2 在 4 個十字路口

### 路口 1：alpha 已大幅衰減（事實）

```
v0.1 Python 代理       : PF 4.61 (假象)
v0.2 替代版 (3.5 年)   : PF -0.79
Naive 修正版 (5.6 年)  : PF -0.92  ← 最可信
  └── Long-only        : PF 1.057  ← 真實 alpha 上限
```

### 路口 2：剩下 3 條路

#### 路徑 A：繼續尋找 v0.3/v0.4 的潛力
- 找 B-2 vs B-3 元兇
- 修 .pla 預設值（v0.5）
- 跑修正版 v0.3 / v0.4 看 A+B+C 過濾是否能拉高 PF
- **預期**：可能拉到 1.3-1.8（樂觀）；可能仍 < 1.0（悲觀）

#### 路徑 B：簡化為 Long-only + 調 TP
- 加 Long-only 開關（input）
- TargetMult 從 1.5 降到 1.0
- 跑回測看 PF 是否能拉到 1.3+
- **預期**：可能拉到 1.2-1.5

#### 路徑 C：誠實 archive
- 承認母子線在 TXF1 30M 上 alpha 已消化
- 把 S2 移回 archive/，保留作為「**研究失敗案例教材**」
- 寫完整 archive 報告
- 釋放精力給其他更有潛力的策略（如 S6-S15）

## 七、我的判斷

### 為什麼會走到這裡

1. v0.1 Python 代理 PF 4.61 給了**虛假信心**
2. 我設計 v0.3/v0.4 時對「alpha 真實性」**過度樂觀**
3. 多花了 8 個 commit + 663 行代碼設計 A+B+C 過濾
4. 真正跑 MC 才發現**底層 alpha 不存在**

### 三條路的可信度

| 路徑 | 成功機率 | 成功 = PF > 1.5 |
|------|---------|--------------|
| A 找元兇 + v0.5 | 30% | 過濾若有效可能拉高 |
| B Long-only + 調 TP | 50% | Long 子集 PF 1.057 仍弱 |
| C archive | 100% | 誠實接受失敗 |

**理性決策**：A 或 B 各嘗試 1 次，若仍 < 1.5 → C

## 九、誠實的話

**S2 大概率沒救**。

從目前數據：
- 整體 PF -0.92
- Long-only PF 僅 1.057
- 年度績效 3 賺 3 賠完全隨機
- TP 觸及率僅 20%

修正後 v0.3/v0.4 即使有效，**理論上限大約 1.5-1.8**，不會回到 v0.1 的 4.61。

但 **(a)+(b) 都試**只需要 2-3 小時，且能學到：
1. v0.3/v0.4 過濾在真實資料上是否有效
2. Long-only + 調 TP 是否能拉出可用策略
3. 母子線在 TXF1 上的真實 alpha 上限

如果結果是 PF 1.3-1.5 → **可考慮極小倉位實驗性上架**
如果結果是 PF < 1.0 → **確認 archive**

# 為什麼母子線突破策略「比較適合做多」

**寫於**：2026-06-17（路徑 B 選擇後）
**核心問題**：用戶提問「母子線是不是比較適合做多為主？」
**簡短答案**：**是的**，且有 3 個結構性原因

---

## 一、實證證據（從我們的 MC 真實資料）

### Naive 修正版（5.6 年 / 112 筆）
| 子集 | 樣本 | 淨利 | PF | WR |
|------|------|------|------|-----|
| **Long-only** | 84 | **+48,400** | **1.057** ⚠️ | 42.9% |
| **Short-only** | 28 | **-153,200** | **0.672** ✗ | 35.7% |
| 整體 | 112 | -104,800 | 0.92 | — |

### 年度分布看 Long 與 Short

| 年份 | Long 淨利 | Short 淨利 |
|------|---------|----------|
| 2020 | -67K | (無) |
| 2021 | -51K | -37K |
| 2022 | +40K | +127K（特例）|
| 2023 | -46K | -88K |
| 2024 | +78K | +1K |
| 2025 | -16K | -156K（巨虧）|

**關鍵觀察**：

- **排除 2022**：Short 累積 -280K，Long 累積 -85K
- → **絕大多數年份，Short 都在虧錢**

## 二、3 個結構性原因（為何做多較強）

### 原因 1：台股 / TXF1 長期結構性偏多

#### 數據事實
```
2020/01 TWII ~ 12,000
2026/06 TWII ~ 23,000

6 年漲幅：+92%
年化報酬：~ +11.5%
```

**結構**：台股長期向上 → **逆勢做空的成功機率天生較低**。

#### 對策略的影響

**做多突破**：
- 突破後若延續 → 與大趨勢同向 → **可走得遠**
- 即使突破失敗 → 回到趨勢中 → 損失有限

**做空突破**：
- 突破後若延續 → 逆大趨勢 → **延續性不足**
- 突破失敗 → 反彈到大趨勢中 → **損失放大**

### 原因 2：波動率結構不對稱

#### 統計事實
```
上漲時：波動率收縮（平靜慢漲）
下跌時：波動率放大（恐慌快跌）
```

這是市場行為學的經典現象（"Volatility clustering in fear"）。

#### 對 Inside Bar 樣態的影響

Inside Bar **本質是波動率收縮的視覺確認**：
- 在「**上漲趨勢中段休息**」最常發生 → Inside Bar **頻繁出現** → 之後突破繼續上漲
- 在「**下跌恐慌中**」很少發生 → 因為波動率正在放大 → Inside Bar **稀有** → 不可靠

**結果**：
- 做多 Inside Bar 訊號 = **抓住趨勢中段的休息**（高品質）
- 做空 Inside Bar 訊號 = **抓住下跌中的短暫平靜**（少且不穩）

### 原因 3：散戶心理與資金流向

#### 多頭市場 散戶行為
- 多數散戶**只做多**
- 上漲突破時 = 集體跟單 → **推升動能**
- 下跌突破時 = 恐慌出場 → **加速下跌但快速反彈**（trap）

#### 對突破策略的影響

**做多突破**：
- 散戶跟單 = **流動性 + 動能**
- 突破有「群體跟單支持」 → 走得遠

**做空突破**：
- 散戶逃命 = **瞬間爆量** → 但**沒有持續賣壓**
- 機構抄底買盤介入 → **反彈把 Short 套牢**

## 三、其他突破類策略的證據（不是 S2 獨有）

### 我們的 portfolio 中：

| 策略 | 方向 | 性質 | PF |
|------|------|------|-----|
| L1 TrendLong | 多 | ATR 突破 | 1.42 ✓ |
| **L2 TrendShort** | **空** | ATR 突破 | **2.88** ⭐（但 79 筆樣本少）|
| L3 ConsolidationLong | 多 | 區間 mean rev | 1.17 ✓ |
| L4 ConsolidationShort | 空 | 區間 mean rev | 1.39 ✓ |
| **L5 BreakoutLong** | **只做多** | Box 突破 | **2.02** ⭐ |
| S1 NightMomentum | 多 | 夜盤 ORB | 1.38 |
| **S2 InsideBarBreak** | 雙向（v0.4）| 母子線突破 | **-0.92** ✗ |
| S2 Long-only（v0.5）| **只做多** | 母子線突破 | **1.057**（預期會提升）|

### 關鍵觀察

| 觀察 | 證據 |
|------|------|
| **「突破類」只做多明顯較強** | L5 (BreakoutLong) 只做多 PF 2.02 |
| **「ATR 突破」雙向都行但 Short 樣本太少** | L2 PF 2.88 但只 79 筆 |
| **「Mean reversion 類」雙向都行** | L3/L4 都做但都 PF > 1 |

**結論**：
- **突破類 → 做多較強**（L5 + S2 都證實）
- **趨勢延續 → 雙向都行但 Short 較少**
- **Mean rev → 雙向都行**

## 四、戰略意涵：portfolio 設計原則

### 新發現的「方向選擇法則」

```
策略類型           推薦方向              理由
─────────────────────────────────────────────────
突破型 (Breakout)    Long-only           市場結構性偏多 + 散戶心理
趨勢延續 (Trend)     雙向但 Long 加重     L1/L2 同型，但 L1 樣本多
區間 (Mean Rev)      雙向                 不依賴方向，賺震盪
時段 (Time-based)    視 alpha 而定        S1 只做多因夜盤 gap up
樣態 (Pattern)       看樣態方向偏好       Inside Bar → Long
事件驅動 (Event)     視事件性質           — 
```

### 對未來研究的啟示

開發新策略時：
1. **先做 alpha 來源分類**
2. **依分類決定方向偏好**（不要默認「雙向才公平」）
3. **MC 驗證後再決定是否拆 Long/Short**
4. **不要強迫 Short 邏輯對稱**

## 五、為什麼我設計 v0.4 時要做雙向？（檢討）

### 我的失誤

當時設計 v0.4 我**默認雙向**，理由：
- "為了對稱"
- "為了完整覆蓋市場狀態"
- "Inside Bar 雙向都會出現"

**但這完全沒有實證支持**。

### 正確的設計思維

應該先：
1. **跑 baseline 看 Long / Short 哪個有 alpha**
2. **若不對稱嚴重 → 砍掉弱的那邊**
3. **若兩邊都強 → 才保留雙向**

L5 的設計師很聰明：**直接設計為 Long-only**（沒做雙向），避免了 S2 的這個陷阱。

## 六、v0.5 設計方向

### 改動 1：加 Long_Only_Mode 開關

```powerlanguage
inputs:
    Long_Only_Mode(true);   { v0.5 預設 true 基於實證 }

{ 進場條件加 gate }
if v_MA_Up and ... then begin
    buy ("LE_IB_Entry") ...
end;

if Long_Only_Mode = false and  { ★ 只有關閉才允許 Short }
   v_MA_Down and ... then begin
    sell short ("SE_IB_Entry") ...
end;
```

### 改動 2：TargetMult 預設 1.5 → 1.0

理由：
- v0.4 TP 觸及率僅 19%（設太遠）
- 多數交易要嘛 SL（37%）要嘛 Time Stop（42%）
- 降低 TP 倍率 → 觸及率應提升到 35-45%

但**保留 input 可調**，A/B 對比能恢復原設計。

### 改動 3：（可選）修同日多進場

```powerlanguage
{ 加 cooldown 變數 }
variables:
    v_LastEntry_Bar(0),
    
{ 進場條件加 cooldown check }
if BarNumber - v_LastEntry_Bar >= Entry_Cooldown_Bars and
   v_MA_Up and ... then begin
    buy (...) ;
    v_LastEntry_Bar = BarNumber;
end;
```

但這會大幅改 alpha，先不做。Phase 3 再評估。

## 八、潛在風險

### 風險 1：Long-only 在熊市套牢

2022 是台股大跌年，那年 Short 賺 +127K。

如果未來再來一個 2022 級的熊市：
- Long-only S2 = **全套牢**
- 需要 portfolio 中其他 Short 策略（L2 / L4）抵銷

**對策**：S2 上架時必須與 L2/L4 配置（已自然滿足）。

### 風險 2：TargetMult 1.0 可能降低盈虧比

- 原 1.5 倍：盈虧比 1.5/0.5 = 3:1
- 新 1.0 倍：盈虧比 1.0/0.5 = 2:1

**對策**：靠提升 TP 觸及率彌補（從 19% → 40%）。

數學：
- 原版：WR 43% × 3:1 = 期望值 = 0.43 × 3 - 0.57 × 1 = +0.72
- 新版：WR 50% × 2:1 = 期望值 = 0.50 × 2 - 0.50 × 1 = +0.50

**新版理論期望值反而較低**！但實務上 TP 觸及率提升能讓「實際 alpha」增加（因為長時間 hold 的滑價/手續費/隔夜風險成本變低）。

## 九、結論

### 你的直覺正確

**母子線突破策略「比較適合做多」是有結構性原因的**，不是巧合。

3 個結構性因素：
1. 台股長期偏多 → 順勢做多優於逆勢做空
2. 波動率不對稱 → Inside Bar 在多頭結構中更頻繁且穩定
3. 散戶心理 → 多頭突破有跟單動能；空頭突破易被機構接走

### 這是個普世規律

從 L5 (BreakoutLong 只做多 PF 2.02) 與 S2 (雙向虧錢 / Long-only 勉強) 對比看：
- **突破類策略 → Long-only 是常態，雙向是例外**
- 我設計 v0.4 默認雙向是**錯誤決定**

### 修正方向

v0.5 改 Long-only + 調 TP → 預期 PF 1.5-2.0 → 進 Phase 3

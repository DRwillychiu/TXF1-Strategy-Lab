## 1. Design Objective

Replace V3.0 ATR-based primary SL with L1_c (10-day max close-to-close drawdown) × ratio, retaining Layer 0 as hard cap. Kill Layer 1b (variant #35 risk + framework constraint). Preserve Layer 2 (P7 T200) and Layer 3 (P4 MA55) unchanged.

**Core problem being solved**: at 40-48K index, V3.0 ATR × 1.5 produces 500-1000 pts SL (0.78% of price), unsustainable in choppy/declining markets. L1_c decouples from ATR (r=0.542) and reacts to actual close-to-close drawdown rather than volatility regime.

**Anti-goal (what this is NOT)**: not a "smarter" tightening layer, not a regime classifier, not a dynamic SL modification post-entry. All those routes are sealed or backlog.

## 2. Architecture — 4 Layers

```
Layer 0: ATR Wall           ← hard cap (unchanged from V3.0)
Layer 1: L1_c Primary SL    ← NEW in V3.1 (replaces ATR-based)
Layer 2: P7 Profit Lock     ← T200 (unchanged)
Layer 3: P4 MA55 Trail      ← TrailOffset=50 (unchanged)

Vacuum zone (0 to +199 pts): accepted as trend-strategy cost per user 2026-07-24 ruling
Layer 1b (was here in original architecture): KILLED — see L1_Layer1b_kill_summary_20260724.md
```

### Distance selection semantics (critical — one source of bugs)

Final SL distance is `MinList` of Layer 0 and Layer 1 distances (in **distance** space, not price space):

```
v_Layer0_dist = MinList(Current_ATR * 1.5, Daily_ATR * 0.5)   { Layer 0 hard cap }
v_Layer1_dist = MaxList(v_L1c * L1c_Ratio, Floor_Points)      { Layer 1 with floor }
v_Frozen_SL_dist = MinList(v_Layer1_dist, v_Layer0_dist)      { tighter of the two }
v_Frozen_SL_price = EntryPrice - v_Frozen_SL_dist              { convert to price }
```

**Warning per Appendix C陷阱 "雙腿選擇函數"**: MaxList in **price** space and MinList in **distance** space both select the tighter stop. This spec uses distance space throughout to reduce cross-strategy semantic confusion.

## 3. Layer 1 (L1_c) Detailed Design

### 3.1 Formula

```
L1_c[t] = max(Close[i] of Data2 - Close[j] of Data2)
         for i in [2..10], j in [1..i-1]
```

Semantics: over the last 10 completed Daily bars (excluding current, which uses `[1]` per Rule #3), find the maximum peak-to-trough drawdown measured Close-to-Close.

### 3.2 PowerLanguage Skeleton (O(10) rolling max, target for actual .pla)

```
{ ============================================================ }
{ L1_c Rolling 10-day Max Close-to-Close Drawdown (from Data2)  }
{ ============================================================ }

variables:
    v_L1c_raw(0),              { computed L1_c value }
    v_L1c_ready(false),        { flag: enough Data2 bars to compute }
    v_L1c_running_max(0),      { helper for rolling max }
    v_L1c_drop(0),             { helper for current drawdown }
    v_L1c_i(0);                { loop counter }

if CurrentBar of Data2 >= 11 then begin
    v_L1c_raw = 0;
    v_L1c_running_max = -999999;
    for v_L1c_i = 10 downto 1 begin   { walk from oldest to newest }
        if Close[v_L1c_i] of Data2 > v_L1c_running_max then
            v_L1c_running_max = Close[v_L1c_i] of Data2;
        v_L1c_drop = v_L1c_running_max - Close[v_L1c_i] of Data2;
        if v_L1c_drop > v_L1c_raw then
            v_L1c_raw = v_L1c_drop;
    end;
    v_L1c_ready = true;
end
else begin
    v_L1c_raw = 0;
    v_L1c_ready = false;
end;
```

### 3.3 Freeze Mechanism

L1_c is computed at every Data1 bar close (BarStatus(1)=2), but `v_Frozen_SL_dist` is locked at entry bar:

```
variables:
    v_Frozen_SL_dist(0),           { IntraBarPersist }
    v_Frozen_SL_dist_locked(false); { IntraBarPersist }

if MP = 0 then begin
    v_Frozen_SL_dist_locked = false;   { reset when flat }
    v_Frozen_SL_dist = 0;
end;

if MP > 0 and v_Frozen_SL_dist_locked = false then begin
    { First bar in position — freeze SL distance }
    if v_L1c_ready and v_L1c_raw > 0 then
        v_Layer1_dist = MaxList(v_L1c_raw * L1c_Ratio, Floor_Points)
    else
        v_Layer1_dist = Current_ATR * SL_Multiplier;   { Bug-1 fix: cold-start OR L1_c=0 (10-day all-up regime) }
    v_Layer0_dist = MinList(Current_ATR * SL_Multiplier, Daily_ATR * Daily_Cap_Multiplier);
    v_Frozen_SL_dist = MinList(v_Layer1_dist, v_Layer0_dist);
    v_Frozen_SL_dist_locked = true;
end;
```

### 3.4 Cold-start Handling

**Trigger**: `CurrentBar of Data2 < 11` at time of entry — L1_c not computable.

**Fallback**: `v_Layer1_dist = Current_ATR * SL_Multiplier` (V3.0 formula, preserving legacy behavior).

**Expected duration**: MC12's MaxBarsBack of the strategy already forces bar-alignment; Data2 typically has 11+ bars from the first bar the strategy fires. Cold-start fallback is a safety net, not primary path.

**Verification**: user checks first-10-days trade log after Optimizer run. If any entries in first 15 days used ATR fallback, verify SL distance matches V3.0 behavior for those bars (regression test).

### 3.5 Floor Application

`v_Layer1_dist = MaxList(v_L1c_raw * L1c_Ratio, Floor_Points)`

- Floor is a **distance-space** minimum, applied before Layer 0 cap.
- If `Floor_Points = 0`, MaxList degenerates to `v_L1c_raw * L1c_Ratio` (no-op).
- Setting `Floor_Points = 0` in Optimizer effectively tests "no Floor" path.

### Filter #5 D-Plus algorithm (Q-USER-18 ruling)

For each year Y in {2020, 2021, 2022, 2023, 2024, 2025, 2026 partial}:

```
v30_pf_Y = Ratio=999 sanity case per-year PF for year Y   [dynamic, post-Optimizer]

IF v30_pf_Y >= 1.0:
    threshold_Y = max(v30_pf_Y * 0.90, 1.0)                { normal profitable year: keep 1.0 floor }
ELSE (V3.0 losing year -- internal defect not SL-fixable):
    threshold_Y = v30_pf_Y * 1.05                           { relative improvement only, no absolute profit mandate }

Filter #5 passes for year Y if V3.1 PF_Y >= threshold_Y.
Combo fails Filter #5 if ANY year fails.
```

Rationale: V3.0 losing years (e.g., 2023 with Win Rate 26.09%, PF 0.98) reflect entry-signal defects not addressable by SL redesign. Requiring V3.1 to be profitable in these years imposes a scope V3.1 cannot deliver. Relative improvement (x 1.05) is the meaningful and achievable metric for those years.

Sensitivity note: if sweep produces zero combo passing D-Plus, fallback options are (A) relax to x 0.90 uniform, (B) accept "no winner" and re-design.

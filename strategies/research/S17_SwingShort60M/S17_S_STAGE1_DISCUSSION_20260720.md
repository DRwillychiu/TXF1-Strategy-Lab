## Topic 1：進場觸發哲學（2026-07-20 初步共識）

### 三個方向評估

| 方向 | 內容 | 評估 |
|------|------|------|
| A — 均線結構（趨勢追蹤）| 60M ZLEMA 死叉 + 斜率 | ❌ 排除：跟 S16_S 同家族，預期月損益 corr > 0.7 |
| B — K 棒量價型態（Price Action）| 反彈失敗結構 / 吞噬 / 長上影 | ✅ 用戶偏好 |
| C — 日線收盤序列（統計派）| 收盤 < MA(X)、連 N 日下跌 | ✅ 用戶偏好 |

### 共識方向：B+C 雙層架構

```
Layer 1 (C): 日線環境 filter — 「現在是跌勢環境嗎？」
  - 例：收盤 < MA(20) 且 MA(20) 下彎
  - MC12 實作：Data2 = Daily

Layer 2 (B): 60M K 棒觸發 — 「反彈剛失敗嗎？」
  - 例：反彈 K 棒出現後，下一根反轉吞噬
  - MC12 實作：Data1 = 60M
```

### 為什麼 B+C 是最佳組合

1. C 解決 B 的弱點：日線 filter 排除多頭主升段的假反彈失敗
2. B 解決 C 的弱點：K 棒型態給精確進場時機（日線太粗）
3. 雙層各自簡單（各 1-2 條件）= 抗過擬合
4. 跟 S16_S 天然低相關（不同維度）

### K 棒型態適用性原則（新發現）

**K 棒型態可靠度跟時間週期正相關**：
- 5M：雜訊大，型態不可靠 → S16_S 正確選用純數學（ZLEMA 斜率）
- 60M：一根 K 棒 = 一小時多空交戰，有機構意義 → S17_S 適合用型態
- 日線：最穩健 → C 層用日線級統計

**未來開發鐵則**：越長操作週期的策略，越適合用 K 棒型態判定。短週期策略（5M 以下）應用純數學指標。

### 量的處理（暫緩決定）

- 用戶傾向加入量價關係
- 建議 Phase 1 先用純價格型態驗證 alpha，Phase 2 再加量
- TXF1 期貨量的三個陷阱：換月跳量 / 夜盤稀薄 / 到期日異常
- 若用量，需正規化（相對前 N 根比例）+ 夜盤特殊處理
- **待用戶最終裁定**

### S17_S 的 alpha 本質

- 不是「預測下跌的開始」，是「判定下跌的延續」
- Alpha 來源 = 「大多數反彈是假的」這個統計事實
- 下跌趨勢中 10 次反彈有 ~7 次是陷阱 → 賺 7 次、賠 3 次保險費

## 已識別的隱性風險（Topics 2-6 討論時需正面解決）

### 隱性 1 — 跨夜缺口風險（最大威脅）
持倉數天 → 每個夜盤→日盤轉折都是缺口風險點。停損設在反彈高點上方（近），跳空 200 點直接打穿。
→ 需要日線級停損 + 缺口保護（全新工程）

### 隱性 2 — 假日鐵律 vs Swing 持倉的根本衝突
鐵律要求休市前必平倉。Swing 持倉數天 → 頻繁被迫中途砍倉。
→ Topic 3 必須正面解決，可能需要為 swing 策略設計不同版本的合規

### 隱性 3 — V 型反轉致命場景
看起來像反彈失敗，其實是 V 轉底部 → 進場做空被反向軋。
→ B+C 雙層可降低但無法消除

### 隱性 4 — 趨勢結束辨識
何時從「暫時反彈繼續抱」切換到「趨勢反轉要跑」？
→ Topic 4 核心

### 隱性 5 — 期貨量的品質陷阱
換月 / 夜盤 / 到期日三重干擾
→ 量暫緩至 Phase 2

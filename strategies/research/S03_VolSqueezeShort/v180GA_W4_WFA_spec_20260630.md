### Chart configuration
- Strategy: `S3_VolSqueezeShort_v180_EXPERIMENTAL.pla`
- Data1: TXF1 60M
- Data2: TXF1 Daily
- Data3: TXF1 1M
- IntrabarOrderGeneration = TRUE
- Max bars study will reference = 1000
- Initial Capital = 1,000,000 NTD
- Slippage = 1,000 NTD round-trip
- Trade Size = 1 contract

### Optimization settings per window
- Algorithm: Exhaustive
- Fitness: Net Profit (primary), record Sharpe/Sortino/PF
- Optimize: 10 ML params with ranges from Section 2
- Total combinations per window: 11 x 13 x 5 x 9 x 6 x 9 x 10 x 9 x 10 x 13 = too large

### Practical approach: 2-round GA per window

Since exhaustive on 10 params is infeasible (~450M combinations), use GA per window:

**Round 1 (4 core params)**: ML_ScoreTrigger x ML_SpeedThreshPts x ML_VolSpikeMult x ML_MinCategories
- 13 x 10 x 9 x 5 = 5,850 combinations (exhaustive feasible, ~30-45 min per window)
- Lock other 6 ML params at GA-best values

**Round 2 (6 secondary params)**: Apply R1 best, optimize remaining 6
- ML_ActivationPct x ML_VolAvgLen x ML_SpeedBars x ML_ATR_Short_Len x ML_ATR_Long_Len x ML_ATR_Ratio
- 11 x 6 x 9 x 9 x 10 x 13 = 694,980 (use GA algorithm: 256 pop x 30 gen)

### Simplified approach (recommended for 18-file output)

**Per window, one optimization run** using GA algorithm on all 10 params:
- Population: 256
- Generations: 30
- Fitness: Net Profit
- This produces 1 IS optimization report per window

Then apply IS-best to OOS period and run verification:
- This produces 1 OOS verification report per window

**Total: 9 IS + 9 OOS = 18 files**

## 6. Pass/Fail Criteria

### Per-window criteria
| Metric | Pass | Fail |
|--------|------|------|
| OOS Net Profit | > 0 | <= 0 |
| OOS PF | > 1.0 | <= 1.0 |
| IS-best params | Plateau (not spike) | Edge spike |

### Overall WFA criteria
| Metric | Pass | Marginal | Fail |
|--------|------|----------|------|
| OOS windows with Net > 0 | >= 6/9 (67%) | 5/9 (56%) | <= 4/9 |
| WFE (avg OOS/IS ratio) | > 50% | 30-50% | < 30% |
| OOS PF median | > 1.0 | 0.8-1.0 | < 0.8 |
| Param stability across windows | Low variance | Some drift | Wild swings |

### WFE calculation
```
WFE = (Median OOS Net per 6M) / (Median IS Net per 6M) x 100%

Example:
  IS avg Net per 6M = +200K (across 24M)
  OOS Net per 6M = +80K
  WFE = 80/200 = 40% (MARGINAL)
```

## 7. MC12 Execution SOP (per window)

### Step 1: IS Optimization
1. Set chart date range to IS period (e.g. W1: 2020-01-01 to 2021-12-31)
2. Open Strategy Properties > Optimization
3. Set 10 ML params with ranges from Section 2
4. Algorithm: GA (256 pop x 30 gen) or Exhaustive if using 4-param subset
5. Fitness: Net Profit
6. Run optimization
7. Export top result to xlsx: `v180GA_WFA_W1_IS_2020Q1-2021Q4_optimization.xlsx`
8. Record IS-best params

### Step 2: OOS Verification
1. Apply IS-best params to strategy inputs
2. Set chart date range to OOS period (e.g. W1: 2022-01-01 to 2022-06-30)
3. Run backtest (single run, no optimization)
4. Export report to xlsx: `v180GA_WFA_W1_OOS_2022Q1-Q2_verify.xlsx`
5. Record OOS Net, PF, trades, MDD

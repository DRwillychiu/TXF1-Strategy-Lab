## 一、Root Cause（v1.9.1 6/4 case 的架構死結）

### v1.9.1 Section 11 Exit Chain Priority
```
P0-1 ~ P0-4  Safety gates
Layer 2 SP tracking (只更新 state，不 fire！)
S-0 SX_VS_1M_Exit    ← 觸發 ExitFired = 1
S-1 TP limit
S-2 Mid
S-3 TimeStop
S-4 SP/SL Stop       ← 被 ExitFired 阻擋
```

### 6/4 case 死結
1. 進場後 Peak Profit 累積 305 pts
2. SP armed（threshold ~60-90 pts，遠低於 305）
3. SP Floor Price @ EntryPrice - 213.5 pts（70% retain）
4. 反彈 1M K 觸發 factor scoring → v_1M_Trigger = True
5. **S-0 1M_Exit fire market** → ExitFired = 1
6. **S-4 SP Stop 永遠不 place**
7. Next 1M K Open fill @ -181 pts

→ Peak +305 → Exit -181 = **失去 486 pts of alpha**

## 二、v1.9.2 Solution（兩層改動）

### Solution A：P0.5 SP Armed Priority Fire

新 Exit Chain Priority：
```
P0-1 ~ P0-4  Safety gates
Layer 2 SP tracking (peak/arm/floor with tiered retain)
P0.5 NEW     SP Armed Priority Fire ← ⭐ NEW
S-0          1M_Exit (only if P0.5 not fired)
S-1 ~ S-4    原邏輯
```

Code:
```pla
{ ---- P0.5 NEW v1.9.2: SP Armed Priority Fire ---- }
if ( ExitFired = 0 ) and
   ( v_SP_Armed = True ) and
   ( Close >= v_SP_Floor_Price ) then begin
    buy to cover ( "SX_VS_SP_Armed" ) next bar at Market;
    ExitFired = 1;
end;
```

### Solution B：Tiered SP_Retain based on Peak

Peak 越大 → Retain 越緊（越靠近 peak）：

| Peak Profit | Retain % | Floor 距 Peak |
|-------------|----------|---------------|
| < 100 pts | 70%（原）| Peak × 30% |
| 100-200 pts | **80%** ⭐ | Peak × 20% |
| 200-300 pts | **85%** ⭐ | Peak × 15% |
| ≥ 300 pts | **90%** ⭐ | Peak × 10% |

Code:
```pla
if v_Peak_Profit_Pts >= 300 then
    v_SP_Retain_Dynamic = SP_Retain_Tier3_Pct   { 90 }
else if v_Peak_Profit_Pts >= 200 then
    v_SP_Retain_Dynamic = SP_Retain_Tier2_Pct   { 85 }
else if v_Peak_Profit_Pts >= 100 then
    v_SP_Retain_Dynamic = SP_Retain_Tier1_Pct   { 80 }
else
    v_SP_Retain_Dynamic = SP_Retain_Pct;         { 70 }

if v_SP_Armed = True then
    v_SP_Floor_Price = EntryPrice - ( v_Peak_Profit_Pts * v_SP_Retain_Dynamic / 100 );
```

## 五、Trade-off 分析

### Pros
1. **6/4 級 case 從虧損翻為獲利**（-36K → +52K）
2. **SP priority > 1M_Exit** 解決架構死結
3. **Tiered retain 讓大 case 賺更多**
4. **S-4 backup 保留** 若 P0.5 miss 時 catch
5. **改動範圍小**（3 inputs + 1 var + 1 block + retain 邏輯改）

### Cons
1. **Market order 有 slippage**（vs Stop order）— 但可控（1M K open）
2. **可能 fire 太早**（e.g. Peak 105 pts，Floor 84，若反彈到 84 就 fire）→ 錯過再創新低機會
3. **需 refit ML_ params**（v1.9.1 GA 的 sweet spot 可能不同）
4. **6 個 tier boundaries 需驗證**（100/200/300 pts 是否合適 TXF1）

### 未 optimize 部分
- **Tiered thresholds（100/200/300 pts）hardcoded** — 未來可 GA
- **P0.5 fire timing**（用 Close vs High）
- **v_SP_Retain_Dynamic 只寫入 short 端** — 未來 hedge 需寫 long variant

# S2 E 系列論證：Alpha 殘餘性、PF 真實性、樣本信心評估

**寫於**：2026-06-17
**目的**：解決 [`S2_known_issues.md`](S2_known_issues.md) E-1 / E-2 / E-3
**性質**：理論論證 + 量化評估 + 後續驗證路徑
**結論**：S2 v0.4 **理論上仍有殘餘 alpha 值得驗證**，但需 MC 真實回測證實

## 一、E-1: Alpha 衰減風險評估

### 1.1 公認的「Alpha 衰減定律」

| 學術定律 | 含義 |
|---------|------|
| **Stein's Law** | "If something cannot go on forever, it will stop." |
| **Lo's Adaptive Markets Hypothesis** | Alpha 在市場參與者集體學習後消化 |
| **Lopez de Prado** | 「公開的策略 = 死掉的策略」 |

**母子線突破策略已經公開** → 理論上 alpha **應該已被消化**。

### 1.2 但「消化」不等於「歸零」

**反論點**：alpha 衰減是漸進的，不是 binary。
- 即使被廣泛交易，仍可能保留 **部分** edge
- 「**執行細節差異**」可以維持殘餘 alpha
- 「**時間框架選擇**」可以避開主流交易區

### 1.3 為什麼 S2 在 TXF1 30M 上可能還有殘餘 alpha

#### 證據 1：原始 Inside Bar 的「公開度」其實有限

| 流行領域 | 母子線使用程度 |
|---------|------------|
| 西方外匯 / 商品（日線）| 🔴 高度公開 |
| 美股 ETF（日線）| 🟡 中等公開 |
| **台股 TXF1 期貨（30M + Daily）** | 🟢 **低度公開** |

台灣量化圈主流策略：
- 日內當沖（5M / 15M）
- 夜盤策略（時段型）
- 趨勢跟單（ATR / MA）
- 程式選股（個股，非期貨）

**「日線母子線 + 30M 進場」在 TXF1 並不流行** → alpha 衰減程度較低。

#### 證據 2：嚴格過濾 = 訊號稀有性 = alpha 保護

v0.4 完整過濾鏈：

```
14 個 AND 條件全部通過才進場：
  1. v_IsInsideBar
  2. MotherRange >= MinMotherRange
  3. MotherRange <= MaxMotherRange
  4. v_Compression_Pass (A-1: Inside/Mother ratio)
  5. v_BB_Pass (A-2: BB Width contraction)
  6. v_ATR_Pass (A-3: ATR Short/Long contraction)
  7. v_MA_Up (or v_MA_Down for Short)
  8. v_Holiday_Block = false
  9. v_Settlement_Day = false
  10. v_Registry_Expired = false
  11. v_VolPass (B-3: Volume surge)
  12. Close > MotherHigh + v_DynBreakOffset (B-1: dynamic offset)
  13. ConfirmBars 站穩確認 (B-2)
  14. (內隱) Time 在交易時段內
```

**理論預期年化進場 = 2-4 筆**（從基礎 Inside Bar 一年 50+ 天過濾到只剩 2-4 次）。

**訊號稀有性 vs alpha 保護的關係**：
```
訊號頻率 ↑ → 容易被集體交易 → alpha 消化快
訊號頻率 ↓ → 不易被集體交易 → alpha 殘餘多
```

v0.4 把訊號頻率壓到極限 → alpha 殘餘的「**結構性保護**」。

#### 證據 3：執行細節的 micro-edge

S2 v0.4 對比「教科書版」母子線突破的執行差異：

| 維度 | 教科書版 | S2 v0.4 |
|------|---------|---------|
| 突破閾值 | 固定 (e.g., 1 tick) | **動態** (MotherRange × 5%) |
| 進場時機 | 突破當根進 | **連續 2 根站穩才進** |
| 量能過濾 | 無 | **Volume > MA × 1.2** |
| 壓縮確認 | 樣態而已 | **3 維交叉確認**（A-1/A-2/A-3）|
| 停損 | Fixed | **4 層保護**（Frozen + BE + SP + Trail）|
| 停利 | Fixed | **TP + Trail 接管** |

**每個執行細節都是微 edge**。教科書版 PF 可能已降到 1.0 附近，但加上這些 micro-edge 可能拉回 1.5-2.5。

### 1.4 量化驗證路徑（Phase 2）

**驗證殘餘 alpha 的標準方法**：對比測試

| 變體 | 設定 | 預期 PF | 用途 |
|------|------|--------|------|
| **Naive 教科書版** | 全部 A/B/C 關閉，僅 Inside Bar | < 1.0 | 證明「純樣態無 alpha」|
| **v0.2 模組化** | + 標籤統一，無實質過濾 | ≈ Naive | 證明模組化不影響 alpha |
| **v0.3 B+C** | + 假突破過濾 + 停損保護 | 1.2-1.8 | 證明執行細節有 edge |
| **v0.4 完整** | + 壓縮量化過濾 | 1.5-2.5 | 證明壓縮過濾有 edge |

**判定標準**：
- v0.4 PF > v0.3 PF > v0.2 PF → **殘餘 alpha 存在**
- v0.4 PF ≈ v0.2 PF → **過濾無效，alpha 已被消化**
- v0.4 PF < v0.2 PF → **過度過濾，反而傷害績效**

### 1.5 E-1 結論

| 維度 | 評估 |
|------|------|
| 理論基礎 | ⚠️ 教科書策略 alpha 應已部分衰減 |
| 殘餘 alpha 可能性 | 🟢 高（30M+Daily 在 TXF1 不流行 + 14 層過濾 + micro-edge）|
| 量化驗證 | ⏳ 需 Phase 2 MC 真實對比測試 |
| **行動建議** | **繼續 Phase 2 驗證，但對 PF > 3 的結果保持懷疑** |

## 二、E-2: PF 4.61 真實性評估

### 2.1 量化界的「PF 紅旗」標準

| PF 區間 | 業界普遍認知 |
|--------|------------|
| < 1.0 | 賠錢 |
| 1.0-1.3 | 勉強 |
| 1.3-1.8 | 不錯 |
| 1.8-2.5 | 很好 |
| 2.5-3.5 | **可疑**（要審查 setup）|
| > 3.5 | **紅旗**（很可能有 bug 或樣本偏差）|

**v0.1 PF 4.61 落在紅旗區**。

### 2.2 PF 4.61 可能來源（按可能性排序）

#### 可能性 1：Python 日線代理回測樂觀偏差（🔴 最高）

**問題機制**：
- v0.1 用 `^TWII` (台股加權指數) **日線**回測
- 但 S2 設計是 30M chart on TXF1
- 兩者差異：
  - TXF1 ≠ TWII（一個是期貨指數，一個是現貨指數）
  - 日線 ≠ 30M（精度差距大）
  - 沒有「實際成交價」概念，只有「日 K H/L/C」

**結果**：
- 進場價可能用「當日 Close」假設成交（實際 30M Open 可能差很多）
- 停損價可能用「當日 Low」假設觸發（實際 30M 內可能有 wick 提前觸發）
- TP 價可能用「當日 High」假設達到（實際 30M 內可能來回多次）

**樂觀偏差規模估算**：日線代理 PF 通常比 MC 真實 PF **高 30-50%**。

→ 真實 MC PF 預估 = 4.61 × 0.6 = **~ 2.8**

#### 可能性 2：樣本不足（🔴 高）

34 筆樣本中：
- 22 筆 winners × avg gain 45,957 = +1,011,054
- 12 筆 losers × avg loss 18,275 = -219,300
- PF = 1,011,054 / 219,300 = 4.61

**但**：
- 如果其中 1 筆 loser 變成 100k 大虧（一個極端事件）
- PF = 1,011,054 / (219,300 + 100,000) = 3.17
- 變化巨大 = 樣本不足

**統計上 34 筆樣本的 PF 信心區間極大**（可能 95% CI 是 [2.0, 8.0]）。

#### 可能性 3：Lookahead Bug（🟡 中）

Python 回測常見問題：
- 用「未來資訊」當訊號（例如用今日 Close 判斷今日進場）
- `^TWII` 日線資料可能有資料時間戳記偏差

**檢查方法**：MC 真實回測時觀察「進場時間 vs 訊號時間」是否合理。

#### 可能性 4：滑價 / 手續費未計入（🟡 中）

v0.1 Python 回測可能：
- 用「理論價」不含滑價
- 不含交易稅（TXF 期交稅 0.002%，雙邊 = 約 1 tick）

實盤每筆交易實際成本 ≈ -500~-1000 NTD（滑價 + 稅）。
34 筆 × -750 = -25,500 → 減少獲利 ~ -25k
→ PF 從 4.61 略降到 4.0

### 2.3 預測 MC 真實 PF 範圍

| 情境 | 假設 | 預估 MC PF |
|------|------|---------|
| **保守** | 日線代理偏差 50% + 滑價 + 樣本影響 | **1.5 - 2.0** |
| **中性** | 日線代理偏差 30% + 滑價 | **2.0 - 2.8** |
| **樂觀** | 日線代理偏差 20% + 滑價 | **2.8 - 3.5** |
| **極樂觀**（不太可能）| 偏差 < 10% | **3.5 - 4.5** |

**最可能落點**：**2.0 - 2.8**。

### 2.4 通過 / 失敗門檻設定

| MC 真實 PF | 結論 | 後續動作 |
|----------|------|--------|
| > 3.0 | **可疑高** | 審查 setup 有無 lookahead bug |
| 2.0 - 3.0 | **不錯** | 進 Phase 3 嚴謹驗證 |
| 1.5 - 2.0 | **勉強** | 評估是否值得繼續 |
| 1.2 - 1.5 | **邊緣** | 大概率 archive |
| < 1.2 | **失敗** | 確認 alpha 已被市場消化，archive |

### 2.5 E-2 結論

| 維度 | 評估 |
|------|------|
| PF 4.61 真實性 | 🔴 **不真實**（極可能是 Python 代理樂觀偏差）|
| 最可能真實 PF | 2.0 - 2.8 |
| **判定門檻** | MC PF > 1.5 = 繼續；< 1.5 = archive |
| **行動建議** | **完成 Phase 2 MC 回測前，不再引用 PF 4.61 作為論證** |

## 三、E-3: 樣本不足統計信心評估

### 3.1 統計門檻

中心極限定理：樣本 > 30 才能假設常態分布 → 才能用 **t-test / z-test** 等推論。

| 樣本數 | 統計可靠度 |
|--------|---------|
| < 10 | 🔴 無意義（純運氣）|
| 10-29 | 🔴 低（偏差大）|
| **30-49** | 🟡 **勉強有意義**（v0.1 = 34 筆在此）|
| 50-99 | 🟢 中等（可初步推論）|
| 100-299 | 🟢 高（穩健推論）|
| > 300 | 🟢 極高 |

### 3.2 v0.1 樣本問題

```
v0.1 = 34 筆 / 6.4 年 = 5.3 筆/年
```

問題：
- 統計上勉強及格
- 加上 v0.4 嚴格過濾後可能更少
- 預期 v0.4 樣本：**12-24 筆 / 6 年 = 2-4 筆/年**

**v0.4 樣本可能更不足**！

### 3.3 緩解方向

#### 方向 1：MC 30M 比日線多訊號（可能拉到 50+ 筆）

日線一年 250 個交易日 → 每天 1 個 K 棒 = 250 個觀察點。
30M 一年 ~5000 個 K 棒（含夜盤）→ **20 倍細粒度**。

但訊號數不會 ×20，因為：
- Inside Bar 仍然是日線級事件（每天最多 1 個）
- 30M 增加的是「**進場時機精度**」，不是「訊號數量」

**預期 MC 30M v0.1 樣本** ≈ 40-60 筆（比 Python 多 20-50%，因為實際 30M 觸發點更多）

#### 方向 2：放寬部分過濾增加樣本

v0.4 可以做 A/B 對比：
- 全嚴格 (v0.4) → 12-24 筆
- 半嚴格 (只開 A-1) → 25-40 筆
- 寬鬆 (只開 B+C) → 40-60 筆

**取捨**：樣本多但 PF 低 vs 樣本少但 PF 高

#### 方向 3：擴大回測期間

v0.1 回測 2020-2026 (6.4 年)。可考慮：
- 加入 2015-2019 (5 年)
- 但要注意：那段期間 TXF1 結算規則可能不同
- 且加入老資料可能引入「regime change」問題

### 3.4 樣本不足下的「保守決策」

**統計信心不足時**：
- 不要過度信任 PF / WR / MDD 數字
- 用「**範圍**」而非「**點估計**」評估
- 例如：「PF 預期 1.5-2.5」而非「PF = 2.0」
- 上線時 **小倉位試驗**，不是直接 1 口正常配置

### 3.5 E-3 結論

| 維度 | 評估 |
|------|------|
| v0.1 樣本 (34) | 🔴 勉強及格 |
| v0.4 樣本預估 | 🔴 不足（< 30 機率高）|
| **緩解** | MC 30M 跑出更多訊號 + A/B 對比 |
| **行動建議** | **若樣本 < 50，必須誠實標記為「實驗性策略」** |

## 四、E 系列整合結論

### 三題評估矩陣

| Issue | 風險評級 | 量化評估 | 緩解方案 |
|-------|--------|--------|--------|
| **E-1** Alpha 衰減 | 🟡 中 | 殘餘 alpha 可能存在，需驗證 | Phase 2 對比測試 |
| **E-2** PF 4.61 異常 | 🔴 高 | 極可能是代理偏差，預估真實 PF 2.0-2.8 | MC 真實回測 |
| **E-3** 樣本不足 | 🔴 高 | v0.4 樣本可能 < 30 | 拉長回測 + 接受實驗性定位 |

### 最終建議

**S2 v0.4 是「有意義的實驗」，不是「準上架策略」**。

#### 上架前必須驗證

```
[ ] MC 30M 真實 PF > 1.5
[ ] MC 30M 樣本 > 30 筆
[ ] v0.4 vs v0.3 vs Naive 對比顯示 alpha 殘餘
[ ] OOS 表現偏離 IS < 30%
[ ] WFE > 50%
[ ] MC 95% MDD < 帳戶 30%
[ ] 2022 熊市單獨 PF > 1.2
```

**上述條件 7/7 通過才考慮 Phase 4 模擬上架**。

#### 預期最終定位

最樂觀情境（所有驗證通過）：
- S2 上 live 但配置 **小於 L1 的一半**（樣本少 → 信心少 → 倉位少）
- 帳戶配置建議：500K 起始
- 預期年化交易：15-25 筆
- 預期年化淨利：+80k ~ +180k（保守估計）

最悲觀情境（多項驗證失敗）：
- S2 維持在 research/，作為「**設計試驗**」教材
- 留下完整的 v0.1 → v0.4 演化記錄
- 學到「公開技術分析策略在 TXF1 30M 不夠 alpha」這個負面結論

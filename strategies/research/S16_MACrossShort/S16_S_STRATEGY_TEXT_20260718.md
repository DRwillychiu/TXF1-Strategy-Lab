### Strategy Description

**【一、策略定位】**

在台指期貨5分鐘K線上，利用ZLEMA雙均線死叉搭配MinSlope過濾器，
狙擊極短動能爆發的空頭行情，抓2小時內的momentum burst，
其餘時間小虧或不做。

- 策略性格: 狙擊手型(Sniper)
- 主場行情: 空頭趨勢盤、高波動急殺盤
- 保險成本: 多頭盤整期間的小虧損
- 交易頻率: 約17次/年(低頻)
- 持倉時間: 平均僅佔約0.15%，多數時間空手等待


**【二、進場邏輯】**

進場條件(全部同時滿足才進場):

1. 死叉訊號: 快線ZLEMA(25)由上往下穿越慢線ZLEMA(70)
   -> 短期動能首次弱於中期動能，代表空方力道正在集結

2. 斜率過濾: 快線每根K棒下跌幅度 > 28點
   -> 只在極端下跌動能出現時才進場，篩掉大多數普通死叉訊號

3. 合規檢查: 非結算日、非假日(63個期交所假日封鎖)、資料未過期、未手動停止

進場方式: 下一根K棒以市價做空

白話文:
兩條均線交叉向下，而且快線正在陡峭下彎(每5分鐘跌超過28點)，
才會進場做空。條件非常嚴格，一年只進場約17次。


**【三、出場邏輯】**

出場採用8層優先順序，由高到低依序檢查:

第0層 [硬性合規] -- 最高優先
  手動停止 / 資料過期 / 假日平倉(凌晨04:15) / 結算日平倉(12:30)
  -> 無條件強制出場，保護帳戶安全
  -> 假日模組 v1.0.1 起真實生效：63個期交所假日進場封鎖+持倉強制平倉

第0.5層 [時間護欄] -- v1.3 新增
  凌晨04:30後不開新倉；04:40持倉強制市價平倉(成交約04:40-04:45)
  -> 任何部位結構上不可能跨越早盤空窗/週末/假日休市
  -> 進場端開放到04:30：未來收盤前的急殺burst頭段吃得到
  -> 實測1筆觸發(+21,400)，並擋掉1筆跨早盤空窗的gap虧損(-32,800)

第1層 [快速止損] -- 核心防線
  (a) 虧損超過60點(12,000元) -> 立刻砍倉
  (b) 持倉滿4根K棒仍無獲利 -> 立刻砍倉
  -> 本層處理了75筆交易(68%)，合計 -1,186,200
  -> 策略虧損可控的關鍵機制

第2層 [極端反轉監控] -- Rule #17 多層停損
  當虧損達到停損距離的20%時啟動
  同時監控5個面向: K棒型態/量價/動能/結構/波動率
  綜合評分超過60%且跨3個以上類別 -> 觸發出場
  -> 實測中未觸發(第1層已先處理)

第3層 [保本追蹤] -- 獲利保護
  Tier 1: 獲利達1倍ATR -> 停損拉到成本價附近
  Tier 2: 獲利達1.5倍ATR -> 停損再往上拉
  -> 實測11筆合計 -54,000，此機制正在深度檢驗中(G3議題):
     疑似在初始停損階段過早啟用，截斷該賺的獲利

第4層 [金叉出場] -- 主要出場訊號
  快線ZLEMA由下往上穿越慢線 -> 空方動能結束，平倉
  -> 實測僅觸發3筆(burst通常在金叉前就被TimeStop截住)

第5層 [時間停損] -- 主要獲利來源
  持倉滿24根K棒(=2小時) -> 強制平倉
  -> 這是策略的alpha核心: 21筆TimeStop出場，100%勝率，
     平均每筆獲利+94,581元，合計貢獻+1,986,200元
  -> 設計邏輯: momentum burst的動能窗口約2小時，
     超過這個時間繼續持有反而增加回吐風險

第6層 [ATR停損] -- 最後防線
  以進場時的ATR x 4.0計算固定停損價位
  -> 實測中未觸發(第1層已先處理)

第7層 [引擎護欄] -- MC系統備援
  MultiCharts引擎層級的SetStopLoss，進場瞬間即生效
  -> 防止任何邏輯遺漏導致的無限虧損

適合:

- 熊市延續下殺
- 高波動盤中急速回檔
- 政策衝擊/系統性風險爆發
  (實證: 2026年7月台股DD危機期間，本策略單月14筆交易+264,000，
   在L1-L5多方組合失血時發揮空方對沖本職——模擬中，未實盤)

不適合:
- 強多頭主軸(會產生保險成本，但每筆虧損可控)
- 緩漲盤整(進場條件過嚴，自然不會亂進)
- 低波動月份(自然低頻，不會硬做)
- 跨假日行情(v1.0.1起無條件不參與——見設計決策6)


**【六、關鍵設計決策】**

1. 為什麼用5分鐘K線?
   ZLEMA在5分鐘上零延遲優勢最明顯，能最早捕捉到動能反轉。
   代價是whipsaw較多，但QuickStop已控制每筆虧損。

2. 為什麼不加更多進場過濾器?
   測試過ATR環境/成交量/連續下彎/日線方向/時段/距離共6種filter，
   全部否決。原因: 5分鐘時框承擔不起延遲，加filter會錯過burst起點。

3. 為什麼不加行情過濾(Regime Filter)?
   刻意不加。多頭時的小虧損是可接受的保險成本，
   加了filter反而可能在行情突然轉空時來不及進場。

4. 為什麼TimeStop設24根(2小時)?
   momentum burst的動能窗口約2小時，
   超過這個時間繼續持有，獲利回吐風險大於繼續持有的期望值。

5. 為什麼勝率這麼低(22.73%)還能賺錢?
   狙擊手型策略的本質: 大多數時候小虧(平均-14.6K)，
   少數時候大賺(平均+83K)，賺賠比5.68倍彌補低勝率。

6. 為什麼堅持假日封鎖，即使歷史上那筆跨假單賺了37萬?
   持倉跨休市期間，所有停損機制全部失效——gap面前
   QuickStop/ATR SL/引擎護欄通通擋不住。2025年4月那筆+370K
   是賭對了關稅崩盤方向；若反向跳空即為單筆-360K(帳戶36%)。
   賺或虧取決於休市期間的新聞，不是策略邏輯。
   本策略只賺紀律內的錢。


**【七、風險揭露】**

1. 最長可能連續虧損10次，期間虧損159,600(初始資金16.0%)
2. 最長持平期間約1年10個月(2020/05~2022/03無新高)
3. 多頭行情期間為結構性保險成本區
4. ZLEMA_Slow=70為窄峰參數(S80時績效-33.5%)
5. MinSlope=30時出現懸崖(-27.4%)，參數距離懸崖僅2步
6. Alpha高度集中: 21筆TimeStop承載全部獲利，
   系統斷線漏接2-3筆大單即可能由盈轉平

操作者需具備的心理準備:

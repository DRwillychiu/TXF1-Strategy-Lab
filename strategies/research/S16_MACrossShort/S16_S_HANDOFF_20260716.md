### 5.5 D-2 進化版完整實作 (主線 A)
**用戶洞察**: 空方策略在多頭環境要抓兩類行情：
- Type 1: 突然的高斜率下跌（單根高 slope）
- Type 2: 連續型的斜率下跌（多根連續穩定跌）

**完整 code sketch**:
```pla
{ === 3 種 slope 度量 === }
v_Slope_Now      = v_ZLEMA_Fast[1] - v_ZLEMA_Fast;
v_Slope_Prev     = v_ZLEMA_Fast[2] - v_ZLEMA_Fast[1];
v_Slope_Accel    = v_Slope_Now - v_Slope_Prev;
v_Slope_Avg3     = (v_ZLEMA_Fast[3] - v_ZLEMA_Fast) / 3;

{ === 3 根連續下彎 === }
v_Slope_Consist  = v_ZLEMA_Fast[3] > v_ZLEMA_Fast[2] and
                   v_ZLEMA_Fast[2] > v_ZLEMA_Fast[1] and
                   v_ZLEMA_Fast[1] > v_ZLEMA_Fast;

{ === 雙 gate 進場 === }
if v_Death_Cross and (
    (v_Slope_Now > MinSlope and v_Slope_Accel >= MinAccel)   { Type 1 }
    OR
    (v_Slope_Avg3 > MinSlopeAvg and v_Slope_Consist = True)  { Type 2 }
) then
    sell short next bar at market;
```

**新增 inputs**:
```pla
MinSlope        ( 28  ),   { Type 1: 保留現行 }
MinAccel        ( 0   ),   { Type 1: 允許加速度 >= 0 (不減速) }
MinSlopeAvg     ( 15  ),   { Type 2: 3 根均斜門檻，較低 }
```

**GA 掃描**:
- 3 params × 平均 10 值/param = 60-100 combos
- 保留其他 v1.0-PROD LOCKED

**風險**: Type 2 帶來的 alpha 若小於帶來的 QuickStop 損 → REJECTED

### 5.7 「超過 2hr burst」完整解釋
**Burst 定義**: 一段連續的動能爆發下跌
**現行機制**: 24 根 K = 2hr 硬砍
**問題**: 若 burst 持續 3-4hr → 我們硬砍會截斷後半段

**實例**:
```
T=0     進場做空 (Close=47000)
T=1hr   Close=46800 (+40K)
T=2hr   Close=46600 (+80K) → TimeStop 出場
T=3hr   Close=46300 (若持有 +140K，實際：出場了)
T=4hr   Close=46000 (若持有 +200K，實際：只賺 +80K)
少賺 120K
```

**未量化**：20 筆 TimeStop 中有多少屬於這種截斷？需主線 D 對比實驗回答。

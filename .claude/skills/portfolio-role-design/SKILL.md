# 策略組合角色設計鐵則

> **2026-08-01 用戶裁示，適用於全部策略層級（live / live_simulation / research）**

## 核心原則

每支策略是組合的一角，不是獨立運作的完整系統。

```
設計目標 ≠ 單一策略 PF 最大化
設計目標 = 抓到該賺的行情 + 小虧損 + 小賺錢 + 大賺錢
```

## 鐵則

### R1: 角色優先於績效

每支策略有明確的「該賺的行情」定義：
- 趨勢多頭策略 → 該賺上漲波段
- 趨勢空頭策略 → 該賺下跌波段
- 盤整策略 → 該賺區間震盪
- 動量策略 → 該賺極端行情

**當策略在「該賺的行情」中缺席，比策略整體 PF 低 0.05 更嚴重。**

### R2: 小虧損、小賺錢、大賺錢

| 結果 | 設計要求 |
|------|---------|
| 虧損單 | 必須小（出場系統控制，非進場濾網封殺） |
| 小賺單 | 正常，不需消滅 |
| 大賺單 | 策略存在的意義，必須參與 |
| 磨耗 | 可接受，由組合中其他策略彌補 |

### R3: 進場濾網 vs 出場系統的職責分離

| 職責 | 負責機制 | 錯誤範例 |
|------|---------|---------|
| 上車（參與行情） | 進場條件（越早越好） | 用 MinSlope=28 封殺 70% 的死亡交叉 |
| 控制虧損 | QuickStop / StopLoss / TimeStop | 用嚴格進場條件來「減少虧損單」 |
| 保護獲利 | TrailingStop / BreakEven | — |

**禁止**：用過嚴的進場濾網來提高 PF。這會讓策略在該賺的行情中缺席。

### R4: 組合彌補認知

本策略的不足之處（盤整磨耗、小虧損累積）有其他策略彌補：
- L1-L5 覆蓋多頭趨勢
- S1 覆蓋夜盤動量
- S3 / S3_L / S3_S 覆蓋波動率事件
- S16_S 覆蓋 MA 交叉空頭

**不需要每支策略都能「獨立存活」。**

## 應用於參數最佳化

### 最佳化指標優先序

1. **大行情參與率**（該進場時有沒有進場？）
2. **單筆虧損大小**（做錯時虧多少？）
3. **R:R 比**（大賺 vs 小虧的比例）
4. **PF**（僅作為最終確認，不作為主要篩選標準）

### 最佳化時的常見錯誤

| 錯誤 | 正確做法 |
|------|---------|
| 最大化 PF → 進場門檻越拉越高 | 先確認大行情參與率 ≥ 90%，再看 PF |
| 用完整回測期 PF 評估 → 低指數年代的物理差異汙染結論 | 分段評估，注意指數水位效應 |
| 認為「晚進場但確認」是好事 | 晚進場 = 少賺的利潤 = 策略失職 |
| 認為「少交易 = 高品質」 | 少交易可能 = 漏掉大行情 |

## 與現有規範的關係

- **Rule #13（10 維度框架）**：本鐵則修正維度權重——大行情參與率成為第一維度
- **STRATEGY_RD_SOP**：W0 Alpha Pre-verify 必須包含「該角色的大行情是否被捕獲」
- **Adversarial SOP Step 7**：Before/After 表必須包含大行情參與率欄位

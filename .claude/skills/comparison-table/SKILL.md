# 比較表呈現規範

**觸發**：任何「A 對 B」的呈現——版本前後、參數方案、定義選項、策略對照。
**產出**：`show_widget`，不是純 markdown 表格。
**基準案例**：`L2 v5.3 → v5.4 標籤版`（2026-08-25，用戶明確稱「非常滿意」）。

---

## 1. 五段結構，順序不可換

```
① 結論橫幅      一句話講完，大字，放最上面
② 沒變 / 變了    兩張對比卡並排，數字大、說明小
③ 完整指標表     每一項逐行列出，含「差異」欄
④ 新增資訊表     這次才看得見的東西
⑤ 值得記住的事   1-2 點，含推翻自己的更正
```

**②「沒變／變了」是整套的核心。** 讀者第一眼就要分清楚
**「什麼被保證沒動」** 與 **「什麼是這次的成果」**，不必讀數字。

---

## 2. 每一段的規格

### ① 結論橫幅
- `var(--surface-1)`，`border-radius: 12px`，padding `1.25rem 1.5rem`
- 小字副標（13px，`--text-secondary`）→ 大字結論（26px，weight 500）→ 說明段（14px，line-height 1.65）
- **結論句必須是白話**，例：「改了標籤，績效一格沒動」

### ② 對比卡
- `grid-template-columns: repeat(auto-fit, minmax(260px, 1fr))`，gap 14px
- 左卡（沒變）：`0.5px solid var(--border)`
- 右卡（變了）：**`2px solid var(--border-accent)`** ← 唯一允許 2px 的地方
- 每卡：小標（12px 大寫字距 .1em）→ 大數字（34px，分母用 18px 灰）→ 一句說明 → 條列細節（13px，line-height 1.9）

### ③ 完整指標表
- **不要只列重點，全部列出。** 24 項就列 24 項
- 欄位：`指標 | A | B | 差異`
- `font-variant-numeric: tabular-nums`
- 隔行 `background: var(--surface-1)`
- 差異欄：相同用 `±0` 綠字；不同用紅字寫實際差值
- 表頭 `1px solid var(--border-strong)`，資料列 `0.5px solid var(--border)`

### ④ 新增資訊表
- 標題上方加一句灰字說明「改之前這裡是什麼樣子」
- 重點列整列 `background: var(--bg-accent)` ＋ 內容加粗
- 合計列 `background: var(--surface-1)`

### ⑤ 值得記住的事
- `var(--surface-1)` 圓角框
- 用「一、」「二、」編號，不用項目符號
- **如果這次推翻了自己先前的說法，必須寫在這裡**，含數字與原因

---

## 3. 硬規則

| # | 規則 |
|---|---|
| 1 | **數字全部 `tabular-nums`**，負號用 `−`（U+2212）不用 hyphen |
| 2 | 顏色只用 CSS 變數，**深淺色模式都要能讀** |
| 3 | **不用 emoji**。需要圖示用 Tabler outline |
| 4 | 表格外層包 `overflow-x: auto`，窄螢幕不撐破版面 |
| 5 | 標題句一律**句子大小寫**，不用 Title Case |
| 6 | **不要在 widget 裡寫長段解釋**——那些放回覆本文 |
| 7 | 每個 widget 開頭要有 `<h2 class="sr-only">` 一句話摘要 |

## 4. 反面示範（2026-08-25 第一版被要求重做）

| 問題 | 為什麼不行 |
|---|---|
| 直接把 R-1..R-5 的驗收清單放最上面 | 那是工程師語言，讀者要先知道「結論是什麼」 |
| 指標表只列重點幾項 | 「全部相同」這個主張需要**全部列出**才有說服力 |
| 沒有「沒變 / 變了」的視覺區隔 | 讀者無法一眼分辨保證與成果 |

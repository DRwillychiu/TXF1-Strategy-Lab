# 策略敘事版純文字說明 SKILL

## 觸發詞
「給我簡潔版本」/「純文字版本」/「敘事版」/「白話說明」/「3 分鐘版」

## 目標
**讓完全不懂這份策略的人在 3 分鐘內理解清楚。** 不是濃縮審計檔，是講給人聽的故事。

## 結構模板（6 段，順序固定）

1. **這是什麼 + 賺什麼錢**：一句定位 + 一句經濟邏輯（為什麼這種行情有錢賺）+ 組合角色
2. **怎麼進場**：條件白話化 + 每個條件「代表市場發生什麼事」的翻譯句 + 嚴選程度（頻率）
3. **怎麼出場**：各層防線一層一句白話，標明哪層是「主要獲利來源」
4. **設計鐵則**：不做什麼 + 為什麼（各一句）
5. **成績單**：翻譯過的數字（見濾網規則）+ 誠實代價（心理成本）
6. **目前狀態**：在哪個階段、下一個關卡是什麼

## 「誰都懂」濾網（違反任一條 = 重寫）

1. **零未解釋術語**：ZLEMA/ATR/死叉/獲利因子/PF/WFA 等，要嘛同句內建翻譯，要嘛改寫成白話
   - ❌「賺賠比 5.1」 → ✅「贏一次抵五次虧損」
   - ❌「獲利達 2.5 倍 ATR」 → ✅「帳面獲利夠大之後」
   - ❌「死叉」 → ✅「快線跌破慢線，代表短期動能首次弱於中期」
2. **禁夾英文行話**：lumpy / whipsaw / regime → 損益大小月分明 / 洗盤 / 行情型態
3. **必有經濟邏輯句**：為什麼這種行情有錢賺（例：崩盤下跌又快又猛，抓頭段就夠賺）
4. **數字上限 ~12 個**：只留讀者記得住的（頻率/勝率/淨利/年化/回檔/單筆控制）
5. **禁括號證據註解**：「（實測 xx 筆…）」是審計檔寫法；證據住在 STRATEGY_TEXT/DEPLOYMENT，敘事版不自我辯護
6. **長度 700-900 字**，每段只講一個概念
7. **誠實揭露不可少**：心理成本、保險費期、操作紀律要求 — 用一般人聽得懂的方式講

## 二、用戶的 SL → 跳空開低假設（精準洞察）

### 假設陳述
> 「假設夜盤進場，如果碰到止損，是不是隔天跳空開低機率高？」

### 邏輯推論（合理）

```
夜盤多單觸發 SL
  ↓
表示走勢已反轉，多頭結構失效
  ↓
夜盤空頭壓制強
  ↓
（推論）隔天日盤開盤跳空向下機率 ↑
```

### 間接證據（從 v2.2 vs v2.3 數據反推）

| 群體 | 觀察 | 含義 |
|------|------|------|
| **存活到 04:15 的多單** | 09:00 比 04:30 多賺 +12.6 點/筆 | **正向 gap** 系統性存在 |
| **盤中觸 SL 的多單** | （直接證據缺，但邏輯推論）| **負向 gap** 機率高 |
| **整體平均** | 雙峰分布，可能接近中性 | 篩選後存活組強烈正向偏差 |

### 選擇性偏差（Selection Bias）的雙峰分布

```
所有夜盤多單的隔天 gap 分布（假設）：

頻率
 ↑
 |    SL 組             存活組
 |   （負向 gap）       （正向 gap）
 |     /\                  /\
 |    /  \                /  \
 |   /    \              /    \
 +---+----+--------------+----+---→ gap (點數)
   -50  -20    0    +10  +20  +50
                ↑
            「隨機表象」
```

### 為什麼整體 +12.6 點正向？

v2.2 的 LX_NM_Time **只包含「存活到 04:15 的多單」**（SL 在那之前已經出場了）。
這是 **強篩選後的群體**，本身已具備「夜盤多頭結構成立」的特徵。

所以 v2.3 揭露的「+12.6 點 / 筆」是 **存活組 conditional gap**，不是 unconditional 整體 gap。

## 四、v2.4 設計決策對照

| 項目 | v2.1（原）| v2.2/v2.3（曾改）| **v2.4（最終）** |
|------|----------|------------------|------------------|
| ExitTime | 500 | 415 | **500（恢復）** ✅ |
| Entry condition | Time<ExitTime | Time<EntryEnd_Time | **Time<ExitTime（恢復）** ✅ |
| LX_NM_Time label | ✅ | ❌ DailyFlat | **✅（恢復）** |
| LX_NM_Time 出場時間 | 09:00 day open | 04:30 night | **09:00 day open（恢復）** |
| Holiday 模組 | ❌ 無 | ✅ 加入 | **✅ 保留**（多日 gap 保護）|
| Manual_Kill_Switch | ❌ 無 | ✅ 加入 | **✅ 保留** |
| Day Session Emergency | ❌ 無 | ✅ 加入 | **❌ 移除**（干擾 09:00 意圖）|

### 為什麼保留 Holiday 模組？

正常夜→日 gap = **4 小時 gap**（05:00 → 09:00）→ 系統性正向偏差，可套利。

但 **假日跨假 gap = 60+ 小時**（如連假 4 天）：
- 不確定性極高
- 重大突發事件機率累積
- 正向 / 負向偏差未經驗證
- 風險不對稱（如 2022/06/05 夜盤崩跌 3000 點）

**Holiday 模組讓策略在假日眼前提早平倉，避開 60+ 小時不確定 gap**。
正常夜盤照常吃 4 小時 gap 套利。

**取兩個世界最好的**。

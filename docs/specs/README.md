## 執行層能力的疊加順序

```
L2  Market · Stop · ExitFired 單張                    ← 最小集合
L4  ＋ 多資料流對齊 · 變數歷史 [1]
L3  ＋ Limit 單 · OCO 撤銷
L5  ＋ 多腿部位 · 部分口數 · from Entry 綁定 · TickSize
L1  ＋ tick 生命週期 · IntraBarPersist · BarStatus 守衛
```

> `engine/context.py` 的資料模型仍須從第一天就以 tick 為原生、bar close 為特例。
> 否則做到 L1 要回頭重構，前四支已通過的對帳全部重跑。

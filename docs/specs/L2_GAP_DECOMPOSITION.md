## 算術上只有一種解

```
24 − 3 − 1 = 20      3 筆 MC 根本沒有，1 筆標籤錯
56 + 1     = 57
```

> **不是「4 筆標籤錯」，是「3 筆多出來的交易 + 1 筆標籤錯」。**
>
> 那 3 筆是**進場條件的差異**，不是標籤問題。標籤只解釋 1 筆。

## 排除：不是邊界誤判

24 筆 re-entry 的餘裕（訊號棒 Close 低於前筆進場價幾點）：

```
最小 4 點   最大 416 點   沒有一筆等於 0
```

**所以不是 `<=` vs `<` 的差別。** 把門檻改成嚴格小於，仍然是 24 筆。

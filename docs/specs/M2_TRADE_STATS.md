## 一 指標清單　**只做你會用的**

MC12 的 Performance Summary 有 22 欄。**逐項確認後選出 14 項**——
不看的就不做，那才是嚴謹，不是把 22 個全寫出來。

### 判斷賺不賺

| 指標 | 回答什麼 |
|---|---|
| `Profit Factor` | 毛利 ÷ 毛損 |
| `Percent Profitable` | 勝率 |

### 判斷賺賠結構

| 指標 | 回答什麼 |
|---|---|
| `Avg Win` / `Avg Loss` | 平均賺多少、賠多少 |
| `Ratio Avg Win/Avg Loss` | 賺賠比 |

### 判斷撐不撐得住

| 指標 | 回答什麼 |
|---|---|
| `Max Consecutive Losers` | 最長連續虧損。**心理與資金的雙重壓力測試** |
| `Account Size Required` | 期初 + 最大回撤金額 |

### 判斷交易頻率

| 指標 | 註 |
|---|---|
| `Total Trades` | 筆數少不代表差——L4 六年 94 筆是設計 |

### 判斷成本侵蝕

| 指標 | 註 |
|---|---|
| `Total Commission` | **微台的成本 72% 是固定手續費，相對成本是大台的 2.7 倍** |
| `Total Slippage` | 見第三節 |

### 判斷資金效率

| 指標 | 註 |
|---|---|
| `Return on Initial Capital` | 淨利 ÷ 期初 |
| `Annual Rate of Return` | **CAGR，日曆年** |
| `Max Contracts Held` | **直接對應保證金**——帳戶 A 峰值 6 口需 210,300，本金 200,000 |

> **未來會有加減碼**，所以資金效率三項要寫成能承受變動口數的形式，
> 不寫死成固定口數的簡化。

### 多空拆分

**Total / Long / Short 三欄，全部明確標示。**
兩個帳戶就是多空分開的——**這一欄等於帳戶層級的績效**。

### 時間分布

**年度表 + 月度表，兩者都要。**
最實用的是找出策略失效期——L3 的樣本外 PF 從 1.396 掉到 0.192。

### MAE / MFE

見第五節。

## 二 平手的定義

**裁決：單獨一類，用毛損益定義。**

```
毛損益 = 0    進場價 = 出場價
淨損益 = 0    扣掉手續費與稅之後恰為 0
```

**淨損益不可能恰為 0**，因為期交稅 = 契約金額 × 0.00002，
隨成交價變動是個非整數。

### 實測（樣本內，五支）

```
毛損益 = 0     1 筆（L5）
淨損益 = 0     0 筆
|淨損益| < 1   0 筆
```

**幾乎不存在，但定義仍要對**——MC 把平手算在虧損側，
我們單獨一類，所以勝率會與 MC 有微小差異。

## 三 滑價

**裁決 2026-09-09：**

```
點數  5 tick = 5 點/邊/口。三商品皆同
方向  一律不利方向
單型  **全部單型都加，含限價單**
開關  做成可切換，預設關閉，兩組數字並排對照
```

### 為什麼限價單也加

限價單理論上不會有不利滑價。**但這裡刻意加，理由是壓力測試**：

> 假設市場流動性非常差的嚴苛情況下，策略是否仍然賺錢。
> **在最嚴苛的假設下仍然賺錢，才是可信的。**

### 5 tick 的換算

| 商品 | tick | 5 tick | 金額/邊/口 | 來回（2 口） |
|---|---|---|---|---|
| TMF 微台 | 1 | 5 點 | 50 | 200 元 |
| MXF 小台 | 1 | 5 點 | 250 | 1,000 元 |
| TXF 大台 | 1 | 5 點 | **1,000** | 4,000 元 |

**大台 5 點 = 1,000 元，與 `CLAUDE.md` 的「1,000 NTD/邊/口」吻合**——
所以原意確實是點數，1,000 只是它在大台的金額表示。

### ★ 實測影響（微台，樣本內）

| | 筆數 off | 筆數 5pt | 淨利 off | 淨利 5pt | PF off | PF 5pt |
|---|---|---|---|---|---|---|
| L1 | 492 | 515 | 273,140 | 140,101 | 1.512 | 1.229 |
| L2 | 92 | 96 | 146,264 | 112,161 | 2.842 | 2.148 |
| L3 | 442 | 447 | 168,148 | 95,233 | 1.350 | 1.182 |
| L4 | 94 | 95 | 55,920 | 34,993 | 1.680 | 1.366 |
| L5 | 240 | 240 | 72,894 | **27,915** | 1.288 | **1.102** |
| **合計** | | | **716,366** | **410,403** | | **−42.7%** |

```
總體 MDD   滑價關閉  7.98% = 33,751
           滑價 5 點 11.87% = 52,072      +49%
```

> **★ 淨利掉 42.7%，但 MDD 漲 49%。**
> 滑價不只吃獲利，**它把回撤放大得更嚴重**——
> 因為虧損單的每一筆都多虧 20 點，而回撤是虧損的累積。

**五支的 PF 全部仍然 > 1**——在最嚴苛的假設下仍然賺錢。

但 **L5 只剩 27,915、PF 1.102**，六年半幾乎是打平。
它的平均獲利 139 點，來回滑價 20 點就佔 14%。

### 筆數會變，這是連鎖效應

```
L1  492 → 515      L2  92 → 96      L3  442 → 447
```

**滑價改變成交價 → 改變部位 → 改變後續訊號。**
不是單純的成本扣減。

### 架構：包裝層，不是塞進去

```
MC12FillModel     「誰觸發、成交在哪、順序如何」   ← MC 的樂觀假設，對帳基準
  └ SlippageFill  「往不利方向推 N 點」            ← 可切換
```

**把滑價塞進 `fill_mc12` 會污染它的定位**——它就不再是 MC 的複製品，
對帳基準也就消失了。已寫成測試 `test_fill_mc12_stays_zero_slippage`。

`policy` 名稱同時顯示兩層：

```
fill_mc12+slip=off
fill_mc12+slip=5tick|limit|assumed
                             ↑ 設定值，不是量測值
```

### 這是設定值，不是量測值

`is_measured = False`。真實滑價要從實戰紀錄量（訊號價 vs 成交價），
**量到之前，任何用它算出的數字都要標註**。

## 四 Avg Bars 的單位

**裁決：根數與分鐘兩個都報，以分鐘為主。**

```
根數    只用來對 MC12 的報告（它報根數）
分鐘    用來跨支比較、評估跨夜與事件風險
```

### 為什麼根數不可跨支比較

| | 週期 | 獲利單根數 | 獲利單分鐘 | 獲利單小時 |
|---|---|---|---|---|
| L1 | 45M | 50.7 | 2,282 | **38.0** |
| L2 | 60M | 31.1 | 1,863 | 31.1 |
| L3 | 15M | 45.7 | 686 | **11.4** |
| L4 | 15M | 35.1 | 527 | 8.8 |
| L5 | 15M | 26.2 | 393 | 6.5 |

**L1 的 50.7 根與 L3 的 45.7 根看起來差不多，實際差 3.3 倍時間。**

### 實戰上的三個後果

**跨夜與週末暴露**　L1 平均抱 38 小時，必然跨夜、常常跨週末。
夜盤流動性差、隔日跳空、國際事件。

**保證金佔用時間**　抱越久那筆保證金鎖越久，其他策略能用的越少。

**事件風險**　抱 38 小時必然遇到 FOMC、非農、財報；抱 6.5 小時多半不會。

## 五 MAE / MFE

**裁決：1 分 K 取樣，MAE 與 MFE 兩者都要，單位用點數。**

### 它是 2×2，不是兩個獨立指標

| | 回答什麼 | 驅動什麼決策 |
|---|---|---|
| **獲利單 MAE** | 贏的單曾經虧多深 | **停損不能再緊的界線** |
| 獲利單 MFE | 贏的單最多賺過 | 與實際均賺比 = 回吐多少 |
| 虧損單 MAE | 輸的單虧到多深 | 停損有沒有真的生效 |
| **虧損單 MFE** | 輸的單曾經賺過 | **停利設太遠的證據** |

### 實測（樣本內，1 分 K，單位：點）

| | 獲利MAE | 獲利MFE | 虧損MAE | 虧損MFE | 實際均賺 | 回吐 |
|---|---|---|---|---|---|---|
| L1 | 29 | 426 | 122 | 54 | 238 | **44%** |
| L2 | 47 | 553 | 102 | 54 | 325 | **41%** |
| L3 | 37 | 182 | 130 | 53 | 159 | 13% |
| L4 | 37 | 230 | 91 | 42 | 180 | 22% |
| L5 | 54 | 189 | 153 | 50 | 139 | 26% |

**L1 和 L2 把四成的最高獲利吐回去了**——追蹤停損太鬆的訊號。
**L3 只吐 13%**，它的固定目標（箱頂）抓得比較準。

### 為什麼用 1 分 K

**Data1 高估 MAE**，因為 K 棒的高低點包含進場前與出場後的價格：

```
              Data1    1 分 K    差
L1（45M）      40       29      −27%
L3（15M）      39       37       −5%
```

**週期越大失真越大。** 成本幾乎是零（0.05 秒）。

> **1 分 K 仍然略微高估**（進場那一分鐘也包含進場前的價格），
> 真正精確要 tick 資料。**這一點必須寫在輸出上。**

## 六 年化報酬

**裁決：CAGR，日曆年。並把交易日數當獨立事實一併輸出。**

```
CAGR = (1 + 總報酬)^(1 / 年數) − 1
年數 = 日曆天 / 365.25
```

### 為什麼用日曆年而不是交易年

```
日曆年數   7.671
交易年數   7.661      差 0.13%
```

**兩者只差 0.13%**，但**可比性完全不同**：
CAGR 要跟定存年利率、大盤年報酬比，那些全部用日曆年。

### 交易日數（從 210 萬列 1 分 K 反推）

```
2019  241    2020  245    2021  244    2022  246
2023  239    2024  242    2025  243
完整年度平均 243.2 天　範圍 239–246
```

**這比公告的行事曆更權威——那是實際成交的日子，不是預定的日子。**

### 邊界情況

**若總報酬 ≤ −100%（權益歸零），CAGR 在數學上無定義。**
回傳 −100% 並標註，不拋錯也不靜默給怪數字。

## 七 所需帳戶規模（裁決 2026-09-09）

MC 的定義是「期初資金 + 最大回撤金額」，但我們有四種組合：

| | 回撤來源 | 金額定義 | 微台總體 | 比期初多 |
|---|---|---|---|---|
| A | ③ 日結算 | 百分比那一點 | 336,288 | 12.1% |
| B | ③ 日結算 | 最大絕對 | 365,179 | 21.7% |
| C | ⑤ 盤中極值 | 百分比那一點 | 336,628 | 12.2% |
| **D** | **⑤ 盤中極值** | **最大絕對** | **367,139** | **22.4%** |

**A≈C、B≈D。真正的分歧在「百分比點 vs 最大絕對」，差了 3 萬。**

### 裁決：主指標 D，對照 A，差距獨立標出

```
D   「準備多少錢」問的是絕對值，而且要防斷頭 → 盤中極值 × 最大絕對
A   與 MDD 定義一致（金額跟著百分比走），可與其他報告對帳 → 對照
```

**兩者的差距本身是資訊**：差距大代表「相對最慘」與「絕對最慘」
發生在不同時期，權益曲線不是平穩成長的。

### 實測

| | 期初 | D 主指標 | A 對照 | 差距 |
|---|---|---|---|---|
| A 多 | 200,000 | **267,139**（+33.6%） | 236,288 | 30,851 |
| B 空 | 100,000 | **149,855**（+49.9%） | 149,855 | **0** |
| 總體 | 300,000 | **367,139**（+22.4%） | 336,288 | 30,851 |

```
D 發生於 2026-06-12　　A 發生於 2021-03-10
```

> **帳戶 B 的四個選項數字完全相同**——它的相對最慘與絕對最慘是同一天
> （2024-08-23），權益曲線沒有成長到讓兩者分開。
>
> **而它需要比期初多 50%。** 空單帳戶的 10 萬本金，
> 在歷史上最壞的時候會虧掉一半。**這跟保證金的發現是同一件事：帳戶 B 配得太少。**

## 七之二　單支 MDD 的主分母（裁決 2026-09-09）

**名目每支 6 萬。**

單支的 MDD 是要回答「這支策略本身多危險」。
用帳戶或總體當分母，會讓同一支策略在不同組合下有不同的數字——
**那就不是策略的屬性了**。

帳戶與總體的 MDD 各自獨立輸出，它們回答的是不同層次的問題。

### 實作時追加的兩個決定

**年數用回測期間，不是首末筆。** 策略閒置的那一年，資金一樣被綁著。
`compute(period=...)` 沒給時退回首末筆並在報表標註。

**持倉時間用日曆分鐘。** 含夜盤空檔與週末——那才是真正暴露的時間。
昨天算的「38 小時」是 K 棒數 × 45 分（市場開盤時間），
今天用日曆時間 L1 是 64 小時。**兩者都留，報表標清楚。**

### CAGR 無定義的兩種情況

```
權益歸零      總報酬 <= −100%
期間不滿一天   同日進出時 (1+r)^(1/1e-9) 會溢位
```

**標為無定義，不拋錯也不靜默給怪數字。**

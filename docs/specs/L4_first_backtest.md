## 淨利差距較大，原因待查

筆數差 5%，但淨利差 60%（1,399,503 vs 877,200）。同樣的勝率下 PF 更高
（1.92 vs 1.49），代表**我們的贏家更大或輸家更小**。

三個嫌疑，按可能性排序：

| # | 嫌疑 | 判斷方式 |
|---|---|---|
| 1 | **Data2 / Data3 對齊規則** | L4 是第一支三資料流的策略，對齊是我猜的部分 |
| 2 | 成交價（`fill_mc12` 的 gap policy） | L2 已測出 `AT_OPEN` 較接近，但 L4 未單獨測 |
| 3 | `v_Stop_Level` 棘輪的初始值 | `.pla` 沒把它列入空手重置清單（D-4），照抄了 |

**對齊是首要嫌疑**，因為那是 L4 相對 L2 唯一的新東西，而 L4 的偏差也比 L2 大。

## 對齊規則（目前採用的）

```
Data2 當根 = 最後一根 close_at <= 當前 Data1 的 close_at
```

所以 15M 的 09:00 看到的 Data2 當根是夜盤 05:00 那根，`[1]` 是 04:00。
到 15M 的 09:45（與 60M 09:45 同時收盤），Data2 當根才變成 09:45。

**這是最保守的規則**——任何更寬鬆的都會讀到未形成的 K 棒，那是未來函數。
L3 / L4 的標頭都沒說明 MC 的實際規則。

> 若 MC 更寬鬆，對帳會顯示筆數不同——**那是可觀測的**，
> 比默默讀到未來資料安全。

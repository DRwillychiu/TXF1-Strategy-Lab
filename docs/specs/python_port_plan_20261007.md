## 三、逐一校正的順序

- 模組：M1 → M2 → M3 → M4 → M5、M6 → M7 → 每支整支回測對 MC
- 策略：L2 → L4 → L3 → L5 → L1
  - L2 單一資料序列、Python 已完成 v5.4，最容易
  - L1 有 IOG，最難，放最後
- 每支「完成」的定義：預設參數全期回測，筆數、進出場時間、價格與 MC 報表 100% 相同；有差異逐筆歸因，不能歸因不算完成。
- 第二層（之後）：同一套程式改吃錄製系統的資料，差異只能來自資料源。

# spec_L3_R2 — L3 停損等比例 ＋ 盈虧比

> 討論定案：2026-09-23｜狀態：設計定案、兩項待決（§4）

## 1. 為什麼改（歸因，六年回測）
- 172 筆停損中 140 筆（81%）5 個交易日內回到目標價——被震盪洗掉，不是看錯方向
- 同一時段內進出的單虧（夜進夜出 −44,380），撐到下一時段的單賺（夜進日出 +126,360）
- 極端波動期 L3 並未虧損（10 日定義下仍為正）
- 最大回撤 2026/5/29–9/10：18 筆 2 勝

## 2. 設計（已定案）

| 項目 | 設計 |
|---|---|
| 停損位置 | 箱底下方「箱寬 × X%」；X 在 MC 掃 10%–50%，取高原中間 |
| 單筆範圍 | 進場價 0.33%–0.98%；另加帳戶 3%（9,000 元）硬上限 |
| 太窄 | 放寬到 0.33% |
| 太寬 | 停損位不動，改在「停損位上方 0.98%」處進場（跌破後站回的方式不變） |
| 目標價 | 維持現行算法（近 80 根高點與箱頂取低者）；記錄目標類型研究盲點 |
| 盈虧比門檻 | 預設 2.0，同時測 1.5、2.5（確認不是尖峰）；用「進場價到新停損」計算 |
| 連虧暫停 | 2 筆為主；另測「依盈虧比」（2020–2023 算、2024–2026 驗，後段也過才採用） |
| 停用線 | L3 回撤達 30,000 元（1,500 點） |
| 極端波動 | 近 10 日平均震幅 > 過去一年單日震幅中位數 2 倍 → 只發警示，照常交易 |
| SL_Pct（規範 #12） | 保留，當上限 0.98% 使用：超過時改進場位置，不壓縮停損 |
| 箱體品質（2026-09-23 加入） | 邊界確認：箱頂與箱底各至少被碰觸 2 次（60 分K 的高／低進入邊界容差內）；排除單根影線定邊（若邊界只由一根 K 棒的影線造成，取次高／次低）。以 `Box_Touch_Min`、`Box_NoWick` 兩個開關控制，可單獨關閉以比較 |
| 箱體記錄 | 每筆進場記錄：箱頂、箱底、箱寬（點／%）、成箱時間、箱齡、上下緣碰觸次數、邊界是否為單根影線、目標類型、計畫盈虧比 |

## 3. 驗收
- 帳戶回撤 ≤ 10%、淨利跌幅 ≤ 30%
- 交易次數不得低於基準的 50%（樣本足夠才有統計意義）
- G1、G3、五件套（≥ 4/5）
- 不以績效挑參數：窗口、X、盈虧比都要在高原上

## 4. 已決（2026-09-23）
1. 箱體記錄併入新版，第一次 MC 就產出
2. 箱體定義本次就改：邊界至少碰 2 次、排除單根影線——理由：箱體必須被確認，不能「看起來像箱子就當箱子」

## 4b. 一次改兩件事的隔離辦法
- 四種組合各跑一次，才分得出是誰造成差異：
  | 組合 | 箱體品質 | 新停損 |
  |---|---|---|
  | 基準 | 關 | 關（＝上架版本，G3 對帳） |
  | A | **開** | 關 |
  | B | 關 | **開** |
  | C | 開 | 開（正式候選） |
- 預期副作用：箱體變嚴 → 成箱次數與交易次數下降；若 C 的交易數低於基準的 50%，樣本不足，需回頭放寬碰觸次數

## 5. 箱體現行定義（供檢查）
- 60 分K 前 16 根最高、最低為參考區間；目前 60 分K 在區間內且高低幅 ≤ 區間 10% → 凍結成箱
- 60 分K 收盤出箱即失效；箱寬需 ≥ 15 分K ATR × 8.5
- 盲點：不看邊界碰觸次數、單根影線可定邊、跨日夜盤、高波動難成箱、8.5／0.50／80 為最佳化值

## 三、Portfolio 級共通痛點（**所有策略都失分**）

### 🔴 痛點 #1：跨策略相關性從未計算（維度 3 全 1 分）

**問題**：我們有 6 隻策略，但**從未算過彼此的相關係數**。
**意涵**：
- 可能 L1 + L5 + S1 在多頭年同時大賺 → 多頭年帳戶超漲
- 可能 L2 + L4 在熊市同時大虧 → 熊年帳戶超跌
- **portfolio 整體 Sharpe 可能比預期低很多**

**機構級必做**：6×6 相關矩陣（30 對組合）。

### 🔴 痛點 #2：Walk-Forward 從未做（維度 6 全 1 分）

**問題**：所有策略都用「過去 6 年完整資料」回測 + 優化。
**意涵**：
- 可能 inputs 是 **過度擬合**
- 真實 OOS (Out-of-Sample) 可能表現大幅衰退
- 不知道策略 robustness

**機構級必做**：
- IS 2 年 / OOS 6 個月滾動
- 每隻策略產出 WFE 數字
- WFE < 50% → 該策略不該上 live

### 🟡 痛點 #3：三市況 PF 未獨立計算（維度 7 普遍偏低）

**問題**：只看「全期間 PF」，沒看「bull/bear/range 各自 PF」。
**意涵**：
- L4 全期 PF 1.41 但 2022 熊年虧 -51K = **bear PF 可能 < 0.8**
- L3 全期 PF 1.17 但 2021 多頭年虧 = **bull PF 可能 < 1.0**
- 一隻策略**只在 1/3 市況有效** = 機構不接受

**機構級必做**：每隻策略拆 bull/bear/range 計算 PF。

## 六、Portfolio Top 3 P0 優化路線（接下來該做）

### 🔴 P0-1：跨策略相關性矩陣（**最高優先**）

**內容**：
- 計算 6×6 daily PnL correlation
- 找出 > 0.7 的高相關對
- 評估 portfolio 整體 Sharpe vs 個別 Sharpe

**預期發現**：
- L1 + L5 高相關（兩個 Long trend）
- L1 + S1 中相關（多單方向）
- L2 + L4 中相關（兩個 Short）

**改進**：若 L1+L5 相關 > 0.7 → 倉位減半（避免重複曝險）

**時間估計**：2 小時（寫腳本 + 分析）

### 🔴 P0-2：Walk-Forward 全策略驗證

**內容**：
- 6 隻策略各跑 WFA
- IS 2 年 / OOS 6 個月
- 計算 WFE
- WFE < 50% → 該策略警示

**預期發現**：
- L3 / L4 可能 WFE < 50%
- L1 / L5 / S1 可能 > 60%

**改進**：低 WFE 策略**降倉位**或**警示用戶**

**時間估計**：4-6 小時（需要寫 WFA 框架）

### 🔴 P0-3：三市況 PF 拆解

**內容**：
- 識別 2020-2026 期間的 bull / bear / range 區段
- 每隻策略在各市況下計算 PF / 淨利
- 找出「**靠單一市況救命**」的策略

**預期發現**：
- L4 全靠 2025-04 黑天鵝
- L1 / L5 全靠 2024-2026 牛市
- L3 可能無一市況強

**改進**：明確標記「**這策略依賴 X 市況**」進 portfolio rotation 邏輯

**時間估計**：3-4 小時

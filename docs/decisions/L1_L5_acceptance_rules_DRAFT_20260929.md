# L1、L5 優化驗收規則（草案，2026-09-29，待 Willy 鎖定）

> 規則必須在看到任何 L1／L5 優化結果之前鎖定。鎖定後改規則＝重新開始。

## 1. 對照組與樣本
- 對照組：L1_0（上架版 V3.1）、L5_0（上架版 v19.9），跑到 2026-09-24 13:45，設定和既有上架版報表相同
- 上架前：L1 2019-12-19 ～ 2026-06-16；L5 2021-09-16（報表起點）～ 2026-06-16
- 上架後：2026-06-17 ～ 09-24（只能驗證，不能挑參數）
- 雜訊帶：對照組上架前「平均一筆虧損單」（MC 金額），L1_0／L5_0 到齊時計算並寫入本檔

## 2. 門檻（沿用 L3 2026-09-27 19:24 版，全部要過）
1. 上架前最大連虧金額、前三大連虧平均，**兩項都比對照組小**，至少一項小超過一個雜訊帶
2. 上架前淨利跌幅 ≤ 15%
3. 上架後最大連虧，好超過一個雜訊帶

## 3. 獲利結構不變（新增，依 repo 鐵則 portfolio-role-design R1、R2）
- L1：對照組上架前**前 20 大**獲利單；L5：**前 10 大**（L5 筆數約 L1 的三分之一）
- 挑戰者要**參與 ≥ 90%**：同一個交易日有進場即算參與
- 這些單在挑戰者裡的合計獲利 ≥ 對照組的 90%
- 依據：L1 前 10 大獲利單 = 上架前淨利 87%，前 20 大已超過淨利（V3.0 報表線索，L1_0 到齊後重算）；大行情缺席比 PF 下降更嚴重

## 4. 排名
- 通過門檻的版本之間：規則 B（樣本外優先：最大連虧和淨利都較好，至少一項好超過一個雜訊帶才勝出；反向則現任留任）；分不出勝負 → 規則 E

## 5. 程式
- 先寫「文字語意 → 程式」對照表，再寫程式；語意檢查＋突變測試＋獨立審查通過才交給 MC
- 「跳過一筆」一律用虛擬單寫法（v19.3 教訓）
- 單一改動先測，再測組合（L3 v18 教訓：單獨都不好、合起來才好）

## 6. 已知限制
- L1 既有報表未開 1 分鐘 Bar Magnifier，但 V3.0 起程式要求逐筆回測；L1_0 先用和既有報表相同的設定，另跑一份開 Magnifier 的作為落差檢查（選做）

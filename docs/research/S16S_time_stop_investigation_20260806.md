> 這次調查的價值不在找到更好的參數，而在**證明現行值是對的，而且知道為什麼**。

## 1. 調查起因

使用者提出兩個問題：

1. 已經有「快速停損（時間）」（4 根且無獲利），為何還需要「時間停損」（24 根）？
2. 如果 24 根之外行情繼續下殺，是不是連二次進場也吃不到？

查證發現：**`M8_On = false`（完全不設限）從未被測過。**
2026-07-18 的掃描只涵蓋 12 / 24 / 36 / 48，全是有限值，
且當時是 v1.4-BELATE、109 筆交易，**凍結 ATR、True BE、百分比停利、結構停利全部不存在**。

## 7. 結構限制：不是時間，是「時間上限 ＋ 洗盤式再進場」的組合

再進場條件（`S16_S_MACrossShort_v1.14.0.pla` 第 1112-1122 行）：

```
MarketPosition        = 0
v_ReEntry_Armed       = True
v_ZLEMA_Fast          < v_ZLEMA_Slow      { 空頭結構仍在 }
v_Slope               > MinSlope           { 仍在陡跌 }
Close                 >= v_ReEntry_Price   { ← 關鍵 }

v_ReEntry_Price = v_Last_EntryPrice        { 原始進場價 }
```

**再進場要求收盤價回到原始進場價之上。**

緩跌趨勢中 24 根出場後，價格在進場價**之下** → 條件恆假 → **再進場無法武裝**。
而快線早已在慢線之下 → **新的死亡交叉也不會發生**。

**結果：持續緩跌中，24 根出場後這支策略完全無法再進場，直到價格漲回原進場價。**

### 7.1 兩種再進場設計互斥

| 設計 | 觸發條件 | 用途 |
|---|---|---|
| **洗盤回補**（現行） | 價格洗回原進場價 | 抓假突破後的二次機會 |
| **續勢加碼**（未實作） | 價格再破新低 | 抓趨勢的第二段 |

**兩者在數學上互斥，不可能塞進同一支策略。**
要吃續跌，必須是另一支獨立策略。

### 7.2 這是角色邊界，不是缺陷

**S16_S 抓的是「動能爆發的頭段」，不是「趨勢」。**
24 根的持倉上限（動能爆發 2 小時自解）與洗盤式再進場（等回補再空一次），
兩個設計指向同一件事。

**緩跌趨勢明確落在其設計範圍之外。**
依組合角色設計原則，單一策略不需要抓到所有行情 ——
緩跌趨勢應由另一支策略覆蓋，而不是把 S16_S 改成什麼都想抓。

## 8. 一個必須在 promote 前解決的矛盾

無限制版有兩個反直覺的數字：

| 指標 | 24 根（現行） | 無限制 | 誰好 |
|---|---|---|---|
| 淨利 | 2,670,800 | 2,393,200 | 24 根 |
| 最大回檔（金額） | −575,200 | −737,600 | 24 根 |
| 最大回檔（百分比） | −23.07% | **−22.23%** | 無限制 |
| **夏普比率** | 0.1402 | **0.1690** | **無限制** |

**夏普高 20%**：持倉拉長把獲利攤平到更多月份，大小月落差變小、月報酬波動度下降。

**回檔百分比較低但金額較高**：兩個版本的最大回檔發生在**不同時點、不同權益水位**，
無限制版那筆發生在權益較高時，除下來百分比就低。
**絕對金額與百分比在此指向相反方向，兩者皆非錯誤，量的不是同一件事。**

## 10. 效力範圍聲明

進場門檻固定 28 點｜回測 2020–2026｜有效樣本集中於 2026 年 1–7 月
（佔 76% 筆數、92.4% 淨利）｜傳統模式、細部資料停用｜固定 2 口｜滑價 1,000 元／口／邊。

24 根上限使窗口幾乎從不真的滾動，`Struct_Lookback >= 25` 因此等價。
**任何未來變更 `MaxHoldingBars` 的動作，必須連帶重驗 A2 的「20 根最佳」結論。**

## 3. 發現

### E-1 ★ 結構性缺陷：時段第一根的斜率閘門形同虛設

**機制（計算上的必然，非統計相關）**

```powerlanguage
v_Slope = v_ZLEMA_Fast[1] - v_ZLEMA_Fast
```

在時段第一根，`[1]` 指向**上一個時段的最後一根**。隔夜 3 小時 45 分的跳空
被整包當成「一根 K 棒的斜率」，`MinSlope = 28` 無法過濾。

**MC 戳記慣例（先釘死）**

全樣本日盤最早進場 08:55、夜盤最早 15:10，皆無更早者
→ MC 以**收盤時間**戳記 → 這些成交來自**該時段第一根**發出的訊號。

**證據**

| | 這 17 天 | 全體 1,599 交易日 |
|---|---|---|
| 跳空中位數 | **−1.108%** | +0.022% |
| \|跳空\| 中位數 | 1.108% | 0.174% |
| **向下跳空占比** | **17 / 17 = 100%** | 44.7% |

隨機 17 連中的機率 ≈ **4.7 × 10⁻⁷**。

| 項目 | 數值 |
|---|---|
| 損益 | **−393,200** |
| 勝率 | 11.8%（全樣本 27.9%） |
| 出場標籤 | 14/17 走快速停損 |
| 年度分布 | 2020(2) ／ 2022(2) ／ 2024(2) ／ 2025(4) ／ 2026(7) |

**進場端第一個非 2026 集中的發現。**

### E-2 第一根的方向把結果切乾淨

`第一根開→收 = 進場價 − 時段開盤價`（08:55 成交 ≈ 08:50 那根的收盤）

| 第一根 | 筆 | 損益 | 勝率 | MFE 中位 | MAE 中位 |
|---|---|---|---|---|---|
| **收在開盤之上** | **10** | **−379,600** | **0.0%** | 79 | **−122** |
| 收在開盤之下 | 7 | −13,600 | 28.6% | 38 | −56 |

10 連敗在 27.9% 基準勝率下的機率 ≈ 4%。
**唯一大贏家 +149,200 落在「收在開盤之下」組。**

**橋接（第一根方向 → 整段路徑，零交叉污染）**

| 第一根 | 續跌 | V轉 | 續漲 | A轉 | 震盪 |
|---|---|---|---|---|---|
| 收在開盤之上 | **0** | 0 | 5 | 2 | 3 |
| 收在開盤之下 | **3** | 0 | **0** | 1 | 3 |

### E-3 夜盤同樣需要處理（使用者裁示 2026-08-08）

| | 中位 \|跳空\| | 95 分位 | **最大** | 第一根進場筆數 |
|---|---|---|---|---|
| 日盤 08:45 | 0.174% | 0.919% | **8.11%** | 17 |
| 夜盤 15:00 | 0.072% | 0.377% | **7.30%** | 1 |

夜盤跳空幅度僅日盤四成，**但尾部厚度同級**。現行樣本只有 1 筆是頻率問題，
不是結構免疫。濾網做成雙時段對稱。

| 年 | 平均進場價 | 28 點相當於 | 筆數 |

同一閘門在 2020 比 2026 緊 4.2 倍。129 筆裡 76% 落在 2026。
**本版不處理** —— 它改變整個交易母體，會與缺口濾網的歸因互相污染。

## 5. K 棒型態：18 型 MECE 分類

一根 K 棒的形狀由 `(O,H,L,C)` 完全決定。令 `R = H − L`：

```
body + upper shadow + lower shadow  ==  1     (恆等式)
```

形狀空間 = 二維單體 × 方向位元。判定樹依 `body` 四分再依影線比例三分，
故任一 K 棒恰對應一型。**實測 3,198 筆全數歸類、18 型全出現、零重複。**

| 代碼 | 型態 | 日盤 | 夜盤 |
|---|---|---|---|
| T1 / T2 | 長實體（漲／跌） | 9.8% / 7.1% | 11.4% / 6.1% |
| T3 / T4 | 中實體下影主導 | 10.3% / 9.2% | 13.0% / 9.6% |
| T5 / T6 | 中實體上影主導 | 7.8% / 7.1% | 8.0% / 5.3% |
| T7 / T8 | 中實體雙影均衡 | 9.8% / 9.7% | 9.2% / 8.9% |
| T9 / T10 | 小實體下影主導 | 3.3% / 5.1% | 4.4% / 3.7% |
| T11 / T12 | 小實體上影主導 | 2.8% / 3.0% | 2.4% / 2.8% |
| T13 / T14 | 小實體雙影均衡 | 6.2% / 5.0% | 5.3% / 4.9% |
| T15 / T16 / T17 | 十字（下影／上影／均衡） | 1.2% / 1.1% / 1.6% | 1.3% / 0.9% / 2.8% |
| T0 | 一字線 | 0.1% | 0.0% |

### 五組處置分類（交叉驗證後修正）

初版有 **7 處指派錯誤**，根因是組名講「影線」、指派卻按「顏色」——
兩個正交的軸被混用。修正後改用**單一準則：下檔有沒有被買回**。

|---|---|---|---|---|---|
| 甲 收在低點・賣方全控 | 下跌 ＋ 無明顯下影 | T2 T6 T12 | 17.2% | 14.1% | 放行 |
| 乙 探底後仍收跌 | 下跌 ＋ 有下影 | T4 T8 T10 T14 | 29.0% | 27.2% | 放行 |
| 丙 多空平衡 | 十字／一字 | T15 T16 T17 T0 | 4.0% | 4.9% | 待驗 |
| 丁 未探底即收漲 | 上漲 ＋ 無明顯下影 | T1 T5 T11 | 20.3% | 21.8% | 封鎖 |

MECE 驗證 18/18。**組內排序（丁 vs 戊、甲 vs 乙）目前純屬假設。**

### ★ 方法論警告：同棒統計是循環論證

用一根 K 棒自己的 OHLC 算出的任何統計量（開→收、開→最低），
都被該棒的分類定義所決定。**「上漲K的開→收為正」是恆真，不是實證。**

**非循環的證據只有兩類：**

1. 各型態的**發生頻率**（純計數）
2. **第一根的型態 → 第 2~N 根的走勢**（損益來自被分類的那根之後）

第 2 類需要 5 分 K 資料。本文件中所有「型態 → 效果」的陳述，
除 §3 E-2 那張表（用實際交易損益）外，一律只到**假設**層級。

## 6. 訊號／成交錯位規則（repo-wide，本日確立）

```
本檔所有進場都是 next bar 單：第 N 根的訊號產生第 N+1 根的成交。
第 N 根送出的單無法在第 N+1 根撤銷，因此任何意圖阻止成交的規則，
必須在它所保護的那根之前一根評估。

=> 每個時間／根數 input 必須在自己的註解裡寫明它指的是訊號棒還是成交棒。
```

| 參數 | 合規 | 說明 |
|---|---|---|
| `Gap_Scope_Bars` | ✅ | 註解已寫明：抑制訊號於時段第 1..N 根，故無成交於第 2..N+1 根 |
| `Tail_LastEntry_Time` | ❌ | 名為進場時間，實際管訊號棒。430 允許 04:35 成交（2026-03-07 實例），且 `Tail_ForceExit_Time = 440` 使該筆只活 2 根 |

`Tail_LastEntry_Time` **刻意不在 v1.16.0 修正**，以保持缺口濾網的歸因乾淨。排 v1.17.0。
修正寫法（HHMM 不可直接加減，`500 − 5 ≠ 455`）：

```powerlanguage
v_Tail_Signal_Cutoff = MinutesToTime( TimeToMinutes( Tail_LastEntry_Time )
                                      - BarInterval );
```

## 8. v1.16.0 濾網定義

```
在時段第一根評估，抑制該根的進場訊號（故第二根不會成交）：

  跳空  = (Open - Close[1]) / Close[1] * 100  <=  -Gap_Down_Min_Pct
  且  第一根漲幅 = (Close - Open) / Open * 100  >=  Gap_Rise_Min_Pct
```

| 參數 | 預設 | 依據 |
|---|---|---|
| `Gap_Filter_On` | **False** | repo 慣例，新機制一律 OFF 上線 |
| `Gap_Day_On` / `Gap_Night_On` | True / True | E-1 證據在日盤；夜盤依 E-3 裁示對稱處理 |
| `Gap_Down_Min_Pct` | **0.30** | 一階掃描 0.10~0.50 完全等價（高原正中）。角色是穩定性護欄 |
| `Gap_Rise_Min_Pct` | **0.00** | 一階掃描單調遞減，0 最佳。比較用 `>=`，故 0.00 亦封鎖收平的 K 棒 |
| `Gap_Scope_Bars` | **1** | 斜率汙染的機制邊界：第 2 根起 `[1]` 已是同時段 |

**為什麼用方向測試而非時間封鎖**

| 方案 | 封鎖 | 一階估計 | 最大贏家 |
|---|---|---|---|
| 封鎖時段第一根（純時間） | 17 | +393,200 | **被砍掉** |
| **只封鎖收在開盤之上** | **10** | **+379,600** | **+149,200 保留** |

97% 的效益、59% 的封鎖量，且保住整個「跳空續跌」的贏家類別。
依 `portfolio-role-design` 鐵則（抓該賺的行情、小虧大賺），取後者。

**本版不處理的事**

2026-07-17 整段跌 3.45%、第一根收在開盤之下，**濾網放行，仍虧 85,200**。
進場後先逆行 331 點觸發快速停損才反轉。**方向對、時機錯 ——
屬於 QuickStop 容忍度，不屬於缺口。不假裝這個濾網能處理它。**

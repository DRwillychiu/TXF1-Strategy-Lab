## 裁示 2 — 三向細分保留，但量法要換

分類保留（型態確實分上／下／水平），**問題在現行量法測到的是「哪種樞紐收尾」**。

### 四個候選與判準

判準：**描述市場的量法，兩種排列應給出一致分布。**
另跑虛無對照（只要求交替、不要求外擴，n = 29,718）當基準。

| 量法 | P29 差距 | 虛無基準 | 超額 |
|---|---|---|---|
| M1 中點漂移（現行） | 32.5 pp | 5.3 | +27.2 |
| **M2 兩條趨勢線斜率平均** | **21.9 pp** | 3.5 | **+18.4** |
| M6 中間四樞紐 | 18.2 pp | 8.9 | +9.3 |
| M7 進入型態前的走勢 | 18.9 pp | 1.9 | +17.0 |

*M4「相鄰配對中點」與 M1 代數上相同（172/172 同號），已淘汰。
M3 與 M2 同號 172/172，取較易解釋的 M2。*

### ★ 最重要的結論：差距下不去，因為排列本身就是資訊

**四個量法的差距都落在 18-32 pp，而虛無基準只有 2-9 pp。**

這不是量法沒選好。**單調外擴這個要求本身保證了「最後一個樞紐必為整段最極端」** ——
以新低收尾與以新高收尾，本來就是兩個不同的市場狀態。

### 定案

| 項目 | 決定 |
|---|---|
| §3 量法 | **M2 兩條趨勢線斜率平均**（每根點數，時間正規化） |
| §3 分類 | **六格，不是三格**：{先高, 先低} × {上升, 下降, 水平} |
| 為什麼六格 | 排列是混淆因子。**把它攤開來當分類的一部分，比藏在合計裡誠實。** |

```powerlanguage
{ M2：兩條邊界線的每根斜率平均 = 通道中心的漂移率 }
v_SlopeUp  = ( PH[1] - PH[3] ) / ( BarOf_PH1 - BarOf_PH3 );
v_SlopeDn  = ( PL[1] - PL[3] ) / ( BarOf_PL1 - BarOf_PL3 );
v_P29_Drift = ( v_SlopeUp + v_SlopeDn ) / 2;

if v_P29_Drift > 0 then      v_P29_Dir =  1     { 上升擴散 }
else if v_P29_Drift < 0 then v_P29_Dir = -1     { 下降擴散 }
else                         v_P29_Dir =  0;    { 水平擴散 }

{ 分類必須連同排列一起報 }
v_P29_Order = 1;                      { 1 = 先出現高，以樞紐低收尾 }
if <第一個樞紐是低> then v_P29_Order = 2;   { 2 = 先出現低，以樞紐高收尾 }
```

### M2 下的六格分布（n = 172）

| 排列 | n | 上升 | 下降 | 水平 |
|---|---|---|---|---|
| 先出現高（以樞紐低收尾） | 91 | 37.4% | 61.5% | 1.1% |
| 先出現低（以樞紐高收尾） | 81 | 59.3% | 40.7% | 0.0% |
| **合計** | **172** | **47.7%** | **51.7%** | **0.6%** |

## ★ M7 不用在 §3，它是 P49／P50 的分辨器

M7（進入型態前的走勢）是 Bulkowski 原本區分**擴散頂 vs 擴散底**的方式。

**若 §3 也用 M7，§3 就和 P49／P50 變成同一件事，P29 的三向細分等於重複。**

| 段 | 量什麼 | 用哪個 |
|---|---|---|
| §3 三向細分 | 型態**內部**的通道漂移 | **M2** |
| P49／P50 | 進入型態**之前**的走勢 | **M7** |

**兩者測不同的東西，不重疊。** M7 保留給 P49／P50 使用。

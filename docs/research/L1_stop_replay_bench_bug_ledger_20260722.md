## BUG 帳本

### B1 — 重播不模擬「停損後再進場」 [OPEN / 結構性]
- **內容**: 內層停損踢出交易後, 實盤 L1 會在下一次突破訊號重新進場 (再進場 EV +100 pts/筆)。重播對被殺贏家計全額機會成本, 補償計零。
- **影響**: 所有 34+ 變體的否決值系統性偏悲觀。
- **翻案潛力**: 唯一可能翻案者 = B swing N=3 stop 版 (July -279 vs -2,038, MDD -522, 但表面 -5,966)。若 137 個被殺贏家的再進場能回收大部分獲利, 結論可能翻轉。
- **終審手段**: MC12 原生回測 (自動含再進場) — 這是離線重播的原理性極限。

### B2 — 執行模型錯配 (A/B 家族) [CONFIRMED → FIXED]
- **內容**: 棒低點/swing low 實務是 intrabar stop 單, 重播卻用「收盤確認 → 次根開盤」→ 出場價系統性偏差。與自己寫的 L34 教訓自相矛盾。
- **修復**: `replay_stop2()` intrabar 觸發 + 跳空開盤成交。
- **重跑結果**: A 家族 -1,904~-2,435, B 家族 -5,857~-5,966 → **否決維持** (但 B N=3 的 MDD -522/July -279 是全場最佳風險端數字, 掛 B1 待 MC12)。

### B3 — MC MAE 慣例誤解 [CONFIRMED → RESOLVED]
- **內容**: 初版交叉驗證 93-112 筆誤差 >30 pts, 最大 1,236 — 疑似資料錯位。
- **鑑定**: MC 的最大可能虧損 = **不含出場棒的 intrabar lows + 以實際出場價為 floor + 固定 5 pts 成本**。套用後 456/456 誤差恰好 = 5 pts (0 筆 >30)。進場價 456/456 精確 = 進場棒開盤價。
- **結論**: 測試台資料完整性經獨立驗證成立。**副作用發現**: MC MAE 在跳空出場棒上低估真實 excursion → 任何以 MC MAE 為基礎的模擬都繼承此低估。

### B4 — MAE 模擬的幻想成交 [CONFIRMED → V2.9 致命]
- **內容**: §2.3/2.4 的 cap 模擬假設「MAE > cap 的交易能在 cap 價位出場」。真實路徑顯示深 MAE 事件多為跳空/崩盤棒 — tighter stop 的實際成交價與 ATR 停損幾乎相同 (同一根棒的跳空開盤價)。
- **修正後**: 1.2% clip 以 stop 單重播 = **+23 pts / 6.5 年觸發 1 次** (原宣稱 +600)。
- **裁決**: **V2.9 per-trade 災難斷路器提案死亡**。殘值僅剩「連續陰跌型黑天鵝」保險 (2021-05-12 型), 無 EV 主張, 不值得動 live 程式碼。

### B5 — 出場棒排除偏誤 [CONFIRMED → FIXED]
- **內容**: 重播把原始出場棒排除在內層評估外 — 盤中連續下跌棒上, tighter stop 會在 ATR 停損之前先成交, 此節省被忽略 (反方向 bug, 偏袒否決結論)。
- **修復**: 出場棒參與 + `level > x_price` guard + 跳空同價處理。
- **重跑結果**: A/B July 節省擴大, 但總帳仍全負 → 否決維持。

### B6 — SP 重播模型殘差 [OPEN / 已量化]
- **內容**: SP 網格的自我驗證錨點 (原參數 500/45%) 重播應零變化, 實測 -269 pts / 10 筆偏差 → 我的 P7 模型與 MC 實作存在細節差異 (peak 更新時序/掛單時點)。
- **處置**: 所有 SP 網格數字帶 **±300 pts noise floor** 解讀; 終審以 MC12 為準。

### B7 — SP 網格訊號的 2026 集中度 [OPEN / 穩健性紅旗]
- **內容**: 500/70% 的 +1,948 中, **+1,688 (86.6%) 來自 2026 單一年**; 前六年合計僅 +259。且 75% 是懸崖 (+11, #431 從 3,342 被剪到 1,322)。
- **風險**: recent-bias / 少數事件擬合 — 與 S8/S9 被 KILL 的 pattern (L23) 同構。
- **處置**: 列為 PLAUSIBLE 候選, 只可經 MC12 一鍵 A/B (profitReturnPrcnt_Long 55 → 35/30) + 分年檢視後再議, 不得直接上 live。

## 追加 Lesson (2026-07-22 深夜, V2.9 定案討論)

- **L37**: 引擎內建函數攜帶「隱藏預設語義」(SetStopLoss 金額預設 per-position 基準), 在 1 口回測中與正確語義數學上不可分辨, 只在實盤口數 != 1 時引爆。凡跨語義域借用工具 (金錢工具模擬價格停損、MaxList 作用於價格 vs 距離), 必須: (a) 顯式宣告基準 (SetStopContract), (b) 驗證器斷言語義而非公式形狀, (c) 在 spec 中記錄隱藏假設。程式碼的「形狀」不攜帶「語義」— 這是本日兩大 BUG (MaxList 取腿、per-position 砍半) 的共同病根。

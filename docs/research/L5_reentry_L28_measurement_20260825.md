## 5. 附：L3 `CL_ReEntry` 的統計檢定（回答 2026-08-25 提問）

**問題**：L3 的二次進場在回測賠錢，但未來實戰未必賠，對嗎？

**答：對，而且統計上很明確。**

```
CL_ReEntry    n=49   平均 -6,049   標準差 106,187   標準誤 15,170   t = -0.40
95% 信賴區間  -35,781  ~  +23,684        <- 跨過 0
兩樣本 vs CL_Entry   平均差 -12,025   t = -0.77   <- |t| < 2
置換檢定 20,000 次    p = 0.3111              <- 不顯著
```

> **「L3 的二次進場會賠錢」在統計上不成立。**
> **49 筆的平均值與 0 分不開，也與主進場分不開。**

### 5.1 但反方向也要講清楚

```
去掉最大一筆（+381,200）之後：n=48，淨 -677,600
分布：MIN -106,400  P25 -78,000  MED -40,000  P75 +42,400  MAX +381,200
```

**那個接近零的平均值是靠一筆撐起來的。**

> **正確說法：高變異，不是穩定賠錢——但同樣也不是穩定賺錢。**
> **49 筆這個樣本量，任何方向都下不了判決。**

**這與今天 K 棒研究的結論一致**：不能靠「它賠錢」就砍，
**因為統計上它根本沒被證明賠錢，而砍掉的代價（淨利 −19.8%~−28.7%）卻是實測的。**

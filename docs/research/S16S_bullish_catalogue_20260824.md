### 4.1 代碼落在 31-33 而不是插進 16-28

29/30 是中性對（內含線／外包線），下游每一份腳本與文件都以這兩個號碼為鍵。
重新編號的代價遠大於把 `v_KB_BullNow` 改寬。

### 4.2 ★ 多頭 Hikkake 刻意**不是**純鏡像 —— 這是本次唯一的判斷取捨

D47 空頭 Hikkake 只檢查**極值**（`L < L[3]`）。純鏡像就是 `H > H[3]`，
也就是「最高價曾經穿越」即算數。實測結果：

```
極值版          6,749 次，其中 1,925 次（28.5%）落在黑棒上
收盤確認版      4,035 次
```

其中一次是 **`2026-04-08 21:55`，O 35335 → C 35212，跌 123 點的黑棒**，
而且它正是 187 根進場訊號棒之一。

**在那種棒上以「多頭反轉」為由平掉空單，站不住腳。** 因此採**收盤確認**。

副作用（正面）：改用收盤確認後，**三個新型態在 187 根訊號棒上的額外否決數 = 0**，
172 筆 / 2,265,200 錨點完全不動。極值版會動 1 筆。

> ⚠️ **D47 空方 Hikkake 有同樣的洞**（可能在一根大紅棒上被判為空方結構）。
> 它在 `KB_Entry_Mode = 0` 下完全惰性，不影響任何現行數字，**故本次不動，列為待裁示**。

### 4.3 三明治**不進**出場集合 —— 第二個判斷取捨

三明治的完成棒依定義是**黑棒**（實測 3,331 / 3,331，100%）。
用戶要的是「**非常強勢的**反轉多頭結構」，一個收黑的型態是**支撐測試**，不是那個。

**它仍然透過 R1 擋進場**，在那裡的意思是「不要往一個剛守住兩次的價位放空」。

**用戶原話舉的例子是「連三紅」= 三白兵，它只佔 2.4%。
實際會觸發的，97% 是三內部上漲與三外部上漲。**

### 觸發頻率的實際意義

```
單根命中率 6.02%（含 Hikkake 6.70%），平均持倉 12.3 根
=> 一筆交易期間至少遇到一次的機率 = 53.4%（含 Hikkake 約 57%）
```

**Mode 2（不論賺賠都平）會打斷大約一半的交易。**
這正是 `SX_MA_TimeStop_Pct` 那 10 筆 / 2,479,200 的風險所在。
Mode 1（只在虧損時平）以結構保護尾巴 —— 大魚幾乎整段持倉都在獲利。

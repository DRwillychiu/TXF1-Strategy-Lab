## 1. 讀本文件前必須知道的三件事

### 1.1 閘門方向與教科書相反

```powerlanguage
v_KB_Block = ( v_KB_Code <> 0 );
```

**任何命中的型態都會擋掉進場——包含「支持空單」的型態。**
依據是規格書 §7.5 的量測：型態標記的是**比較差**的進場。

### 1.2 三個開關決定哪個家族有資格擋

```powerlanguage
v_KB_Sup = ( KB_Block_Support <> 0 );   { 代碼 1-13  支持空單 }
v_KB_Opp = ( KB_Block_Oppose  <> 0 );   { 代碼 14-26 反對空單 }
v_KB_Neu = ( KB_Block_Neutral <> 0 );   { 代碼 27-28 中性     }
v_KB_On  = ( v_KB_Sup or v_KB_Opp or v_KB_Neu );
```

**三個預設都是 0 → `v_KB_On = False` → 整段判定被跳過 → 退化錨點成立。**

### 1.3 先中先停，順序即優先序

每一條都是 `if v_KB_Code = 0 and ...`，依代碼 1→28 依序判定，**先命中者寫入代碼並終止**。

**規格書未定義優先序。** 對「擋不擋」無影響（任何非零都擋），
但影響「記錄成哪一個代碼」，因此影響逐一命中次數的統計。

## 2. 共用元件 — 9 項全部相符

所有元件在 `v_KB_On = True and v_Bars_In_Sess >= 2` 之內計算。

| 元件 | 規格書 | 程式碼 | 這一條在做什麼 |
|---|---|---|---|
| `Range` | `H - L` | `v_KB_R0 = H - L` | 全距，所有比例的分母 |
| `Body` | `AbsValue(C-O)` | `v_KB_B0 = AbsValue( C - O )` | 實體長度，不分方向 |
| `Top` | `MaxList(O,C)` | `v_KB_T0 = MaxList( O, C )` | 實體上緣。**孕線的包含判定用它，不是用 H** |
| `Bot` | `MinList(O,C)` | `v_KB_M0 = MinList( O, C )` | 實體下緣 |
| `UpSh` | `H[n] - Top(n)` ※ | `v_KB_S0 = H - v_KB_T0` | 上影線。**買方推高後被壓回的幅度** |
| `DnSh` | `Bot(n) - L[n]` ※ | `v_KB_N2 = v_KB_M2 - L[2]` | 下影線。僅 B37 用到，故只算第 2 根 |
| `長實體` | `Body / Range >= 0.50` | `( v_KB_R0 > 0 ) and ( v_KB_R0 >= KB_Pat_MinRange )`<br>`and ( v_KB_B0 / MaxList( v_KB_R0, 1 ) >= KB_Pat_LongBody )` | **保證參照根夠大，使「包住／突破」帶有資訊**。0.50 = 實體 ≥ 上下影線之和 |
| `十字` | `Body < 10% Range`<br>`and Range >= 3`<br>`and 上下影各 >= 1` | `( v_KB_R0 >= KB_Pat_DojiMinRange )`<br>`and ( v_KB_B0 / MaxList( v_KB_R0, 1 ) < KB_Pat_DojiRatio )`<br>`and ( v_KB_S0 >= KB_Pat_DojiMinShadow )`<br>`and ( v_KB_M0 - L >= KB_Pat_DojiMinShadow )` | 開收幾乎相同、兩側都有探測。**影線下限是為了排除全距很小的一字線** |
| `完全相同` | 差 0 點 | `H = H[1]` / `L = L[1]` / `C = C[1]` / `O = C[1]` | **不給容差。** 放到 1 點時符合的相鄰棒對從 9.95% 跳到 26.44% |

※ 規格書 §6 的記法行寫成 `UpSh(n)=H-Top(n)`、`DnSh(n)=Bot(n)-L`，**漏了索引**。
程式碼實作正確，要改的是規格書。

**`MaxList( R0, 1 )` 是除零保護。** TXF 最小跳動 1 點，`R0 > 0` 已保證 `R0 >= 1`，
故 `MaxList(R0,1) = R0` —— **不改變語意**。

**分層計算：** `R0/B0/T0/M0/S0/L0/L1/D0` 在 `>= 2` 算；`R2/B2/T2/M2/S2/N2/L2` 在 `>= 3` 算；
`R3/R4/B3/B4/L3/L4` 在 `>= 5` 算。**用到哪一層，該型態就必須被同層或更高層的閘門保護。**

## 4. 反對空單 — 13 種（代碼 14–26）

包在 `if v_KB_Opp = True then begin ... end` 之內。

> **除 A21（代碼 18）與 B37（代碼 22）之外，全部以紅棒收尾。**

# 重點說明

**一句話**：喇叭形出現在**一段上漲之後**是擴散頂，出現在**一段下跌之後**是擴散底。
**兩者的形狀一模一樣，差別只在型態出現前那一小時的走勢。**

## 與最相近型態的分界

| 對照 | 分界 |
|---|---|
| **vs P29 擴散三角** | P29 是母型態，**不帶方向**。P49／P50 是 P29 加上「前段走勢」這一個條件 |

## 為什麼這樣定義而不是那樣 —— 每一條都附對照量測

### ① 為什麼用「前 12 根最小平方斜率」而不是「端點差」

**M7 是分類器。同一個型態因為窗口挪一根就換邊，代表它分不乾淨。**

| 擾動 | 端點差 | **最小平方斜率** |
|---|---|---|
| 窗長 12 → 10/11/13/14 | 94 / 808 = **11.6%** | 57 / 808 = **7.1%** |
| **起點 ±1 根** | 41 / 404 = **10.1%** | 26 / 404 = **6.4%** |
| **恰為 0 的型態數** | **4**（需額外平手規則） | **0** |
| 最小非零值 | 1.0000 點 | 0.0055 點／根 |

**「起點挪一根」在實作上真的會發生**——樞紐在第 `i` 根成立、`i+1` 才確認。

### ② 為什麼母體是 202 不是 172

`s16s_p29_clean.py:72` 原本有一行 `one session only`，**那是 K 棒結構的規則被誤套到圖形型態上**。

```
只准同時段（舊）  172
允許跨時段（新）  202      +30，+17.4%
```

多出的 30 個**全部只跨 1 個邊界**，起始集中在 `04`（20 個）、`03`、`12`、`13`。
**起始小時涵蓋 17 → 19 個。**

### ③ 為什麼要先做三個檢查才敢用 M7

**2026-08-25 的 §3 三向細分被推翻，就是因為沒做這三個檢查。**

| 檢查 | M7 結果 | 被推翻的 §3 |
|---|---|---|
| 被「排列」污染？ | 差 **4.6pp**（雜訊 14.4pp） | **18.9～32pp** ❌ |
| 與 M2 重複？ | 同號 55.4%（獨立 50%） | — |
| 分派自帶偏差？ | 55.4% vs 隨機 **52.5%** | — |

**第三個最重要：P29 出現前的走勢和隨機挑一個時點沒有分別。
M7 把母體切開，但沒有偷偷塞進方向偏誤。**

# 操作邏輯

## 盤面意義

**喇叭形描述的是「分歧在放大」**——高點一個比一個高、低點一個比一個低，
多空雙方都不肯認輸，一次比一次用力。

**加上前段走勢之後意義才完整：**

| | 前段 | 意義 |
|---|---|---|
| **P49 擴散頂** | 漲了一小時 | 漲勢末端開始出現大幅來回，**買方推不動但還在推** |
| **P50 擴散底** | 跌了一小時 | 跌勢末端開始出現大幅來回，**賣方壓不下但還在壓** |

## 突破條件 —— 每一個細節都釘死

| # | 項目 | 釘死為 |
|---|---|---|
| 1 | 外推方式 | **E1**：通過最後兩個樞紐低（空方）或樞紐高（多方） |
| 2 | 用哪根的價 | **當根 `Close`** |
| 3 | 方向（P49 空方） | `Close < 下緣線值` |
| 4 | **相等算不算** | **不算**（嚴格小於） |
| 5 | **幾根確認** | **一根** |
| 6 | **突破幅度門檻** | **無**（純穿越） |
| 7 | **影線刺穿算不算** | **不算**，只看收盤 |
| 8 | 線能否跨時段外推 | **能**（擺盪幾何型） |
| 9 | **假突破（下根收回）** | **不撤銷確認** |
| 10 | 首次穿越 | `Close[t] < line_t` **且** `Close[t-1] >= line_{t-1}` |

## 有效期

**＝ 型態自己形成所花的根數**（中位數 12 根）。**自我指涉，沒有可調的 N。**

三種失效並存，全部零參數：**價格破壞** ／ **時間衰減（存活 > 形成）** ／ **反向型態出現**。

## ⚠️ 目前不能做的事

1. **不能說 P49／P50 能改善進場或出場。** 報酬**從未檢定**，也不應在用戶同意前檢定。
2. **不能引用 2026-08-24 那 33 個圖形型態檢定**作為任何設計依據——
   那 33 個定義是 Claude 自行發明、自行執行、事後回報的，用它否定設計是循環論證。
3. **不能拿開口大小設門檻。** 任何門檻現在都只能從這 202 個裡挑，那是對結果變數選擇。
4. **不能說 P49 比 P50 好或反之。** 兩者的差異從未量測。
5. **夜盤佔比高（P49 96/112、P50 77/90）尚未解釋**，母體本身就是 1:2.80，不可據此推論。

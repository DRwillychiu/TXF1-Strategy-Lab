# 重點說明

**一句話**：高點一個比一個高、低點一個比一個低，**波動整段向外擴張**，
市場在同一段時間裡同時往兩邊試，而且每次都試得更遠。

**它跟三角形正好相反。** 三角形是兩條線往中間收，代表分歧在縮小；
擴散是兩條線往外開，代表**分歧在放大**。多空雙方都不肯認輸，一次比一次用力。

### 三個必須知道的量測結果

**① Bulkowski 的「3 高 + 2 低」最低門檻是幾何陷阱**

| 定義 | 成立根數 | 佔比 | 上升 / 下降 / 水平 |
|---|---|---|---|
| **3 高 + 3 低（對稱，本專案採用）** | **6,238** | **1.480%** | **47.1% / 50.4% / 2.5%** |
| 3 高 + 2 低 | 25,123 | 5.960% | **75.5%** / 22.7% / 1.9% |
| 2 高 + 3 低 | 22,619 | 5.366% | 21.0% / **76.9%** / 2.0% |

**3+2 報「75.5% 上升」，鏡像的 2+3 立刻報「76.9% 下降」。**
要求三個墊高的高點卻只要求兩個下移的低點，**中點被機械性推高**。
這個數字與市場無關，是定義不對稱造出來的。**所以採對稱 3+3。**

**② 「用收盤價去雜訊」在 TXF1 5 分 K 上是反的**

| 樞紐基準 | 樞紐高數 | 佔全部棒 |
|---|---|---|
| 高／低價 | 74,411 | **17.65%** |
| 收盤價 | 92,170 | **21.87%** ← **更多** |

趨勢中高點連續墊高比較「黏」；收盤在區間內來回，反而製造更多局部極值。

**③ 三向細分在頻率上是硬幣**

47.1% / 50.4% / 2.5% —— **細分沒有在頻率上集中任何東西。
報酬未測，現在下任何結論都會是樣本內選擇。**

### 為什麼不用學界的平滑法

Lo, Mamaysky & Wang (2000) 的診斷成立（原始極值太多，我們實測 17.65%），
**但它的藥不能吃**：頻寬乘數 0.3 是肉眼調的，而且對稱核**需要未來的棒** ——
型態會在實盤上自己消失，不可交易。

**本專案的解法是用結構不用平滑**：要求三個樞紐單調外擴，
**15.60% → 1.48%，壓掉 90.4%，零參數。**

# 圖形示意圖說明

```
        PH1 ●                                    上緣：三個高點一個比一個高
           ╱ ╲          ← 上緣趨勢線（外擴）
     PH2 ●     ╲
        ╱ ╲     ╲
  PH3 ●     ╲     ╲
     ╱ ╲     ╲     ╲
────●───╲─────╲─────╲──────  中點漂移方向 = 三向細分的依據
         ╲     ╲     ╲   ╱
          ╲     ╲     ● PL3
           ╲     ╲   ╱
            ╲     ● PL2
             ╲   ╱          ← 下緣趨勢線（外擴）
              ● PL1              下緣：三個低點一個比一個低

時間 ──────────────────────────────────────►
```

**讀圖三個重點：**

1. **兩條線往外開，不是往內收** —— 這是擴散型態與三角形的唯一分界。
2. **必須三個高 ＋ 三個低，對稱** —— 兩點只能定線，第三點才確認方向持續。
   Bulkowski 原文：「至少五個觸點：三個峰或三個谷觸及對應趨勢線，另一條至少兩個」。
3. **中點連線的走向決定細分** —— 中點往上走是上升擴散、往下是下降擴散、平的是水平擴散。

**三向細分的外觀差異：**

```
上升擴散 47.1%          下降擴散 50.4%          水平擴散 2.5%
上緣升得比下緣快        下緣降得比上緣快        兩緣對稱外開
中點往上漂             中點往下漂              中點不動
```

# 操作邏輯

## 一、這個型態在盤面上是什麼意思

**波動在放大，而且是雙向放大。**
每一次往上都比上次高，每一次往下都比上次低 —— 沒有一方能收乾對方。

實務上這是**最難做的環境**：停損容易被掃，因為下一個低點按定義會比這個低點更低。

## 二、★ 用法：不是「事後認出來」，是「事前的價位地圖」

**這是 2026-08-25 用戶裁示的方向（裁示 3 = B），也是這份規格最重要的一點。**

傳統用法是等型態完成再反應 —— 但型態完成時，該走的已經走完了。

**改成事前算：手上有兩個樞紐高、兩個樞紐低時，下一個樞紐落在哪裡會完成哪個型態，
現在就算得出來。**

已知狀態：`PH[2] < PH[1]` 且 `PL[2] > PL[1]`，輸出兩個價位：

```
向上觸發位 = PH[1]        ← 下一個樞紐高若高過它，上緣確認外擴
向下觸發位 = PL[1]        ← 下一個樞紐低若低過它，下緣確認外擴
```

**同一組狀態同時能算出其他六種型態的觸發位：**

| 下一個樞紐高 | 下一個樞紐低 | 完成的型態 |
|---|---|---|
| `> PH[1]` | `< PL[1]` | **P29 擴散三角** |
| `< PH[1]` | `= PL[1]` | P08 下降三角 |
| `= PH[1]` | `> PL[1]` | P09 上升三角 |
| `< PH[1]` | `> PL[1]` | P10 對稱三角 |
| `= PH[1]` | `= PL[1]` | P22 箱型 |
| `< PH[1]` | `< PL[1]` | P20 下降通道 |

**每根都能輸出、零自由參數、零前瞻。**
這條路把型態從「事後辨識」變成「盤前就知道價格走到哪會變成什麼」。

## 三、突破怎麼算

**空方突破 = 收盤跌破下緣趨勢線的外推值，一根就算，不需要幅度、不看影線。**

九個細節全部釘死，沒有留任何可調空間：

| # | 項目 | 釘死為 |
|---|---|---|
| 1 | 外推方式 | **E1**：通過最後兩個樞紐低的直線 |
| 2 | 用哪根的收盤 | 當根 `Close` |
| 3 | 方向（空方） | `Close < 下緣線值` |
| 4 | 相等算不算 | **不算**（嚴格小於） |
| 5 | 需要幾根確認 | **一根** |
| 6 | 突破幅度門檻 | **無**（純穿越） |
| 7 | 影線刺穿 | **不算** |
| 8 | 線能否跨時段外推 | **能**（擺盪幾何型，2026-08-21 裁示） |
| 9 | 假突破（下根收回） | **不撤銷確認** |

**為什麼用 E1 不用最小平方**：Bulkowski 的定義建立在「觸點」上，
最近兩個觸點決定這條線當下在哪。
**三點最小平方會畫出一條沒有任何觸點落在上面的線 —— 那不是任何人看得到的線。**

## 四、有效期

**有效期 ＝ 型態自己形成所花的根數**（自我指涉，零參數，2026-08-21 裁示）。
震盪盤形成得慢，有效期自動變長；急盤形成得快，有效期自動變短。

## §1 樞紐定義

```powerlanguage
{ 樞紐高在 i，於 i+1 才確認 -- 記錄延後一根，無前瞻 }
v_PivotHigh = ( H[1] > H[2] ) and ( H[1] > H[0] );
v_PivotLow  = ( L[1] < L[2] ) and ( L[1] < L[0] );

{ 限制：i-1、i、i+1 必須同時段。分形是相鄰依賴，跨時段無意義 }
v_PivotOK   = ( v_Bars_In_Sess >= 3 );
```

**S1 雙尺度穩健性檢驗（裁示 5）—— 同一型態必須在視窗 1 與視窗 2 同時成立：**

```powerlanguage
{ 視窗 2：極值在更寬的鄰域上仍然成立 }
v_PivotHigh_W2 = ( H[2] > H[3] ) and ( H[2] > H[4] )
             and ( H[2] > H[1] ) and ( H[2] > H[0] );
```

**為什麼是 1 與 2**：1 是定義局部極值的最小值，2 是要求極值在更寬鄰域仍成立的最小值。
**兩者是最小的兩個整數視窗，沒有掃描空間。**
這把「平滑」換成「結構」—— 不是把價格抹平，是要求形狀在更寬鄰域上仍然存在。

## §2 型態成立

```powerlanguage
{ PH[1] = 最近一個樞紐高，PH[3] = 往前數第三個。PL 同理 }
v_P29_Form = ( PH[3] < PH[2] ) and ( PH[2] < PH[1] )      { 上緣單調外擴 }
         and ( PL[3] > PL[2] ) and ( PL[2] > PL[1] );     { 下緣單調外擴 }
```

**對稱 3+3，不是 Bulkowski 的 3+2**（理由見「重點說明 ①」）。

## §3 三向細分

```powerlanguage
v_Mid_Old = ( PH[3] + PL[3] ) / 2;
v_Mid_New = ( PH[1] + PL[1] ) / 2;

if v_Mid_New > v_Mid_Old then      v_P29_Dir =  1    { 上升擴散  47.1% }
else if v_Mid_New < v_Mid_Old then v_P29_Dir = -1    { 下降擴散  50.4% }
else                               v_P29_Dir =  0;   { 水平擴散   2.5% }
```

代數上等價於「上緣外擴量 vs 下緣外擴量誰大」，用中點漂移敘述比較直接。

## §4 事前價位地圖

```powerlanguage
{ 只需要兩個樞紐高、兩個樞紐低就能輸出，每根都能算 }
if ( PH[2] < PH[1] ) and ( PL[2] > PL[1] ) then begin
    v_P29_TrigUp = PH[1];        { 下一個樞紐高高過它 -> 上緣確認外擴 }
    v_P29_TrigDn = PL[1];        { 下一個樞紐低低過它 -> 下緣確認外擴 }
end;
```

## §5 突破確認

```powerlanguage
{ E1：通過最後兩個樞紐低的直線，slope 必為負 }
v_Slope  = ( PL[1] - PL[2] ) / ( BarOf_PL1 - BarOf_PL2 );
v_LineNow  = PL[1] + v_Slope * ( CurrentBar - BarOf_PL1 );
v_LinePrev = PL[1] + v_Slope * ( CurrentBar - 1 - BarOf_PL1 );

{ 嚴格小於、單一一根、首次穿越、不看影線、不設幅度門檻 }
v_P29_BreakDn = ( Close    <  v_LineNow  )
            and ( Close[1] >= v_LinePrev );
```

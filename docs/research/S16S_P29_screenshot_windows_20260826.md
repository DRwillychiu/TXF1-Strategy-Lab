### 0.1 重新載入最新版指標

雲端版本已修過三次，**舊版截出來的圖是錯的**：

| 修正 | 影響截圖嗎 |
|---|---|
| `s1` 偏移（恆為 0） | 否，只影響數值 |
| 外包棒漏抓 | 是，會少兩個型態 |

### 0.2 為什麼 `Show_Pivots` 必須關掉

```
樞紐高 75,145 ＋ 樞紐低 76,032 = 151,177 個
佔全部 421,513 根 = 35.9%
```

2026-08-26 第一次截圖就是這個狀況 —— **看不出型態不是眼力問題，是顯示設計錯了。**

**現在預設只畫兩條趨勢線**：上緣紅色、下緣青色、寬度 3，**顏色寬度寫死在程式碼裡**，不受 Format 對話框記憶值影響。

## 0.3 ⚠️ 2026-08-26 第二次截圖後：`Plot` 改為繪圖物件

**第二次截圖乾淨了（只剩兩條線），但線橫跨整張圖 —— 那還是錯的。**

**實測：**

```
截圖範圍  2026-06-10 18:00 ~ 06-11 13:10   共 185 根
應該有線  02:10 ~ 02:50                    只有 9 根 = 4.9%
其餘 176 根應該完全空白
```

**成因：MC12 會把 `NoPlot` 的空隙用直線接起來。**
畫面上的長對角線，是從上一個型態（06-02 22:50）直接連到這一個（06-11 02:10）。
**02:10 那個轉折才是真正的型態，其餘都是內插產物。**

**已改用 `TL_New` 繪圖物件**——離散線段，不與任何東西相連。

| `Line_Mode` | 行為 |
|---|---|
| **1（預設）** | **繪圖物件。線只出現在型態存活的那幾根** |
| 2 | 舊的 `Plot`，會跨空隙內插（保留供對照，不要用） |
| 0 | 完全不畫 |

**型態死亡後物件會留在圖上**，可以往回捲看歷史型態。

**判讀不變：有線＝那段時間有型態，沒線＝沒有。**

## 1. 怎麼判讀

| 畫面上 | 意思 |
|---|---|
| **兩條線出現** | 型態成立（`P29 FORM`），狀態 = 有效 |
| **兩條線還在** | 有效或測試中 —— **假突破後線不會消失** |
| **兩條線消失** | 型態失效（過期／真突破／真跌破） |
| 線的斜率 | 上緣往上、下緣往下 = 開口張開 |

**線在＝型態活著。線不見＝死了。就這麼直接。**

## 5. 完整事件清單怎麼看

指標對每個型態會印出這些事件：

| 事件 | 意思 |
|---|---|
| `P29 FORM` | 型態成立，兩條線開始畫 |
| `P29 SIG_TEST` | 收盤跌破下緣，**空方訊號**，但未達三根黑K |
| `P29 SIG_RUN3` | 收盤跌破下緣**且**三根黑K，**強訊號**，型態同時死亡 |
| `P29 TEST_UP` | 收盤突破上緣，進入測試中（線還在） |
| `P29 FALSE_BREAK` | 下一個樞紐時已回到型態內，**回到有效** |
| `P29 KILL_PIVOT` | 下一個樞紐時仍在型態外，失效 |
| `P29 KILL_RUN3` | 向上突破且三根紅K，**立即失效** |
| `P29 EXPIRE` | 有效期屆滿（存活根數 > 形成根數） |

**結局分布（202 筆）**：有效期屆滿 138（68.3%）／三紅殺死 21／三黑訊號 16／樞紐裁決 27。

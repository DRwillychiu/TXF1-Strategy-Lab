## 2. 文獻依據（2026-08-25 蒐集）

### 2.1 Bulkowski 的擴散頂正式定義

| 條件 | 原文 |
|---|---|
| 前段趨勢 | 「**向上**通往型態。趨勢起點低於型態起點。」 |
| 形狀 | 「**更高的峰、更低的谷** —— 喇叭形。」 |
| 趨勢線 | 「上緣趨勢線向上斜，下緣向下斜。」 |
| **觸點** | 「**至少五個觸點：三個峰或三個谷觸及對應趨勢線，另一條至少兩個。**」 |
| 留白 | 「價格要在型態內來回穿越，把區域填滿。」 |

**兩件事被獨立證實：**
1. **「至少 3 個觸點」** —— 與本專案「兩點定線、三點才確認方向持續」的推導一致
2. **「前段趨勢向上，否則就是擴散底」** —— 這就是 P49／P50 的區分依據

### 2.2 突破確認的市場共識

> 「突破一般發生在價格**收盤**越過支撐或壓力位。」
> 「在收盤前進場是較高風險的做法，容易被假突破掃到。」

⚠️ **Bulkowski 對擴散型態本身是例外**，他寫「價格**刺穿**趨勢線」（盤中）。
**用戶裁示採收盤價，與他不同，而且用戶版本的自由參數更少。**

### 2.3 樞紐基準的三個陣營

| | 做法 | 自由參數 | 本專案採用 |
|---|---|---|---|
| A 影線派 | 高／低價 | 1（樞紐視窗） | ✅ |
| B 實體派 | 收盤價 | 1 | ❌ |
| C 學術派（Lo, Mamaysky & Wang 2000） | 收盤 ＋ 核回歸平滑 | **4，含 1 個肉眼調的 0.3 乘數** | ❌ |

**採 A 的理由（推導，非偏好）**：擴散型態描述「區間放大」，
**區間按定義就是高減低。用收盤價會系統性低估區間。**

## 3. ★ 陣營 C 的診斷成立，但它的藥我們不吃

### 3.1 診斷（我們資料上實證）

```
樞紐高 74,411 個 / 421,513 根  =  17.65% 的棒是樞紐高
```

**每 5.7 根就有一根被判定為轉折高點。這正是 Lo 等人說的「太多極值」。**

### 3.2 但陣營 B 的解法治不了這個病，反而更嚴重

| 樞紐基準 | 樞紐高數 | 佔全部棒 |
|---|---|---|
| 高／低價 | 74,411 | **17.65%** |
| 收盤價 | 92,170 | **21.87%** ← **更多** |

**趨勢中高點連續墊高比較「黏」；收盤在區間內來回，製造更多局部極值。
「用收盤價去雜訊」的直覺在 TXF1 5 分 K 上是反的。**

### 3.3 底層問題不是「該平滑多少」，是樞紐定義裡沒有尺度

```
分形樞紐   H[i] > H[i-1] and H[i] > H[i+1]
```

**這個定義只問順序，不問幅度。高 1 點也算樞紐，高 300 點也算樞紐。**

**Lo 等人用頻寬壓數量，是在治症狀。而那個頻寬還要再乘 0.3，
乘數的選擇理由是「這樣型態看起來才對」—— 那是對美感擬合。**

### 3.4 我們的解法：用結構要求，不用平滑

```
k=2   65,224 根   15.60%     ← Lo 說的「太多」
k=3    6,238 根    1.48%     ← 壓掉 90.4%
```

**k=3 不是旋鈕，是推導，而且 Bulkowski 的官方門檻也是 3。代價 0 個自由參數。**

## 4. P29 完整規格

### §1 樞紐定義（裁示 1、5）

```
樞紐高 at i：  H[i] > H[i-1]  且  H[i] > H[i+1]
樞紐低 at i：  L[i] < L[i-1]  且  L[i] < L[i+1]

限制     i-1、i、i+1 必須同時段      { 分形是相鄰依賴，跨時段無意義 }
可知時點  i 的樞紐在 i+1 才確認       { 記錄延後一根，無前瞻 }
```

**S1 雙尺度穩健性檢驗**：同一型態必須在**視窗 1** 與**視窗 2** 的樞紐上**同時成立**。

```
視窗 2 樞紐高 at i：  H[i] > H[i±1]  且  H[i] > H[i±2]
```

**為什麼是視窗 1 與 2**：1 是定義局部極值的最小值，2 是要求極值在更寬鄰域仍成立的最小值。
**兩者是最小的兩個整數視窗，沒有掃描空間。** 這把「平滑」換成「結構」——
不是把價格抹平，而是要求形狀在更寬的鄰域上仍然存在。

**自由參數 0。**

### §2 型態成立條件

```
最近三個樞紐高   PH[3] < PH[2] < PH[1]      { 單調外擴 }
最近三個樞紐低   PL[3] > PL[2] > PL[1]      { 單調外擴 }
```

**為什麼對稱 3+3 而非 Bulkowski 的 3+2** —— 實測證明非對稱會製造幾何假象：

| 定義 | 成立根數 | 佔比 | 上升 / 下降 / 水平 |
|---|---|---|---|
| **3 高 + 3 低（對稱）** | **6,238** | **1.480%** | **47.1% / 50.4% / 2.5%** |
| 3 高 + 2 低 | 25,123 | 5.960% | **75.5%** / 22.7% / 1.9% |
| 2 高 + 3 低 | 22,619 | 5.366% | 21.0% / **76.9%** / 2.0% |

**3+2 的「75.5% 上升」是純幾何假象**：要求三個單調墊高的高點卻只要求兩個下移的低點，
中點被機械性推高。**鏡像版立刻給出鏡像結果（76.9% 下降），證明與市場無關。**

**跨度中位數 17 根（約 85 分鐘）。**

### §3 三向細分

```
中點[舊] = ( PH[3] + PL[3] ) / 2
中點[新] = ( PH[1] + PL[1] ) / 2

上升擴散   中點[新] > 中點[舊]        實測 47.1%
下降擴散   中點[新] < 中點[舊]        實測 50.4%
水平擴散   中點[新] = 中點[舊]        實測  2.5%
```

代數上等價於「上緣外擴量 vs 下緣外擴量誰大」，中點漂移的敘述更直接。

⚠️ **頻率上是硬幣（47/50/2.5）。細分在頻率上沒有集中任何東西。
報酬未測，現在下結論會是樣本內選擇。**

### §4 事前價位地圖（裁示 3 = B）

**手上有兩個樞紐高、兩個樞紐低時，下一個樞紐落在哪會完成哪個型態，現在就算得出來。**

```
狀態：PH[2] < PH[1]  且  PL[2] > PL[1]

輸出兩個價位：
    向上觸發位 = PH[1]
    向下觸發位 = PL[1]
```

**同一組狀態同時能算出其他型態的觸發位：**

| 下一個樞紐高 | 下一個樞紐低 | 完成 |
|---|---|---|
| `> PH[1]` | `< PL[1]` | **P29 擴散三角** |
| `< PH[1]` | `= PL[1]` | P08 下降三角 |
| `= PH[1]` | `> PL[1]` | P09 上升三角 |
| `< PH[1]` | `> PL[1]` | P10 對稱三角 |
| `= PH[1]` | `= PL[1]` | P22 箱型 |
| `< PH[1]` | `< PL[1]` | P20 下降通道 |

**每根都能輸出，零自由參數，零前瞻。**

**這條路把型態從「事後辨識」變成「事前的價位地圖」，
而後者才是實盤能用的東西 —— 這是用戶 2026-08-25 提出的方向。**

### §5 突破確認（裁示 4 = E1，裁示 6 = 收盤單根）

```
slope   = ( PL[1] - PL[2] ) / ( bar(PL[1]) - bar(PL[2]) )      { 必為負 }
line_t  = PL[1] + slope * ( t - bar(PL[1]) )

突破 = ( Close[t] < line_t )  且  ( Close[t-1] >= line_{t-1} )  { 首次穿越 }
```

| # | 項目 | 釘死為 | 參數 |
|---|---|---|---|
| 1 | 外推方式 | **E1**：通過最後兩個樞紐低 | 0 |
| 2 | 用哪根的收盤 | 當根 `Close` | 0 |
| 3 | 方向（空方） | `Close < 下緣線值` | 0 |
| 4 | 相等算不算 | **不算**（嚴格小於） | 0 |
| 5 | 需要幾根確認 | **一根** | 0 |
| 6 | 突破幅度門檻 | **無**（純穿越） | 0 |
| 7 | 影線刺穿 | **不算** | 0 |
| 8 | 線能否跨時段外推 | **能**（擺盪幾何型，2026-08-21 裁示） | 0 |
| 9 | 假突破（下根收回） | **不撤銷確認** | 0 |

**採 E1 的理由**：Bulkowski 的定義建立在「觸點」上，最近兩個觸點決定當下這條線在哪。
**E3（三點最小平方）會產生一條沒有任何觸點落在其上的線，那不是任何人看得到的線。**

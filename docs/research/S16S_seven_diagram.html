七種型態 —— 規格逐條對照圖

這七種的邏輯先前已經審查過（08-29 樞紐型 A 組、08-30 母體普查），本頁把每一條規格標到圖上對應的位置，並記錄它為什麼是零參數。定義原樣取自已審查的來源，本頁沒有重寫任何一條。

示意圖不是隨手畫的

每張圖的樞紐價格都先寫下來，再餵進與指標同一組述詞檢查它確實成立。座標若不滿足條件，產生器就掛掉。所以圖上看到的排列，就是程式碼會判定成立的排列。
P15

頭肩頂

Head and Shoulders八年 5,242 個

五個交替樞紐，以樞紐高起頭。頭必須高過兩肩 —— 只有這一條。

條件式子圖上哪裡
頭高過左肩h0 < h2第 1 與第 3 個高點
頭高過右肩h2 > h4第 3 與第 5 個高點

零參數：肩不要求對稱。「兩肩要多接近」是容差，容差就是參數。頸線水平化同理。加上去的代價量在 s16s_hs_scan.py。

註：08-29 原裁示是不編碼（鏡像同樣通過、不含方向）。08-31 標準改為「有出現就畫」，本型態因此進來。

P26

圓弧頂

Rounding Top八年 60 個

九個交替樞紐，取其中五個高點。先升後降，而且上行在減速、下行在加速。

條件式子圖上哪裡
先升後降a < b < c > d > e五個高點的排列
上行減速(b−a) > (c−b)第二段漲幅小於第一段
下行加速(c−d) < (d−e)第二段跌幅大於第一段

零參數：三條全是同尺度的比較，沒有任何外來常數。「圓不圓」不靠曲率門檻，靠兩段漲幅／兩段跌幅誰大誰小。

註：08-30 量測：給定「先漲後跌」，圓弧 20.7%／尖頂 30.1%／混合 49.2%，接近兩個獨立銅板的 25/25/50 —— 這個標籤被量到沒有內容。照 08-31 裁示仍然畫上去，讓你用眼睛檢查這個量測。

P32

V 型反轉

V Reversal八年 97 個

與 P26 同一組九個樞紐，只有加減速方向相反：上行在加速、下行在減速 —— 一個尖頂。

條件式子圖上哪裡
先升後降a < b < c > d > e與 P26 完全相同
上行加速(b−a) < (c−b)第二段漲幅大於第一段
下行減速(c−d) > (d−e)第二段跌幅小於第一段

零參數：與 P26 互斥：兩者的第二、三條剛好相反，所以同一組樞紐不可能兩個都成立，指標裡用 else if 表達。

註：「把畫面縮小，任何東西都符合 V」——你 08-30 的這句話成立，量測見左。

P56

死貓反彈

Dead-Cat Bounce八年 9,134 個

四個交替樞紐。跌下來、反彈、反彈死在原本那段的區間裡、然後創更低的低。

條件式子圖上哪裡
先跌一段l1 < h0第一個低點低於第一個高點
反彈死在區間內min(l1,h0) ≤ h1 ≤ max(l1,h0)第二個高點落在前兩點框出的帶子裡
再創低l2 < l1第二個低點低於第一個低點

零參數：區間裝置（08-29 裁示）：兩點定區間、第三點受測，容差就是 |h0−l1|，由型態自己給。零參數、免疫於衰減律。

註：本組最頻繁的三個之一：8 年 9,134 個，每 46 根一個。

P59

穿越型態

Descending Scallop八年 309 個

七個交替樞紐，取其中三個低點與頭尾兩個高點 —— 一個走完的 J：探底、回升、而且回升比下跌短。

條件式子圖上哪裡
中間那個低是谷底l1 > l2 < l3三個低點的排列
回升短於下跌(l1−l2) > (l3−l2)從谷底回升的幅度小於跌進谷底的幅度
尾高過頭高h4 > h0最後一個高點高於第一個

零參數：三條都是型態自身兩段長度的比較。「J 的弧度」沒有被量，因為量它就要參數。

P65

塔形頂

Tower Top八年 8,572 個

三個交替樞紐，以樞紐低起頭。漲上去、全數吐回、而且跌的根數不多於漲的根數。

條件式子圖上哪裡
先漲h1 > l0中間的高點高於起點的低點
全數吐回l1 < l0收尾的低點低於起點的低點
跌得不比漲慢跌的根數 ≤ 漲的根數兩段的 K 棒根數相比，不是速度門檻

零參數：第三條用根數比根數，不是「幾根之內」那種門檻。普查時原本還有一條「跌幅至少等於漲幅」，實測發現它完全被第二條涵蓋，個數一根不變，已刪。

P72

訂單塊

Order Block八年 18,705 個

三個交替樞紐。更高的高點，而且中間那個低點沉在舊高之下 —— 也就是那段吃掉舊高的推進，是從舊高底下發動的。

條件式子圖上哪裡
中間的低沉在舊高之下l1 < h0回檔跌破了第一個高點的價位
新高過舊高h1 > h0第二個高點高於第一個

零參數：兩條都是價位大小比較。沒有「訂單塊要多大」「要停留幾根」這類外加條件 —— 那些都是參數。

註：本組最頻繁：8 年 18,705 個，每 23 根一個。條件只有兩條，寬鬆是必然的。

母體與繪圖量

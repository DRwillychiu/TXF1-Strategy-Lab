## 1. ⭐ 為什麼不能照抄 L2 的定義

**先量了才建（L28）。L2 的定義搬到 L3 完全失效：**

| 候選定義 | 筆數 | 勝率 | 淨額 |
|---|---|---|---|
| 停損虧損 ＋ 進場價**完全相同** | **1** | 0% | −91,200 |
| 停損虧損 ＋ 進場價 ≤ 前筆 | **115** | 39.1% | −110,400 |
| **任何虧損 ＋ 進場價 ≤ 前筆（L2 的定義）** | **134** | 41.0% | +128,400 |
| （今天 K 棒研究：停損家族 ＋ 150 分鐘窗） | 26 | 26.9% | −89,200 |

**根因**：L3 用 `Buy ... at v_Box_Btm Stop` 進場，**進場價就是箱底，而箱底是一條會移動的結構線**
（`Lowest(Low, N)` 滾動）。

- 「進場價完全相同」只剩 **1 筆** → 箱底幾乎不重複，代理失效
- 「進場價 ≤ 前筆」有 **134 筆 = 37% 交易** → 那是「箱體沒往上移」，不是二次進場

## 2. 採用的定義（用戶 2026-08-25 裁示 A）

> **同一個盤整段落 ＋ 前一筆因停損虧損出場 ＋ 新的下單價 ≤ 被打斷那筆的進場價**

### 2.1 「同一段落」怎麼判 —— 零參數

`v_is_in_consolidation` 是**黏著的**（`L3:277-289`，與 L4 同構）：
箱體合格時轉真，**只有 Data2 收盤離開箱體才轉假**。

```powerlanguage
if v_is_in_consolidation and (v_is_in_consolidation[1] = false) then
    v_Episode_ID = v_Episode_ID + 1;
```

**false→true 的轉換恰好就是一個新箱體段落。「同段落」= 一次整數比較，不需要時間窗、不需要容差。**

### 2.2 ⭐ 而且這裡沒有 L2 那個定義錯位

| | L2 | **L3** |
|---|---|---|
| 進場 | `Next Bar at **Market**` | **`at v_Box_Btm **Stop**`** |
| 下單當下知道成交價嗎 | **不知道**（下一根開盤） | **知道，就是 `v_Box_Btm`** |

**L2 v5.4 踩到的坑是「拿還不存在的成交價去比」。停損單沒有這個縫隙。**

### 2.3 為什麼要排除市價出場

**L3 與 L2 在這裡不同**：200 筆虧損出場中有 **33 筆不是停損**
（`CL_BreakExit` 28 / `CL_Holiday` 4 / `CL_Settlement` 1）。
只用「虧損」會多算。

`v_MktExit_Ordered` 在持倉中每根重設，並在**全部 5 個市價出場點**設起
（`CL_BreakExit` / `CL_RegistryEnd` / `CL_Holiday` / `CL_Settlement` / `CL_Kill`）。

**重設只在 `MarketPosition = 1` 時執行**，所以變空手那一根仍保有最後在倉的值——
與 L4 依賴 `ExitFired` 是同一個手法。

### 2.4 唯一的 DISARM 是結構型，不是價格型

```powerlanguage
if (v_ReEntry_Armed = true) and (v_Episode_ID <> v_ReEntry_Episode) then
    解除
```

> **L4 v18 零觸發，就是因為它的價格型 DISARM 被自己的停損蘊含。**
> **這裡完全不測價格，那個陷阱在結構上不存在。**

## 2. 程式碼層面：沒有二次進場「模組」，但**進場條件全是狀態**

`grep` 結果：**無 `ReEntry` / `Armed`（`TSL_Armed` 是移動停損的旗標）/ 無 `v_Prev_MP` / 無 `Cooldown_Bars`。**

L2 的進場（`L2_TrendShort.pla:473-480`）：

```powerlanguage
C0       = Close < ( DC_Lower - ATR_Val * 0.45 )   { 狀態：價格在唐奇安下軌之下 }
C_A      = ZLEMA_Val < ZLEMA_Val[1]                { 狀態：ZLEMA 下彎 }
C_B      = ZLEMA_Val < EMA20_Val                   { 狀態：ZLEMA 在 EMA20 之下 }
FilterOK = 前一週收盤 < 週 SMA(13)                  { 狀態：週線空頭 }
MarketPosition = 0
   -> SellShort( "TS_Entry" ) Next Bar at Market;
```

> **四個條件全部是狀態，沒有一個是事件（沒有 `CrossesBelow`），而且完全沒有冷卻期。**
> **所以只要平倉後條件仍成立，L2 下一根就會再進場。**

### 2.1 ⚠ 更正我 2026-08-22 的分組

我當時把 **L2 歸在 A 組**（市價單＋事件觸發，需要武裝狀態機），與 L1 / L4 同組。
**那個分類對 L2 是錯的。** L2 的條件全是狀態，行為上屬於 **B 組**（L3 / L5）——
**本來就會重複進場，缺的只是紀律。**

實測佐證：**最小間隔 = 60 分鐘 = 剛好 1 根 60M K 棒。**

### 2.2 天然的「回到進場價」由唐奇安下軌提供

```
進場要求：Close < DC_Lower − 0.45 × ATR
初始停損：DC_Lower + 1.1 × ATR
                    ---------------------
兩線相距           1.55 × ATR
```

**被停損之後，價格必須再跌 1.55 × ATR 才會重新滿足 `C0`。**
**這就是二次進場的觸發條件，只是參考線是唐奇安下軌而不是「原進場價」。**

P08

下降三角

Descending Triangle高降 x 低平空八年 2,623 個

真實 K 棒，跨度中位數的案例（不是最漂亮的那個）。淡化的是型態前後的脈絡棒。紅點 = 樞紐高，綠點 = 樞紐低，虛線連出上下兩緣。

三個高點單調下移，三個低點停在同一條帶子裡 —— 賣壓一階一階往下壓，買盤守在同一個價位。

條件式子圖上哪裡
高單調下移h1 > h2 > h3上緣三個點
低點落在帶子內min(l1,l2) ≤ l3 ≤ max(l1,l2)下緣：前兩個低定帶子，第三個受測
低在高下l1 < h1 且 l3 < h3整個型態的幾何一致性

零參數：第二條原本寫「低完全相等」，八年只有 7 個、四個年份掛零。改用區間裝置後 2,623 個、零掛零年，而容差是 |l1−l2| 由型態自己給 —— 仍然零參數。

P10

對稱三角

Symmetrical Triangle高降 x 低升續勢八年 463 個

真實 K 棒，跨度中位數的案例（不是最漂亮的那個）。淡化的是型態前後的脈絡棒。紅點 = 樞紐高，綠點 = 樞紐低，虛線連出上下兩緣。

高點下移、低點上移 —— 兩邊同時收斂。它是 P29 擴散三角的鏡像：P29 兩邊同時外擴。

條件式子圖上哪裡
高單調下移h1 > h2 > h3上緣
低單調上移l1 < l2 < l3下緣
低在高下l1 < h1 且 l3 < h3幾何一致性

零參數：兩條單調條件，沒有任何常數。八年 463 個，是這一組裡最少的 —— 兩邊同時收斂比較難成立。

P11

上升楔形

Rising Wedge高升 x 低升，高漲得慢空（反轉）八年 1,919 個

真實 K 棒，跨度中位數的案例（不是最漂亮的那個）。淡化的是型態前後的脈絡棒。紅點 = 樞紐高，綠點 = 樞紐低，虛線連出上下兩緣。

高低點都在上移，但高點漲得比低點慢 —— 空間被由下往上擠掉。它跟已編碼的 P51 上升擴散楔形共用同一格，差別只在誰漲得快。

條件式子圖上哪裡
高單調上移h1 < h2 < h3上緣
低單調上移l1 < l2 < l3下緣
高漲幅小於低漲幅(h3−h1) < (l3−l1)兩條線的跨距相比，收斂

零參數：第三條是比較不是門檻 —— 沒有「要收斂多少」這種常數。同一格裡 P51 是 (h3−h1) > (l3−l1)、P11 是 <，另有 140 個兩者相等落在中間，兩個都不算。

P20

下降通道

Descending Channel高降 x 低降（整格）空（續勢）八年 3,101 個

真實 K 棒，跨度中位數的案例（不是最漂亮的那個）。淡化的是型態前後的脈絡棒。紅點 = 樞紐高，綠點 = 樞紐低，虛線連出上下兩緣。

高低點同步下移。這一格就是它 —— 沒有跨距條件，所以已編碼的 P52 下降擴散楔形（低跌得比較快）是它的子集，量到 1,716 個，占 55.3%。

條件式子圖上哪裡
高單調下移h1 > h2 > h3上緣
低單調下移l1 > l2 > l3下緣
低在高下l1 < h1 且 l3 < h3幾何一致性

零參數：兩條單調，零常數。P52 完全落在 P20 之內，已驗證。依 2026-08-31「兩個都畫」裁示，底層的 P20 與子集 P52 都上圖。

P22

箱型

Rectangle / Box高平 x 低平中性八年 3,063 個

真實 K 棒，跨度中位數的案例（不是最漂亮的那個）。淡化的是型態前後的脈絡棒。紅點 = 樞紐高，綠點 = 樞紐低，虛線連出上下兩緣。

上下緣都停在自己的帶子裡 —— 一段沒有方向的區間。

條件式子圖上哪裡
高點落在帶子內min(h1,h2) ≤ h3 ≤ max(h1,h2)上緣：前兩個高定帶子
低點落在帶子內min(l1,l2) ≤ l3 ≤ max(l1,l2)下緣：前兩個低定帶子
兩邊都不單調非升也非降否則它屬於別的格子

零參數：原定義是「高完全相等 ＋ 低完全相等」，八年只有 2 個、七個年份掛零 —— 幾乎不存在。區間裝置版 3,063 個、零掛零年，倍率 1,532 倍。

「完全相等」第三次被算術殺死

P08 與 P22 的原始定義都寫「完全相等」。實測八年：P08 只有 7 個（四個年份掛零）、P22 只有 2 個（七個年份掛零）—— 跟 P53 的 7 個、P54 的 8 個一模一樣。

改用區間裝置（兩點定帶、第三點受測，容差 = |A−B| 由型態自身給）：P08 2,623、P22 3,063，兩者零掛零年，倍率 375 倍與 1,532 倍。仍然零參數。

這是檢查表第 17 條預測到的，也是 2026-08-28 量過的衰減律：tick 固定 1 點而擺幅八年從 9 點漲到 90 點，完全相等的命中率以 1/擺幅 衰減。

待裁示：若 P08／P22 改用區間裝置，已編碼的 P53／P54（現在用完全相等，7 個與 8 個）要不要一致？改了會動到已驗證的數字。

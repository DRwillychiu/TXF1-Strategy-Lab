# L1 進場門檻：ATR 倍數 vs 固定趴數

## 0. 一句話問題

> **「在非常劇烈波動下，進場仍需要用 2 個 ATR？還是改成固定趴數更直覺？」**

---

## 1. 現況

```powerlanguage
Breakout_Level = maBase + ( Current_ATR * Entry_Multiplier )
Cond_Breakout  = ( Close Crosses Over Breakout_Level )
```

| 元素 | 現值 |
|---|---|
| `maBase` | `Average(Close, 61)`，Data1 = 45M |
| `Current_ATR` | `AvgTrueRange(20)` of Data1 |
| `Entry_Multiplier` | **2** |

**門檻距均線的絕對距離 = 2 x ATR45，會隨波動率浮動。**

---

## 2. 問題的機制（為什麼這是一個真問題）

### 2.1 ATR 型門檻的內建副作用

波動放大 -> ATR 膨脹 -> 門檻被推離均線更遠 -> **必須走更遠才觸發**。

後果鏈：

```
波動放大  ->  門檻變遠  ->  進場更晚  ->  進場位置更伸展
                                    ->  停損距離也更遠（同樣吃 ATR）
                                    ->  單筆風險金額上升
```

**這是設計特性還是設計缺陷，目前沒有實證。** 兩種解讀都說得通：

| 解讀 | 論點 |
|---|---|
| **是特性** | 高波動時本來就該要求更強的證據才進場，這是自動的品質控制 |
| **是缺陷** | 高波動常常正是趨勢啟動點，此時提高門檻等於**系統性錯過最好的行情** |

**本研究的核心就是判定哪一個為真。**

### 2.2 固定趴數的鏡像副作用

```powerlanguage
Breakout_Level = maBase * ( 1 + Entry_Pct / 100 )
```

| | 位階免疫 | 波動免疫 |
|---|---|---|
| 點數（固定點） | ❌ | ❌ |
| **固定趴數** | ✅ | **❌** |
| **ATR 倍數（現行）** | ✅ | ✅ |

固定趴數解決位階問題，但**不隨波動調整**：

- **低波動**：p% 相對於當時的雜訊很大 -> 門檻過嚴 -> 樣本枯竭
- **高波動**：p% 相對於雜訊很小 -> 門檻過鬆 -> 假突破暴增

**所以這不是「哪個比較好」，是「哪一種失效模式對 L1 傷害較小」。**

---

## 3. ⚠ 必須先看的兩個 repo 內前例

### 3.1 S16_S MinSlope 的百分比化 —— 四層獨立關閉

`docs/research/S16S_v1192_slope_percentage_closure_20260811.md`

- v0.6：`threshold = ATR x mult` -> **REJECTED**，理由「ATR 測雙向波動，無法表達方向性斜率」
- v1.9.0：`threshold = ZLEMA_Fast x pct/100` -> 淨利 −1.6%，**PF 反而更好**
- v1.19.2 百分比形式 -> **四層獨立關閉**
- 最終 v1.20.0 採用**速率式**（rate form），非百分比也非 ATR

**適用性判定**：**不可直接套用。** S16_S 標準化的是**斜率（變化率）**，L1 標準化的是
**乖離距離（水準）**。ATR 對距離的意義（「這段距離相當於幾倍常態波動」）遠比對
斜率清楚。**但 S16_S 的教訓成立：這類改動要用四層獨立證據關閉，不能單看淨利。**

### 3.2 MinSlope 的尺度漂移事故

固定點數門檻在 2019 是 0.28%、2026 是 0.062%，**早年緊 4.5 倍**，
直接造成 S16_S 2019-2023 五年只有 4 筆交易，W4 / 三市況 PF **數學上無法計算**。

**L1 目前沒有這個病**（ATR 隨價格縮放）。**改成固定趴數也不會有**（同樣隨價格縮放）。
**改成固定點數就會有 —— 該選項直接封死，不列入研究。**

## 4. ⭐ 需要研究的具體問題（逐項）

### R-1 高波動 regime 下，現行門檻到底晚了多少？

**要量的**：把 6.7 年切成波動分位（用 `Current_ATR` 的滾動百分位），逐 regime 統計：

| 指標 | 為什麼要 |
|---|---|
| 各 regime 的交易筆數 | 高波動 regime 是不是樣本枯竭 |
| 各 regime 的 PF / 平均損益 | 門檻在哪個 regime 失效 |
| 進場價距 `maBase` 的**實際點數與趴數** | 量化「伸展程度」隨波動的變化 |
| 進場後 MAE 分布 | 進場太晚會表現為 MAE 惡化 |

**這一步不需要改任何程式碼**，用現有 500 筆交易明細 + ATR 序列就能算。
**必須先做完 R-1，否則後面全是猜的。**

### R-2 `Entry_Multiplier = 2` 這個值本身驗證過嗎？

`docs/research/` 查無 `Entry_Multiplier` 的 sweep 紀錄。**它可能從未被掃描過。**

**⚠ 若 R-2 顯示 2 不是高原中心，那問題根本不是「ATR vs 趴數」，是「乘數選錯」。**
換公式前必須排除這個更簡單的解釋。

**掃描**：`Entry_Multiplier` 1.0 ~ 4.0 step 0.25（13 格）。

### R-3 固定趴數的等價點在哪？

要能公平對照，必須先找到**與現行門檻在樣本內平均等價**的 `Entry_Pct`：

```
Entry_Pct_equivalent  =  mean( Current_ATR x 2 / maBase ) x 100
```

**這個錨定值必須先算出來**，掃描才有中心。
（比照 S16_S 的 `28 / 40634 = 0.0689%` 錨定作法。）

### R-4 兩種形式的交易母體重疊多少？

用 `(日期, 時間, 進場價)` 配對。依 `version-performance-table` SKILL：
**重疊 < 70% 即為可比性斷點，淨利不可直接相減**，只能比調整 PF / 夏普 / 索丁諾 / 回檔%。

**預期會是斷點**（換進場公式必然大幅改變母體），所以**比較方法必須事先定好**。

### R-5 混合形式值不值得？

```powerlanguage
{ 候選 C：ATR 為主，趴數封頂 }
Breakout_Level = maBase + MinList( Current_ATR * Entry_Multiplier,
                                   maBase * Entry_Pct_Cap / 100 )
```

**動機**：只砍掉「ATR 極端膨脹把門檻推太遠」的尾端，其餘維持現行行為。
**這與 Rule #12 的 `SL_Pct` 封頂是同一個設計語法**，L1 已經在停損側用了這個形狀。

**⚠ 但 Rule #17 明文「禁止固定點數 cap（在 vol-adaptive 架構中是設計矛盾）」。**
`Entry_Pct_Cap` 是**百分比**不是固定點數，形式上不違反，但**必須在 spec 裡明確論證
為何不觸犯該條的精神**，否則不得實作。

### R-6 對停損的連帶影響

`SL_Multiplier` 與 `Daily_Cap_Multiplier` 也吃 ATR。**改進場門檻不會自動改停損，
但會改變「進場價相對均線的位置」，進而改變停損的相對距離。**

R-4 的母體比較必須**同時**檢查停損側指標（平均 MAE、TL_SL 佔比、單筆最大虧損），
不可只看進場側。

| **H1** | ATR 門檻在高波動 regime 系統性延遲進場 | 最高波動四分位的**平均進場乖離趴數**顯著高於最低四分位 | 四分位間差異 < 20% -> H1 否證，整個研究終止 |
| **H2** | 該延遲造成績效損失 | 最高波動四分位的 PF **低於** 全樣本 PF 1.4863 | 高波動四分位 PF >= 全樣本 -> H2 否證，「特性」解讀成立，**不需改公式** |

## 7. ⭐ 與二次進場正交（重要）

**改進場門檻不會破壞二次進場模組，一行都不用改。**

理由：`v_TrendRatio` 的分母是**實際成交乖離**，不是公式：

```powerlanguage
v_Frozen_Gap = Entry_P - maBase      { 這一筆「實際」拿到的乖離 }
v_TrendRatio = ( Close - maBase ) / v_Frozen_Gap
```

無論門檻是 `ATR x 2`、`maBase x p%`、還是別的東西，**二次進場問的永遠是
「這一筆的乖離還剩多少比例」**。

這是 2026-08-13 選「距離比值」而否決「ATR 倍數」時的附帶好處。

**因此兩條線可以完全平行推進，不必互相等待。**

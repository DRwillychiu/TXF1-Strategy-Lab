# L3 二次進場 — 完整 K 棒研究

> 本文最大的價值可能不在結論，而在方法論：
> **只用成交明細做的分析，得到的答案正負號是反的。**

---

## 0. 為什麼要重做

2026-08-25 稍早曾用 369 筆成交明細做過一次分析，結論是「快速二次進場賠 −64,000，但四種節流方案都沒有證據支持」。

使用者當日裁示：**做研究與優化，絕對不能只拿有成交的交易明細分析，必須用完整整份 K 棒行情。**

這個指正是方法論層級的，三個具體缺陷：

1. **只看得到被現行濾網放行的樣本。** 要評估一個新閘門，必須知道被擋掉的那段時間行情走了什麼——那不在明細裡。
2. **「移除該筆」的天真算法不成立。** 擋掉一筆後策略停在空手，之後會在**不同價位**進場。沒有 K 棒就模擬不出替代路徑。
3. **箱型狀態不在明細裡。** `v_Box_Top` / `v_Box_Btm` / 箱齡 / 箱高才是 L3 的進場品質變數，而它們只存在於 K 棒。

## 2. 答案分兩層，而且兩層相反

### 2.1 這 23 筆認得出來嗎 → 認得出來

「快速二次進場」定義：前一筆為虧損停損出場（`CL_SL` 或 `Stop Loss` 且損益 < 0），且本筆進場距前筆出場 ≤ 150 分鐘。共 23 筆（7 賺 16 賠，合計 −64,000）。

| 特徵（進場當下可觀測） | 快速組中位（範圍） | 對照組中位（範圍） |
|---|---|---|
| 進場價距箱底（ATR） | **2.35** (0.14–5.22) | 5.04 (1.52–18.0) |
| 箱內相對位置 | **0.223** (0.015–0.464) | 0.400 (0.142–0.530) |
| 箱高 / ATR | **9.88** (8.68–13.76) | 14.37 (6.99–40.7) |
| 15M ATR | **52.4** | 17.2 |
| 距支撐帶（點） | **146** | 25.5 |
| 箱體收縮率 shrink | **0.260** | 0.147 |
| 箱齡（60M 根） | 4 (2–20) | 3 (0–31) |
| 同箱第 N 次進場 | 2（22/23 與前筆同箱） | 1 |

**指紋**：高波動（ATR 3 倍）、寬箱但收縮不足、緊貼箱底、深入支撐帶下方。

### 2.2 這 23 筆裡能分出 7 賺 / 16 賠嗎 → 不能

18 個進場當下可觀測特徵，AUC 與 permutation p 值：

| 特徵 | AUC | p | 特徵 | AUC | p |
|---|---|---|---|---|---|
| shrink | 0.741 | **0.054** | 相對位置 | 0.652 | 0.511 |
| d2 vs MA | 0.679 | 0.162 | 距箱底(ATR) | 0.661 | 0.781 |

**先前「進場價差%、間隔分鐘無分辨力」的結論仍然成立，並擴大到全部箱型特徵。**

## 3. 反事實：正負號翻轉

把濾網裝進通過 A 級驗收的複刻器，**整段重跑**，讓策略在被擋後自己去找下一個進場點：

| 變體 | 筆數 | 淨利 | PF | Δ淨利 |
|---|---|---|---|---|
| BASELINE | 377 | +2,186,000 | 1.227 | — |
| 冷卻 60 分 | 367 | +1,558,800 | 1.167 | **−627,200 (−28.7%)** |
| **冷卻 150 分（= 擋掉這 23 筆）** | 362 | +1,753,200 | 1.195 | **−432,800 (−19.8%)** |
| 冷卻 300 分 | 356 | +1,824,800 | 1.210 | −361,200 |
| 冷卻 1 天 | 312 | +1,736,400 | 1.231 | −449,600 |

```
天真算法（只用成交明細）：擋掉這 23 筆 = +64,000
完整 K 棒反事實          ：−432,800

連正負號都是反的。
```

**−432,800 中有 −413,200（95%）純粹來自 Top-10 被打掉。**

那 23 筆裡包含兩筆 Top-10：
- `2026-04-24` **+381,200**（全策略第 2 大）
- `2024-07-10` **+150,000**（全策略第 10 大）

合計 +531,200 = 全策略淨利的 **22%**。

## 4. 對照組給了更硬的反證

用快速組的中位數當門檻去切 346 筆對照組，**兩個特徵方向完全相反**：

| 門檻 | 對照組表現 | 方向 |

**「快速二次進場的指紋」在其他情況下是賺錢的特徵。** 拿它當濾網必然誤傷。

## 5. 那個看起來有效的濾網是過擬合

`進場價距箱底 >= 3.0 ATR` 跑出 +295,200（+13.5%）。門檻掃描：

```
1.50 → +344K     2.00 → −46K      2.50 → +200K
2.75 → +446K     3.00 → +295K     3.25 → +302K
3.50 → −16K      4.00 → −77K      5.00 → −632K
```

**相鄰 0.25 ATR 就變號、沒有平台區。** 依專案「參數高原 vs 尖峰」判準，這是雜訊不是訊號。

## 7. 結論

**L3 已經有天然二次進場，不需要新增；而且不得加任何節流。**

理由不是「找不到證據支持」，是**有證據反對**：

1. 任何長度的冷卻都讓淨利掉 **19.8% ~ 28.7%**（通過 A 級驗收的複刻器實測）
2. 損失的 **95% 來自被打掉的 Top-10**
3. 那 23 筆的「指紋」在對照組是**賺錢**的特徵
4. 唯一看似有效的門檻**沒有平台區**，是過擬合

那 16 筆虧損（約 −690K）是這支策略的**入場成本**，不是可切除的缺陷——切除它的同一把刀會把 +531,200 一起切掉。

這與 `portfolio-role-design` SKILL 的鐵則一致：每支策略的目標是「抓到該賺的行情 + 小虧小賺大賺」，不是獨立最大化 PF。

## 0. 七個是誰

| 代號 | 型態 | 幾何 | 方向 |
|---|---|---|---|
| P29 | 擴散三角／喇叭形 | 高遞增 ＋ 低遞減 | 中性 |
| P49 | 擴散頂 | P29 ＋ 前段是上漲 | 空 |

**好消息**：七個全部只需要「最近兩個樞紐高 ＋ 最近兩個樞紐低」，

**六個是零自由參數**，可以直接沿用第一波的骨架。

## 1. ★ 三個必須先裁的問題（不裁就會重蹈 08-17）

### 問題 A — P49／P50 的「前段趨勢」怎麼定義？

這是七個裡**唯一會引進自由參數的地方**。三個選項：

| 選項 | 做法 | 自由參數 | 副作用 |
|---|---|---|---|
| **A1** | 用第三個樞紐：`H[倒數第3] < H[倒數第2]` | **0** | 需要三個樞紐，樣本變少 |
| A2 | 用既有 ZLEMA 狀態 `v_ZLEMA_Fast > v_ZLEMA_Slow` | **0**（借用既有） | 與策略自己的訊號耦合 |
| A3 | 用「N 根前的收盤比現在低」 | **1（N）** | ❌ 引進旋鈕 |

**我的建議：A1。** 留在型態自己的幾何裡，不跟策略耦合，也不新增旋鈕。

### 問題 B — 七個之間會互相遮蔽，串接順序怎麼定？

P49／P50 是 P29 的子集（P29 ＋ 趨勢條件）。
若照 K 棒那套 first-match-wins，**P29 排前面就會把 P49／P50 整個吃掉**。

K 棒側踩過這個坑：B28 三內部上漲被 A06 多頭孕線遮蔽，
最後是用**獨立旗標**解決的（`v_KB_Bull3`）。

| 選項 | 做法 |
|---|---|
| **B1** | 七個各自獨立計數，不做串接（**普查階段本來就該這樣**） |
| B2 | 串接，但把 P29 排到最後 |

**我的建議：B1。** 這一階段是量測不是下單，沒有理由引入遮蔽。

### 問題 C — 程式碼化是寫進 .pla，還是只寫進 Python 普查？

**這一題最重要。**

| 選項 | 做法 | 代價 |
|---|---|---|
| **C1** | 先只寫進 Python 普查腳本，跑檢定，**過了才寫進 .pla** | 零風險，錨點不動 |
| C2 | 直接寫進 .pla | 33 個檢定 0 個過關的前提下，等於加 7 段惰性程式碼 |

**我的建議：C1。** 而且必須先講清楚一件事：

```
累計檢定 33 -> 40
Bonferroni 門檻 3.17 -> 約 3.23
```

**補完這七個，找到東西的機率是「更低」，不是更高。**
它的價值是**母體完整性**（能說「擴散家族全部測過」），不是找到 alpha。
這一點先講明白，測完是負的才不會覺得白做。

## 2. 建議的執行順序

```
1. 裁示 A / B / C 三題（上面）
2. 逐一寫出七個的判定式，一個一個對照「這句話在描述什麼市場狀態」
3. 寫進 s16s_chart_pattern_wave3.py，跑普查（次數 + 訊號棒命中）
4. 跑同一套有檢定力的篩選（7,703 死叉，HZ 12，Bonferroni 3.23）
5. 更新圖鑑：未編碼 39 -> 32，已定義 33 -> 40
6. 出結案文件，不論正負
```

**第 2 步是用戶指定的「逐一邏輯規劃」，不可跳過直接寫程式。**

## 3. 還掛著的另一個裁示

**P47 號角頂要不要立為「掛牌觀察」？**

```
n=259  +8.17 vs −0.90  t=+2.09  置換 p=0.0333
逐年 7/8 年方向一致（二項 p=0.035）
但 33 個檢定的 family-wise p=0.673
```

建議**要**。做法是每次資料更新時自動重算它的逐年一致性，
成本近乎零，而**前瞻樣本外是唯一能確認它的方式**。

## 1. Root Cause（文件傳播型 BUG 的完整因果鏈）

```
P3 程式碼 (正確): v_Frozen_SL = MaxList(兩個停損價) = Entry - MinList(兩距離) = 取緊腿
        ↓ 標頭文件錯誤改寫 (數學錯誤: E - Min(a,b) 被寫成 "entry - MaxList(a,b)")
標頭 STRATEGY LOGIC: "Frozen at entry - MaxList(ATR x SL, DATR x Cap)"
        ↓ V2.6+ (2026-06-18) 寫 P3b 時照抄文件的公式形狀
P3b: SetStopLoss(MaxList(兩距離)) = 取鬆腿 ← BUG
        ↓ 驗證器把 BUG 編碼為標準
verify V-4 斷言 MaxList → BUG 通過驗證一年
```

進場棒 45 分鐘 (IOG=false, 緊停損單次棒才掛) 的唯一保護跑在 1.6-2.8 倍設計風險。2026-07-22 實測: 鬆腿 736 pts vs 意圖 266 pts (2.77x)。

## 2. 變更內容（.pla 共 5 處, 驗證器 5 處）

### 2.1 程式碼（實質變更 2 行）
```powerlanguage
SetStopContract;                                  { 新增: per-contract 基準 }
if MP <= 0 then
    SetStopLoss(MinList(Current_ATR * SL_Multiplier,      { MaxList -> MinList }
                        Daily_ATR * Daily_Cap_Multiplier) * BigPointValue);
```

### 2.2 SetStopContract 的必要性（自我驗證中發現的第三地雷）
MC `SetStopLoss` 金額預設 per-position 基準。2 口實盤時: 總損 = 距離 x BPV x 2 → 觸發距離砍半。
- V2.7 (MaxList) @ 2 口: 鬆腿/2 ≈ 0.8-1.4x 緊腿 — 兩個 BUG 意外部分互抵
- 若只改 MinList 不加 SetStopContract @ 2 口: 緊腿/2 → **進場棒在凍結停損一半距離就被踢出 = 新 BUG**
- MinList + SetStopContract: 每口正確 = 緊腿, 口數不變式成立
- 1 口回測: SetStopContract 與預設完全等價 → 回測可比性不受影響

### 2.3 標頭修正（3 處）

## 2. `ReEntry_Structure_Gate` 是邏輯冗餘，不是樣本巧合

**位元級完全相同**：119 筆、零消失、零新增、欄位差異 0。

**原因在 Section 5.5 的狀態機，執行順序早於進場條件：**

```powerlanguage
if v_ReEntry_Armed = True then begin
    if v_Golden_Cross = True or v_ZLEMA_Fast >= v_ZLEMA_Slow then begin
        v_ReEntry_Armed = False;          { 快線一站上慢線就解除武裝 }
        v_ReEntry_Price = 0;
    end;
end;
```

> **`v_ReEntry_Armed = True` 已經蘊含 `v_ZLEMA_Fast < v_ZLEMA_Slow`。**
> 進場條件再檢查一次是重複的，可事前推導。

與 v1.16.0 的 `Gap_Down_Min_Pct` 同一類：**位元相同 ＋ 可證的結構理由**。

**處置**：本次**不改預設值**（使用者 2026-08-08 裁示「先保留」）。
記錄為「已證惰性、日後簡化第一順位」。

## 8. 結論：不可模擬上架，且阻擋是結構性的

### 8.1 根本阻擋只有一個

**`MinSlope = 28` 是點數門檻，造成 2019-2023 五年只有 4 筆交易。**

這不是「數字不夠好」，而是讓 **W4 的 9 個視窗、W5#7 的三市況、Sniper 的 Bear PF
在數學上無法計算**。

```
28 點 / 2019 指數 ~10,000  =  0.28%
28 點 / 2026 指數 ~45,000  =  0.062%
                              早年緊 4.5 倍
```

候選死叉每年穩定約 1,200 筆，**是閘門把早年整段濾掉，不是市場沒有機會。**

### 8.2 解法已經寫過，但依裁示刪除

`MinSlope` 百分比化（`v_ZLEMA_Fast * MinSlope_Pct / 100`，錨定 `28/40634 = 0.0689%`）
曾實作為 v1.17.0，**一次回測未跑即依使用者裁示刪除**，保存於 commit `e379bd2`。

**歷史實作對照：**

| 版本 | 做法 | 結果 |
|---|---|---|
| v0.6 | `threshold = ATR × mult` | **REJECTED**。ATR 測雙向波動，無法表達方向性斜率 |
| v1.9.0 | `threshold = ZLEMA_Fast × pct/100` | −1.6% 淨利，**PF 反而更好** |

**v1.9.0 的形式是對的，且當時幾乎中性。**

### 8.3 距離模擬上架的完整清單

| 順位 | 缺口 | 性質 | 阻擋等級 |
|---|---|---|---|
| **1** | **MinSlope 百分比化** | 讓樣本分布成立 | **前置條件，不做則 2/3/4 皆無法進行** |
| **2** | W4 Walk-Forward 9 視窗 | 強制 gate | **必要** |
| **3** | W5 十維度未測的 5 項（Sortino/Calmar、相關性、DD clustering、WFE、三市況 PF） | 強制 gate | **必要** |
| **4** | Rule #18 五件套 | 強制 gate | **必要** |
| 5 | Check 6 Sniper 四項（Ruin / Kelly / EV / Bear PF） | 低頻策略強制 | 必要 |
| 6 | IOG 設定確認 | Operational 5/5 的第 5 項 | 必要 |
| 7 | `Tail_LastEntry_Time` 合規（`Tail_FillSemantic_On`） | 目前 NOT COMPLIANT BY DEFAULT | 建議 |

### 8.4 誠實的一句話

> **程式碼品質與單機制驗證的密度都遠超過門檻要求；
> 但「這支策略在 2024 之前幾乎不存在」使所有跨期驗證無法執行。
> 現在缺的不是再做一次最佳化，是把樣本修好。**

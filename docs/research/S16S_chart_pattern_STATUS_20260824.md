## 2. 檢定結論

```
母體      7,703 個死叉（不是 187 個訊號棒）
結果變數  死叉後 12 根的空單報酬（12 取自策略持倉中位數 12.3）
母體平均  −0.59 點   標準差 73.04

累計 33 個檢定    Bonferroni 門檻 |t| > 3.17    過關者 0
最大 |t| = 2.09（P47 號角頂），family-wise p = 0.673
```

**兩波是兩次獨立、預先登記、有多重比較校正的嘗試，結論一致：
圖形型態作為進場濾網，在有檢定力的母體上找不到任何東西。**

### 三個機械性發現（比檢定結果更耐用）

1. **收斂與斜率閘門定義上互斥。** 閘門要求 5 分鐘跌 0.25%（寬棒），
   「最近 N 根最窄」按定義不是寬棒。NR7 出現 51,970 次，訊號棒上 **0** 次。
2. **共現不等於有用。** 訊號棒按定義是大波動棒，波動有自相關，
   任何與波動相關的東西都會偏移，與優勢無關。
3. **進場濾網在這支策略上不可證偽。** 187 根訊號棒，sd 73，
   可偵測下限 **21.0 點**；7,703 上量到的最大效果 **10.1 點**。差 2.1 倍。

## 3. 唯一候選：P47 號角頂

```
n = 259   +8.17 vs −0.90   t = +2.09   置換檢定 p = 0.0333
逐年 7/8 年方向一致（二項 p = 0.035）
33 個檢定的 family-wise  p = 0.673
187 根訊號棒上只出現 9 次 -> 作為濾網幾乎完全惰性
```

**候選，不是發現。** 讓它沒被丟掉的是「7/8 年一致」這個另一個統計量，
不是它的 t 值。**確認只能靠前瞻樣本外，再掃一輪只會讓 family-wise 更差。**

# 跨月價差／結算日收斂：驗收標準草稿（2026-11-20，待 Willy 確認）

> 這份在看到任何策略結果**之前**寫。目前只做過資料檢查（`calspread_data_profile_20261120.md`），沒有跑過任何進出場規則。

## 研究 A：跨月價差回歸
- **標的**：同時買一個月份、賣另一個月份（近月對次月），賺兩者距離回到正常。
- **偏離的定義**：價差減掉自己過去 N 個交易日的中位數。N 取高原區，不取單一最佳值。
- **樣本**：2020–2026 日盤，同一分鐘兩邊都有成交才算。
- **成本**：兩腳都算，口徑同 L1–L6；手續費、期交稅、價差單規則【待確認】。
- **對照組**：同樣持有時間、隨機進場。
- **通過條件**（全部成立）：
  1. 扣成本後每筆期望值大於 0，而且高於對照組。
  2. 2020–2026 七年中至少五年為正。
  3. 2026 年（正價差年代）單獨為正。
  4. 相鄰參數結果不翻負。
  5. 只看距結算 5 個交易日內（次月有量）的子樣本，結論相同。
- **不通過就停**，不靠加條件救。

## 研究 B：結算日收斂
- **標的**：結算日 13:00–13:30，近月期貨對最後結算價的差距。
- **資料**：需要歷次最後結算價（期交所，尚未下載）。
- **通過條件**：同研究 A 的 1、2、4 項；樣本只有約 83 個結算日，另外要求虧損最大的 3 天合計不超過全部獲利的一半。

## 已知限制
- 次月平常很冷清：日盤 285 分鐘裡只有約 170–200 分鐘有成交，一天約 650–1,000 口；結算前 3 天才放大。
- 夜盤不納入。
- 分鐘收盤價不是同一秒成交，價差有雜訊；要用實際逐筆資料複核。

## 定案補充（2026-11-20，跑研究 A 之前寫死）
依 Willy 11/20 原話：「券商端有近月價差單，下單方式就是複式」、「目的是作價差的收斂，可以是正逆價差，除權息季節很容易出現價差」。

- **方向**：兩個方向都做。價差比正常寬 → 賣次月、買近月；比正常窄 → 買次月、賣近月。
- **正常值**：同一組合約（同一個結算週期內）過去 N 個交易日的價差中位數，每天固定一次，不跨換月。候選 N＝3、5、10。
- **偏離門檻**：偏離 ÷ 波動（中位數絕對偏差 × 1.4826，下限 2 點）≥ K。候選 K＝2、3、4、6；K＝0.5 當對照組。
- **成交**：訊號出現後，等下一個兩邊都有成交的分鐘才進出場，不用訊號當下那一分鐘的價格。
- **出場**：價差回到正常值；或持有滿 3 個交易日；或結算前一天收盤前強制出場。結算日不交易。
- **停損**：第一版不設，另外列出最大單筆虧損。
- **成本（主口徑）**：期交稅十萬分之 2，兩腳、進出各一次；加滑價每腳每邊 1 點（來回共 4 點）。手續費【待確認】，另列滑價 0 點與 8 點兩種情況。
- **單位**：一組＝近月、次月各 1 口，績效用「點」表示。
- **另外列出**（不列入通過條件）：除息季（5–8 月）與其他月份分開。

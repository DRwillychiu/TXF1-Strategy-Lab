## 3. ★ 三個必須知道的可比性限制

### 3.1 回測結束日會前移 —— 這是最大的一個

專案規範是「回測 2020/01/01 ~ **今天**」。所以：

- v0.5（07-10）的樣本結束在 2026-07-10
- v1.18.0（08-10）的樣本結束在 **2026-07-30**（最後一筆成交）

而 **119 筆裡有 93 筆落在 2026 年**。相隔三週的兩版，晚的那版多吃到的資料
可能就是好幾筆大單。

**因此：**

| 比較 | 可信度 |
|---|---|
| v1.11.0 → v1.15.0（08-02 ~ 08-06） | 高，同為 129 筆基底 |
| v1.15.0 → v1.18.0（08-06 ~ 08-10） | 高，相隔 4 天 |
| **v1.4 → v1.11.0（07-18 ~ 08-02）** | **低，中間隔兩週且機制大改** |
| **v0.5 → v1.5（07-10 ~ 07-26）** | **低，不可視為純機制效果** |

### 3.2 夏普比率在 v1.15.0 前後不同尺度

v0.5 記 Sharpe **0.463**、v1.4 記 Sortino 0.979；
v1.15.0 起記 Sharpe **0.1429**、v1.18.0 記 0.1623。

**差三倍以上，不是策略變差，是計算基準不同。**
`v1.15.0 之前的夏普／索丁諾不得與之後的並列比較。`
可比的只有 v1.15.0 → v1.18.0 這一段（同一份 MC12 報告欄位）。

### 3.3 筆數基底變過三次

`106 → 109 → 129 → 119 → 118`

- 106 → 109：v1.3 時間護欄
- 109 → 129：機制改動＋樣本延長（兩者無法分離）
- **129 → 119：v1.16.0 缺口濾網（純機制，同日對照，可信）**
- **119 → 118：v1.18.0 尾盤截止（純機制，同日對照，可信）**

## 5. 出場端 vs 進場端

| | 版本數 | 淨利貢獻 | 性質 |
|---|---|---|---|
| 出場端 | 4（v1.12–v1.15） | +283,600 | 保本 → 移動停利 → 結構停利 → 參數溯源 |
| 進場端 | 3（v1.16–v1.18） | **+336,800** | 缺口濾網 ＋ 兩項前瞻性補洞 |

**而且進場端的 +336,800 幾乎全部來自一次改動**（v1.16.0 的 +379,600）。

**這一次改動成功的原因不是找到預測因子，是修補了一個結構性缺陷** ——
時段第一根的 `v_Slope` 因 `[1]` 指向上一時段而失效。

Phase 2 結構研究（2026-08-08）已實測否決「增加預測性濾網」這條路：
八個結構量加兩個斜率對照組全部重疊，**進場訊號通過自己的閘門後不再帶有殘餘資訊**。

> **目前進場端唯一被證實有效的方向，是找出並修補機制缺陷。**

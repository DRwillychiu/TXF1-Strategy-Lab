> 這不是「桌機圖表少 11,909 根」的那件事。那件事在
> `S16S_DESKTOP_BASELINE_20260901.md` 第 1 節，講的是 **MC12 圖表**。
> 本檔講的是 **Python 用的 CSV**，兩台機器的行數完全相同、頭尾同一根，

## 2. 為什麼沒有任何東西叫出來

```
.gitignore:14   scripts/research/s16s_5min.csv
.gitignore:16   scripts/research/s16s_5min.csv
```

CSV 不進 git，兩台機器各自持有。同樣 **421,513 列**、同樣起 `20190102 0850`、
同樣訖 `20260822 0500` —— 所有看得見的表面特徵都相同。

差異方向有正有負（P45 少 14，P41 多 49），所以不是「一邊資料比較多」，
而是**某些根的 OHLC 或 bars_in_sess 不同** —— 像是其中一份是資料商修正過後重抓的。
無法從這一台判斷哪一份比較正確。

## 3. 已裝的護欄

`s16s_eleven_scan.py` 新增 `fingerprint()`，把 CSV 的**列數與 md5** 印出來並寫進 json：

```
CSV  421513 rows  md5 47e4054ff31b086df392bb3022e90e03   <- 筆電
```

沒有這個指紋的數字，跨機器不能比。下一次不一致會是吵的，不是靜的。

# Strategy Text Description SOP

**建立日期**: 2026-07-13
**用途**: 所有策略的純文字說明標準格式，適用於老闆報告、策略歸檔、團隊溝通
**適用範圍**: 所有 promoted / 待 promote 的策略
**參考實例**: `strategies/research/S16_MACrossShort/S16_S_STRATEGY_TEXT_20260713.md`

---

## 一、流程 SOP

### Step 1 — 取得績效數據
- 向用戶索取 MC12 回測 XLS 檔案
- 用 Python `pandas.read_excel()` 讀取（二進位 XLS 不可用 Read tool）
- 逐項萃取數據填入模板

### Step 2 — 數據交叉驗證
- 模板所有數值必須與 XLS 原始值逐項比對
- 呈現驗證表（項目 / 模板值 / XLS 值 / 狀態）
- 全項 OK 後才進入下一步

### Step 3 — 撰寫完整版
- 先呈現績效區段（依模板格式）
- 再呈現策略說明區段（8 章）
- 整份給用戶逐段校正

### Step 4 — 撰寫精簡版
- 從完整版濃縮
- 用戶確認後鎖定

### Step 5 — 存檔 + Git
- 完整版 + 精簡版存入策略目錄
- 檔名: `<策略代號>_STRATEGY_TEXT_<YYYYMMDD>.md`
- Commit + Push

## 二、完整版模板

### A. 績效區段

```
策略: <策略名稱>
商品: TXF1 台指期
方向: <純做多/純做空>
操作週期: <5分K/1分K/日K>
適合行情: <趨勢盤/盤整盤/波動盤>
回測期間: <起始日>-<結束日>(約X.X年)
初始資金: 100萬
操作部位: 1口大台
成本設定: 滑價 1,000/口(代手續費)，共計 <總滑價>

── 報酬 ──
淨利: <值>
總報酬率(ROI): <值>%
年化報酬率: <值>%
CAGR: <值>%

── 風險 ──
MDD: <值>% (虧損<金額>)
恢復因子(淨利/MDD): <值>
最大單筆虧損: <金額> (佔初始資金<值>%)
最大連續虧損: <次數>次 / <金額> (<值>%)
最長持平期間: 約<期間>
夏普比率: <值>(月) / 約<值>(年化)
索丁諾比率: <值>

── 交易品質 ──
交易次數: <值>次
勝率: <值>%
獲利因子: <值>
賺賠比: <值>
平均每筆損益: <值>
持倉僅<值>%，多數時間空手等待

補充:
1. 恢復因子<值>：策略每承受1元最大回檔，換回<值>元獲利。
2. <夏普率相關說明，依策略類型調整>
3. <索丁諾比率相關說明>
```

### B. 策略說明區段（8 章）

**【一、策略定位】** — 1-2 句白話文定位
- 策略性格（狙擊手/波段/趨勢跟隨/...）
- 主場行情
- 保險成本來源
- 交易頻率
- 持倉時間

**【二、進場邏輯】** — 列點式
- 逐條列出所有進場 gate
- 合規檢查（結算日/假日/資料過期/手動停止）
- 白話文總結（非本科也能讀懂）

**【三、出場邏輯】** — 按 Priority Chain 層級
- 每層說明: 層級名稱 / 觸發條件 / 實測筆數與績效 / 角色定位
- 白話文說明每層的實戰意義

**【四、出場實測分佈】** — 表格
- 每個 exit signal 的: 筆數 / 淨損益 / 勝率 / 均損益 / 角色
- 核心結構總結（alpha 來源 vs 控損成本）

**【五、適合與不適合的行情】** — 列點式
- 適合: 3-4 種具體行情場景
- 不適合: 2-3 種，說明為何不適合但不會大虧

**【六、關鍵設計決策】** — 問答式
- 每個重大設計選擇用「為什麼...?」開頭
- 說明理由 + trade-off

**【七、風險揭露】** — 列點式
- 具體數字（最大連敗/持平期/參數風險）
- 操作者心理準備要求

**【八、組合定位】** — 表格
- 配置上限 / 帳戶配置 / 組合角色 / 與其他策略相關性

## 四、撰寫原則

1. **白話文優先**: 非本科可讀，不用術語堆砌
2. **數據必有出處**: 所有數字來自 MC12 XLS，不可憑記憶
3. **列點式為主**: 避免長段落
4. **策略類型適性**: 補充說明依策略類型調整（低勝率/高勝率/波段/日內）
5. **出場必含停利+停損**: 不可只寫停損，停利是核心說明
6. **精簡版不省略關鍵**: 賺甚麼錢/進場/出場三段不可合併或省略

## 六、敘事版（3 分鐘版）— 2026-07-18 用戶 ruling 新增

**觸發詞**：用戶說「給我簡潔版本」「純文字版本」「敘事版」「白話說明」時，一律產出本格式。
**目標**：讓完全不懂這份策略的人在 3 分鐘內理解清楚。是講給人聽的故事，不是濃縮審計檔。
**位置**：STRATEGY_TEXT 的 PART 0（在精簡版之前）。

### 結構模板（6 段固定順序）
1. 這是什麼 + 賺什麼錢（一句經濟邏輯：為什麼這種行情有錢賺）+ 組合角色
2. 怎麼進場（條件白話化 + 每個條件「代表市場發生什麼事」的翻譯句 + 出手頻率）
3. 怎麼出場（各層防線一層一句，標明哪層是主要獲利來源）
4. 設計鐵則（不做什麼 + 為什麼）
5. 成績單（翻譯過的數字 + 誠實心理成本）
6. 目前狀態（階段 + 下一關卡）

### 「誰都懂」濾網（違反任一條 = 重寫）
1. **零未解釋術語**：ZLEMA/ATR/死叉/獲利因子等要嘛同句內建翻譯，要嘛改白話
   （「賺賠比 5.1」→「贏一次抵五次虧損」；「2.5 倍 ATR」→「帳面獲利夠大之後」）
2. **禁夾英文行話**：lumpy/whipsaw/regime → 損益大小月分明/洗盤/行情型態
3. **必有經濟邏輯句**（為什麼這種行情有錢賺）
4. **數字上限約 12 個**（只留讀者記得住的）
5. **禁括號證據註解**（證據住在 PART 1/2 與 DEPLOYMENT，敘事版不自我辯護）
6. **長度 700-900 字**，每段一個概念
7. **誠實揭露不可少**（心理成本、保險費期、紀律要求）

- ✅ 合格範例：`strategies/research/S16_MACrossShort/S16_S_STRATEGY_TEXT_20260718.md` PART 0

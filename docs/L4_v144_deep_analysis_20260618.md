## 二、L4 在賺什麼錢、虧什麼錢

### 2.1 出場標籤揭露真相

| 出場標籤 | 筆數 | 淨利 | WR | 平均 |

| **CS_BreakExit** | 20 | **-377,800** ❌ | **0%** | -18,890 |
| Stop Loss (MC engine) | 1 | -17,400 | 0% | -17,400 |

### 2.2 矛盾與解釋

**矛盾**：CS_SL 是「停損」標籤，卻是主要賺錢來源（+500K）！

**解釋**：L4 的 SL 不是傳統 SL，是**「Trail 跟上來的 SL」**：
- 進場時：SL = Box_Top + ATR × 2 倍（在反方向）
- 持倉中：Trail 啟動後，SL 跟著價格下移
- **65% 的 CS_SL 觸發時**：價格已大幅下跌，Trail 帶 SL 到賺錢區，反彈到 SL 出場 = **鎖利**

**真正的「停損」反而是 CS_BreakExit**：
- CS_BreakExit = 「盤整 box 真的向上突破成功」
- 20 筆全部 0% WR = 假突破思維被市場打臉
- 每次 -18,890 = 真實的「策略 thesis 失敗」損失

### 2.3 核心 alpha 與失敗模式

```
CS_SL  + CS_SP  + CS_TimeExit + CS_BreakExit + CS_Holiday
+500K  +179K    -22K          -378K           -23K        = +239K

賺錢來源：SL Trail + SP 鎖利  = +679K
虧錢來源：BreakExit 假突破真的成功 = -378K
```

**淨贏 +239K 的本質**：
- 多數時候「假突破失敗論」成立 → 賺錢
- 少數時候「假突破成功了」→ 大虧
- 賺贏次數多，但虧的單筆大

**6 年：3 賺 3 賠 / 累積 +239K**

### 3.2 兩個極端年度的真相

#### 2022 為何賠錢？（核心發現）
- 2022 是台股**熊市**（從 18,000 跌到 13,000）
- 應該是 L4 做空的「黃金年」
- 但 31 筆只賠 -51K = 大失所望
- **真相**：熊市中「向上假突破」很多，但**多數都繼續跌**（真趨勢）
- L4 邏輯：「假突破會反彈回跌」→ 結果「假突破真的成功 → 真的繼續漲了一段才反轉」→ SL 觸發在賠錢位置

→ **L4 的反轉空邏輯在強趨勢熊市反而失靈**！

#### 2025 +294K 怎麼來的？（單一事件依賴）
- 2025-04-07 11:00 進場 → 當日 CS_SL +273K
- **這就是川普關稅震撼**：4/7 開盤暴跌
- L4 抓到一個盤整 box 然後價格暴瀉
- Trail 帶到大利潤後反彈 → CS_SL 鎖利 +273K
- 整年 +294K 中，**單筆貢獻 93%**

→ **2025 績效靠黑天鵝事件，不可重複**

### 3.3 對單筆事件依賴的危險

若把 2025-04-07 那筆從統計拿掉：
```
6 年總淨利：+239K - 273K = -34K
年化：-0.5% (虧錢)
```

**L4 的「真實長期表現」其實是 6 年微虧**，靠一次黑天鵝救命。

## 四、進場邏輯解析

### 4.1 五層過濾鏈

```
1. Daily MA 過濾 (Daily_FastMA(20) vs SlowMA(60))
   → 只有特定多空結構時允許做空

2. 60M 盤整偵測 (Lookback_Bars=15, Shrink_Rate=0.7)
   → 過去 15 根 60M K 的範圍收縮 70%

3. Weekly MA 方向 (Weekly_MA_Len=48)
   → 對齊週線方向

4. 假突破偵測 (Trap_Zone)
   → Box_Top 之上後回測

5. Time_Limit_Bars=6
   → 假突破後 6 根 60M 內才允許進場（避免太晚進）
```

### 4.2 出場機制

```
P0 (互斥優先序):
  Kill > RegistryEnd > Holiday > Settlement (Constitution v1.2)

P1 Disaster Control:
  CS_BreakExit — Box 真的破壞且向上延續

P2 Time Stop:
  CS_TimeExit — 60 根 60M K 都沒大行情

P3 Stop Loss:
  CS_SP > CS_BE > CS_SL (tightest first)
  其中 CS_SP / CS_BE 預設關閉（v14.2 A/B 失敗）
  實際只剩 CS_SL = Frozen Stop + MA55 Trail
```

### 4.3 v14.4 新加 P3b
```
SetStopLoss = AbsValue((Box_Top + ATR*2.0) - Close) * BPV
              when MarketPosition >= 0 (freezes when short opens)
```
→ Entry bar 立刻有 engine 級 stop，補上 IOG=false 的漏洞

## 六、適合的賺錢行情

### 6.1 ⭐⭐ 最佳行情：**盤整末期 + 黑天鵝下跌**

特徵：
- 60M 圖表上連續 15 根 K 範圍收縮 70%
- 突然向上假突破（散戶 FOMO）
- 隨即出現「驅動性下跌事件」（如 2025-04 川普關稅）
- 暴跌 → Trail 帶利 → 反彈 → SL 鎖利

**範例**：
- 2025-04-07 +273K
- 2024-08-22 +57K（日銀升息暴跌）
- 2022-07-05 +47K（CPI 暴跌）

### 6.2 ⭐ 次佳行情：**盤整 → 假突破 → 緩跌**

特徵：
- 盤整突破後散戶追多套牢
- 機構慢慢出貨
- 跌幅 1-3% 內，Trail 抓到中段

### 6.3 一般行情：**短期波動回到 box 中線**

CS_SP 100% WR 主要在此情境觸發。

## 七、會虧錢的行情

### 7.1 ❌❌ 最危險：**強單邊上漲（真突破）**

- 盤整 box 真的向上突破成功
- 散戶不只 FOMO，是真實趨勢

**範例**：

- 2021-10-14 -43K（台積電 ADR 暴漲）
- 2022-10-18 -37K（10 月反彈起點）

- 2022 全年虧損就是這原因

- L4 預期「反彈會出現 → 鎖利」結果「沒反彈 → SL 在賠錢位置」

→ **L4 在強趨勢中（兩個方向都不利）**

## 十、改進方向建議

### 10.1 🔴 必須解決：CS_BreakExit 巨虧 -378K

問題：20 筆 0% WR = 策略 thesis 完全失敗時

**方向 A**：加入「Daily MA 趨勢過濾強化」
- 若 Daily MA Fast >> Slow（強多頭）→ 不做空
- 預期可過濾掉 50% CS_BreakExit

**方向 B**：BreakExit 速度
- 目前 BreakExit 觸發在 60M Close 突破
- 改為 15M 突破觸發 → 提早出場
- 預期可降低平均虧損 -18.9K → -12K

**方向 C**：仿 L3 模式加「動態 SL 收緊」
- 若 Box 已被突破但還沒進入 BreakExit
- 提前把 SL 拉到 Box_Top + 0.5 ATR（更緊）
- 減少 BreakExit 觸發前的虧損

### 10.2 🟡 中等優先：降低單一事件依賴

問題：2025 +294K 93% 靠 1 筆

**方向**：「分批出場機制」
- Trail 帶到 +100K 時，先平 50%
- 鎖定大部分利潤
- 剩餘 50% 跟 Trail 跑

預期：把「+273K 單筆」變成「+150K + 連續小單」分布，降低事件依賴。

### 10.3 🟢 微優化：Cooldown 調整

目前 Cooldown_Bars = 8（每次出場後 8 根 60M K 不再進場）
評估：是否可降到 4-6 增加樣本（13 筆/年 → 18-20 筆/年）

二執行層能力疊加

每一支只新增它自己需要的能力。L2 通過時執行層只需最小集合，到 L5 才需要多腿部位，到 L1 才需要 tick 生命週期。

engine/context.py 的資料模型仍須從第一天就以 tick 為原生、bar close 為特例。否則做到 L1 要回頭重構，前四支已通過的對帳全部重跑。

L2TrendShort · 趨勢空頭移植順位 1　·　Holiday_Flat_Time 300

獨有特徵

  • 週線在 60M 流內自行合成
  • 不需 quotes/align

  • D-5 優先級 4 遮蔽 5 與 6，自訂停損單不再掛出高
  • D-6 13:45 那根歸夜盤，出場延到 15:00 開盤中
  • D-8 標頭兩組績效矛盾 77/2.67M vs 78/2.88M高

五看似相同其實不同

程式碼形狀幾乎一致、語意不同。這是移植最容易踩的一類，因為照抄看起來是對的。

項目一邊另一邊後果
箱體失效判定L3 L4 用 Close of Data2L5 用 High/Low of Data2L5 的箱體脆弱得多，影線碰到就終止
SL_Pct 上限錨點L1–L4 錨在 CloseL5 錨在 v_Box_Btm未見註解說明理由
SetStopContract 位置L1 L4 L5 頂層無條件L2 在條件內、L3 在盤整判斷內L5 註解寫 must be outside conditional
箱體收縮率L3 是 0.1（極窄）L4 是 0.7、L5 是 0.6同形狀，鬆緊差七倍
週線濾網邏輯L1 用 ORL5 用 ANDL1 註解：趨勢策略需在起點就進場，AND 會錯過早期多頭
深夜封鎖區間L4 是 200–500L5 是 400–500L4 夜盤淨 −120,800、L5 淨 +87,800，方向相反
凍結對象L1 L2 L3 凍結最終價位L4 L5 凍結中間變數當中間變數在持倉期間變動時兩者分岔

六共用範圍

原規劃假設假日偵測 / 結算偵測 / 強制平倉為五支共用。逐份比對後：共用的是資料與偵測，不共用的是時間常數與執行結構。

元件共用說明
Holiday_Tail 63 筆陣列值✓五份逐筆相同
結算日偵測✓DayOfWeek=3 and DayOfMonth in [15,21]
Settlement_Flat_Time✓五支皆 1230
Registry_Valid_Until✓五支皆 1270101
註冊表過期 fail-safe✓邏輯一致
Holiday_Flat_Time✗345 / 300 / 415 / 415 / 415，隨網格而異
初始化守衛✗L1 用 Init_Done，其餘用 CurrentBar = 1
假日偵測區塊✗L1 包在 BarStatus 內，其餘在頂層
強制平倉區塊結構✗四種不同寫法
若照原規劃把整個區塊抽成共用模組，會改變其中至少三支的行為。
tradecal/ 可抽出：註冊表、假日偵測、結算偵測、過期判定。
不可抽出：Holiday_Flat_Time、強制平倉的下單區塊。

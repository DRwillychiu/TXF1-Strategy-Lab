## 二、10/5 08:00～08:40（開盤前）

每一支依序做：

1. 關閉該圖自動交易
2. 到券商確認該策略沒有委託、沒有部位
3. 用上架載入名編譯定案版（L1 `WILLY_ATR_LONG_60M`、L2 `Trendbearish_V1`、L3 `STRATEGY_WILLY_LONG_C`、L4 `STRATEGY_WILLY_SHORT_CTEST2`、L5 `STRATEGY_WILLY_LONG_BREAKOUT_C`）
4. 圖表重新計算後核對
   - 參數數量：L1 32、L2 41、L3 23、L4 29、L5 41，全部預設值（L5 `State_Start_Date` 1261005）
   - IOG：L1 開，其他關
   - 策略屬性：2 口、滑價每口 1,000、手續費 0
   - 圖上最後狀態必須空手（有部位 → 不開自動交易，等圖上出場）
5. 下單大師確認對應（跟訊號模式要核對委託名稱）
6. 開啟自動交易；起始部位視窗輸入 0

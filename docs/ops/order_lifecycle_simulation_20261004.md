# 下單全流程模擬：訊號 → 成立 → 通知 → 委託 → 成交 → 回報 → 出場（2026-10-04 11:05）

> 目的：10/5 上線前，把一筆交易從訊號到平倉的每一步講清楚，並列出每一步出錯時怎麼發現、怎麼處理。
> 依據：五支定案版程式、MC 自動交易頁截圖（10/3 20:14）、`DEPT_OPS`（9/30 下單路徑）、L3 v18.2 上線前驗證 B30。
> 標「未確認」的地方要在上線前或上線第一天確認。

## 一、結論（先做這 6 件）

1. **下單路徑已確認只有一條**（Willy 10/4 11:15）：實盤下單全部由下單大師送券商；MC 不直接下到實盤帳戶 → 重複下單風險解除。
2. **下單大師內建「實際部位 vs MC 部位」核對，不一致時只自動提醒、不會自動補單**（Willy 10/4 11:32、14:09）
   - 推論：下單大師是逐筆跟 MC 委託下單（跟訊號），所以委託名稱要全部對應 → 清單：`docs/ops/order_names_L1-L5_20261004.md`（87 個，含引擎停損）
   - 雙停損同時成交造成的反向部位不會自動修正 → 收到提醒後人工處理（見第四節「提醒處理」）
   - 仍待確認：核對頻率；提醒送到哪裡
   - 下單大師的模式決定剩下的風險〔未確認〕：
   - 跟部位（下單大師讓券商部位 ＝ MC 策略部位）：委託名稱不用對應；兩張出場單同時觸發也只會平到 0；TP1、分批出場自動處理
   - 跟訊號（MC 每送一張委託，下單大師就下一張）：五支 82 個委託名稱都要對應（L1 12、L2 17、L3 8、L4 11、L5 34）；雙停損同時觸發會變反向部位
   - 同時要確認 MC 自動交易接的經紀商是什麼（10/3 L1 屬性頁顯示 Interactive Brokers；若是模擬帳戶，MC 收到的成交回報是模擬的，不是券商真實成交）
3. **Kill 開關不要拿來緊急平倉**：改參數會讓 MC 從頭重算，歷史裡 Kill 一直是開的 → 圖上部位變成 0，**不會送出平倉單**（推測，模擬帳戶驗證）。緊急停用＝關自動交易＋到券商手動平倉。
4. **停損只存在本機**：自動交易頁停止單、限價單都是「使用本機」，期交所也沒有原生停損單 → MC、電腦、網路任何一個斷掉，持倉就沒有停損。持倉時電腦不能休眠；斷線超過 1 分鐘就手動處理。
5. **雙停損同價**：L1（引擎停損＋`TL_SL`）、L2（引擎＋暴跌停損＋硬停損）、L4（TP1 後 `CS_SL` 仍是 2 口）可能一次送出兩張出場單 → 部位反向。上線第一週每筆成交後核對券商部位。
6. **兩個 MC 設定建議改**（你決定）：「關閉自動交易於 100 拒絕委託」改成 3；「未收到委託最終狀態就停止自動交易」改成勾選。

## 二、整條路徑（每支策略都一樣的 7 步）

| 步驟 | 在哪裡發生 | 正常應該看到 |
|---|---|---|
| ① 訊號出現 | MC 圖表，K 棒進行中 | 價格接近條件（還不算數） |
| ② 訊號成立 | K 棒收盤那一刻（L1 進場也是收盤；L1 出場停損是逐 tick） | 策略產生委託（市價單、停損單或限價單） |
| ③ 通知 | MC → TG | TG 收到訊號訊息 |
| ④ 委託 | MC → 下單大師 → 券商（Willy 10/4 確認全部經下單大師） | 券商端出現委託；本機停損／限價單留在 MC，觸價才由 MC 發出，再經下單大師送券商 |
| ⑤ 成交 | 券商 | 成交 2 口（L4 TP1、L5 TP 會是 1 口） |
| ⑥ 回報 | 真實成交回報到下單大師與券商；MC 的成交回報來自 MC 自己接的經紀商〔未確認是否為模擬〕 | 下單大師／券商部位 ＝ MC 策略部位 |
| ⑦ 出場 | 重複 ② ～ ⑥ | 平倉後 MC、券商都是 0 |

各支策略的差別：

- L1：IOG 開。進場在 45 分 K 收盤發市價單；停損、獲利保護逐 tick 檢查；結算、假日強制平倉實際在 11:46、03:01 成交（比字面早 45 分）。
- L2：IOG 關，60 分 K 收盤才算。日盤停損用停損單（本機），夜盤停損等收盤確認後才送市價單。
- L3：IOG 關，15 分 K。箱底買進停損單通常在市價之下 → 本機觸發後送市價，實際在下一根開盤成交。
- L4：IOG 關，15 分 K。進場市價；TP1 是 1 口限價（本機）；停損單 2 口直到收盤才改成 1 口。
- L5：IOG 關，15 分 K。兩條腿（底、中線）各自的出場單只出它那條腿（`from Entry`）；TP 1 口限價。

## 四、每一步出錯時：怎麼發現、怎麼處理

### ① ② 訊號出現與成立
- 報價斷線或延遲 → K 棒不收、沒有訊號
  - 發現：圖上最後一根的時間落後時鐘超過 1 根
  - 處理：重新連線報價；**持倉中不要重新載入圖表**（會從頭重算）
- 圖表設定錯（Data1／2／3 週期、時段、IOG、口數）→ 訊號和回測不同，不會報錯
  - 發現：上線前別名回測對不上預期數字（`docs/ops/chart_settings_L1-L5_20261003.md`）
  - 處理：照設定表改正；改完再回測一次
- 即時讀到還沒收完的日 K／週 K（F8）→ 實盤訊號和回測差一根
  - 發現：收盤後重新整理圖表，若歷史訊號位置改變，就是 F8
  - 處理：記錄日期和策略，上線後統一處理（不在 10/5 前改程式）
- 圖表重新計算（改參數、重新編譯、資料重新下載）→ 圖上部位和券商不同
  - 發現：MC 自動交易視窗顯示部位不一致
  - 處理：只在空手時重算；持倉中被迫重算 → 先關自動交易，用「起始經紀商留倉部位」輸入實際部位再開

### ③ 通知
- TG 沒收到 → 只影響通知，不影響下單
  - 發現：MC 委託頁有委託、TG 沒訊息
  - 處理：以 MC 委託頁和券商為準；當天收盤後查 TG 設定（R2 心跳未建）
- TG 重複或延遲 → 不要依 TG 手動下單，以券商為準

### ④ 委託
- 下單大師沒開、對應表錯、帳戶錯 → 券商沒有委託或下錯邊
  - 發現：TG 有訊號、券商沒委託（或方向相反）
  - 處理：立刻手動在券商補單或平倉；下單大師對應表逐一核對委託名稱
- 重複下單：路徑已確認只有下單大師（10/4），這一項只剩「下單大師自己重送」的可能
  - 發現：券商部位 ≠ 2 口
  - 處理：手動平掉多出來的；查下單大師紀錄
- 券商退單（保證金不足、漲跌停、休市、商品代碼錯）
  - 發現：MC 委託狀態「拒絕」
  - 處理：查原因；MC 設定「100 次拒絕才關自動交易」太寬，建議改 3
- 市價單 30 秒沒成交被取消 → 策略以為有送單
  - 發現：MC 委託狀態「已取消」
  - 處理：依當下價格決定手動補單或放棄，並記錄
- 本機停損單：MC 或電腦停住 → 停損單沒有送出
  - 發現：MC 停止回應、電腦休眠、網路斷
  - 處理：持倉時保持電腦與網路在線；斷線超過 1 分鐘就手動在券商下停損或平倉

### ⑤ 成交
- 只成交 1 口 → MC 以 1 口計算出場
  - 發現：MC 部位 ±1、券商委託剩 1 口
  - 處理：決定補單或撤單；「部分成交轉市價」目前關，維持
- 跳空成交在停損外 → 單筆虧損超過計畫
  - 發現：實虧 ÷ 計畫 > 120%
  - 處理：照紀律原則 ⑤ 記錄檢討；程式管不到跳空
- 漲跌停鎖死 → 出場單成交不了
  - 處理：開盤前手動評估；無法自動處理

### ⑥ 回報
- 真實成交和 MC 以為的成交不同（MC 若接模擬經紀商，真實的部分成交、退單、滑價 MC 都不知道）→ MC 照自己的部位繼續掛出場單
  - 發現：下單大師／券商部位 ≠ MC 策略部位
  - 處理：以券商為準，關自動交易，手動處理後再開；下單大師若是「跟部位」模式，會自動把券商拉回 MC 部位，要確認這是你要的行為
- MC 自己的成交回報沒回來（SA 模式）→ MC 以為空手 → 不會掛停損
  - 處理：建議勾選「未收到委託最終狀態就停止自動交易」
- MC 部位 ≠ 券商部位
  - 發現：下單大師內建核對（第一道）；每天收盤後人工核對 13:50、05:05（第二道，上線第一週保留）
  - 處理：以券商為準；下單大師若會自動補單，先確認它補的方向是 MC 部位而不是錯的那一邊，再決定要不要關自動交易
- 下單大師自動同步遇上 MC 重新計算：MC 部位突然改變 → 下單大師照著下單，可能平掉或開出真實部位
  - 處理：持倉中不重算圖表；必要時先停下單大師的同步，再重算

### ⑦ 持倉與出場
- 兩張出場單同時成交（L1 H1、L2 F3、L4 F2）→ 部位反向
  - 發現：券商部位方向和策略相反
  - 處理：立刻平掉反向部位；記錄是哪兩張單
- 強制出場（假日、結算）市價單沒成交
  - 發現：時間到了還有部位
  - 處理：手動平倉；假日前一晚一定要確認空手
- 週末、連假跳空 → 沒有任何程式防護
  - 處理：只能事前決定要不要帶部位過週末（目前不改）
- 緊急停用
  - 正確做法：關閉該圖自動交易 → 到券商撤委託、平倉 → 確認 MC、券商都是 0
  - 不要用 Kill 參數平倉（見結論第 3 點）

## 四之二、下單大師「部位不一致」提醒處理（人工，5 分鐘內）

1. 看是哪一支策略、MC 部位多少、券商部位多少
2. 以券商為準，判斷原因：雙停損同時成交（反向）、部分成交、漏單、退單
3. 關閉那一支的自動交易（避免 MC 再送單）
4. 在券商手動把部位調成 MC 應有的部位（通常是平掉多出來或反向的口數）
5. 確認 MC、下單大師、券商三邊一致後，再開自動交易
6. 記錄：時間、策略、原因、處理方式、損益影響

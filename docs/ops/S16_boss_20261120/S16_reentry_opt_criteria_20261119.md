# S16 被洗出場後再進場：候選與驗收標準（看結果前寫死，2026-11-19）

Willy 11/19：「今天如果被洗出場，我還會重複進場?假設行情又照著預期往下走?」

## 現況（程式事實）
B（v1.28.1）有再進場，`ReEntry_On 1`：
- **何時備妥**：任何出場後備妥（armed），價格設在原進場價。
- **何時解除**：ZLEMA 快線 ≥ 慢線、黃金交叉，或出現新的死亡交叉。
- **怎麼下單**：每一根都要同時符合下面 4 個條件，才在下一根掛「原進場價的賣出停損單」：
  1. 結構：快線 < 慢線（`ReEntry_Structure_Gate 1`）
  2. 斜率：這一根跌速 > 每分鐘 0.05%，也就是 5 分 K 一根要跌 0.25%（`ReEntry_Slope_Gate 1`）
  3. 收盤 ≥ 原進場價（`ReEntry_Close_Gate 1`）
  4. 不是多頭 K 棒型態
- **同時段波動門檻**：不套用在再進場上。

## 診斷（`S16_reentry_diag_20261119.md`，2020 起，推論）
- 共 84 筆虧損出場，77 筆是 20 分鐘沒賺就走（QuickStop_Time）。
- 出場後 4 小時內：
  - 62 筆價格回到原進場價。
  - 只有 5 筆照預期跌到原停利 −2.3%，其中 B 已再進場 3 筆。
- 斜率條件擋掉 41 次，是最主要的阻擋原因。
- 簡易估算：回到原進場價就再空，合計 −88,260。

## 候選（只動 .pla 現有輸入，MC 不用改程式就能實測）
| 代號 | 改法 | 意思 |
|---|---|---|
| R0 | `ReEntry_On 0` | 關掉再進場（對照） |
| R1 | `ReEntry_Slope_Gate 0` | 再進場不要求急跌那一根 |
| R2 | `ReEntry_Close_Gate 0` | 價格已在原進場價下方也可以再空：停損單變成下一根開盤市價 |
| R3 | `ReEntry_Slope_Gate 0`＋`ReEntry_Close_Gate 0` | 兩個都放 |
| R4 | `ReEntry_Structure_Gate 0` | 推論：和 B 相同，因為快線 ≥ 慢線時再進場已經解除；只用來確認 |

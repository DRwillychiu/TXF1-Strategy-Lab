# 第 4 季優化專案規劃（2026-10-01 建立；日期為暫定，待 Willy 確認）

> 依 Willy 10/1「進度規劃」模板（`docs/policies/CONVERSATION_PROTOCOL.md` §4.7）。主目標：L5 → L4 → L1 → L2 依序降低**最大連虧與 MDD**（淨利次要）；四支完成後才做 L3 進場端。

## 一、專案開啟前

### 1. 工具
- MC9（實盤）／MC12（研究）；每支策略一份「開關版」研究程式（預設全關 ＝ 上架版，回歸必須逐筆相同）
- `tools/`：`verify.bat`（G0／G0b／G1）、`check_order_names.py`（出場單名稱）、評分腳本（樣本內／樣本外／逐年／前 10 大）
- 1 分鐘資料 2019/1～2026/9/24（估算與逐根模擬用）；MC 逐筆交易報表

### 2. 遊戲規則
- 績效只認 MC 報表；估算一律標「估算」，只用來決定要不要寫開關
- 樣本內 2021/9/16～2026/6/16；樣本外 2026/6/17～9/17
- 首要：最大連虧與 MDD；淨利次要（L5 9/30 起適用，L4／L1／L2 沿用，鎖定前再確認）
- 每個改動是一個開關、預設關；先單項、再組合；參數取前段結果中出現最多次的值
- 防過擬合：前推測試（逐年）＋參數鄰近穩定度；改善不能只集中在單一年份而前面年份變差
- 每批跑法附「參數核對串」；新程式先過 G1 與出場單名稱檢查才交 MC

### 3. 項目切分

| 項目 | 功能／系統 | 預期效果 |
|---|---|---|
| L5 收尾 | v19.15 過擬合檢查、回歸、空跑、10/5 上架 | MDD −46%、最大連虧 −40%（對 v19.9，MC） |
| L4 盤整空 | 歸因 → 出場端（停利／保本）→ 進場端（盈虧比／停損上限） | 降低最大連虧與 MDD |
| L1 趨勢多 | 同上；先鎖定 L1 規則、取得 L1_0 報表；注意 IOG = true（逐 tick） | 同上 |
| L2 趨勢空 | 同上 | 同上 |
| L3 進場端 | 依 L5 經驗檢查盈虧比與停損上限 | 補齊整份策略 |
| 共用修正 | F8 日 K 讀取（探針結果）、F9 Kill 開關、F12 假日表 2027、F13 停用線寫進程式、R2 帳戶層 | 降低實盤與回測落差 |

### 4. 已知盲點與可能的反證
- 參數用含樣本外的資料挑選（L5 已發生）→ 一律加前推測試
- 改善集中在單一行情（L5 集中在 2026 高波動）→ 逐年表必附
- 日 K `[1]` 在回測讀到「最後收完那根的前一根」，即時是否一致未確認（F8）
- 研究圖與舊上架報表逐筆不同（L5 只有 105／174 筆相同）→ 每支先做同圖回歸
- 出場單名稱重複會讓 MC 中途停止（L5 已發生）→ 新版先掃描
- 跑法與實際參數不一致（L5 已發生一次）→ 參數核對串

### 5. 時間估計（每支策略）
| 步驟 | 估計 | delay 時 |
|---|---|---|
| 歸因（停損結構、先賺後賠、第一次進場） | 0.5 天 | +0.5 天 |
| 出場端測試（停利、保本） | 1 天 | +0.5 天 |
| 進場端測試（盈虧比、停損上限） | 1 天 | +0.5 天 |
| 驗證（前推＋鄰近＋回歸）＋ debug | 1～2 天（固定預留） | +1 天 |
| 空跑 | 2～3 個交易日 | 依實盤狀況 |

## 二、專案開啟後（10/1 09:23 更正：延後只到 10/4，10/5 全部上線）

### 每日規劃（10/1～10/5）
| 日期 | 主項目 | 要交付 | 需要 Willy 提供 |
|---|---|---|---|
| **10/1（四）** | L5 收尾：前推 3 窗、批次 Z、兩個回歸 → 判定；L4 歸因 | L5 定案版；L4 開關版程式 | L5 三份 CSV＋回歸報表；**L4_0、L1_0、L2_0 上架版報表（同一張研究圖、到 9/25）** |
| **10/2（五）** | L4：出場端（停利、保本）＋進場端（盈虧比、停損上限）＋驗證；L5 空跑第 1 天 | L4 定案版；L1 開關版程式 | L4 批次 CSV＋完整報表；L5 空跑紀錄 |
| **10/3（六）** | L1：同上（注意 IOG = true、45 分）；先鎖 L1 規則 | L1 定案版；L2 開關版程式 | L1 批次 CSV＋完整報表 |
| **10/4（日）** | L2：同上；全部文件、上架清單、同步包 | L2 定案版；10/5 上架步驟 | L2 批次 CSV＋完整報表 |
| **10/5（一）** | 上架：通過驗證的新版換上；沒通過的維持現行版 | 換版紀錄 | 三邊（TG、下單大師、券商）確認 |

- 每支策略的做法固定：歸因（停損結構、先賺後賠）→ 套用 L5 有效的四個開關（停利位置、保本、盈虧比門檻、停損上限）→ 單項 → 組合 → 前推＋鄰近驗證。
- 時間很緊：每支只有 1 天，沒有另外的 1～2 天驗證預留；驗證直接排進當天，當天沒過就維持現行版，不拖到下一天。
- L3 進場端檢查排在 10/5 之後。
- 紀律優先選參原則（Willy 10/1 16:27；L5、L4、L1、L2 全部適用）：①風險門檻從帳戶規則推出（單筆 3%、各策略停用線），不從回測最佳化挑；②結果相同時選較嚴的設定；③淨利增加不能拿來放寬風險限制；④每筆進場前最大預計虧損已知且有上限；⑤每筆平倉記錄「實虧 ÷ 預計」，超過 120% 檢討。
- 免空跑上架（Willy 10/1 16:10 選 A）：L4、L1、L2 只要四項全過就 10/5 直接上架——只改預設值、回歸逐筆相同、委託名稱檢查通過、WFA 與鄰近參數檢查通過；任一項不過就維持現行版。
- 每天早上匯報＋晚上匯報；項目一完成就立即匯報。

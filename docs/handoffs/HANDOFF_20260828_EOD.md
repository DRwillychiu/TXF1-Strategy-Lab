## 5. ★ 流程教訓：MC12 的數字何時才算數

同一份計數程式碼、同樣 421,455 根、同樣樞紐數：

| | P52 | 怎麼跑的 |
|---|---|---|
| 第一次 | **1,716** | 在已載入的研究上**手改 input** |
| 第二次 | **1,715**（＝參考值） | **重新匯入 + 預設值** |

計數器在第 672-687 行，第一個開關閘門在第 758 行——
**計數路徑結構上高於所有被改動的開關，設定碰不到它**。所以差異不是設定造成的。

**MC12 未完整重算是假設，未證實。** 但規矩可以直接用：

> **MC12 的數字只有在「重新匯入 .pla ＋ 完整重算」之後才算數。
> 在已載入的研究上改 input 跑出來的是草稿，不可寫進文件、不可當驗收依據。**

Build 260842 報 199 formations（對 202 短少 3）很可能是同一現象——
與「偵測條件在該版與現版之間可證明未改動」相符。

**代價**：今天為了那個差 1 追了三輪。先重新匯入再跑一次的話，一輪就結束。

## 2. Changed This Session

### G1 — BE_Cost_Pts 5 → 10（算術修正）

回測滑價設定是 **1,000 NTD 每口每邊**，非 CLAUDE.md 記載的 round-trip 1,000。

```
每口來回成本 = 2,000 NTD = 10 點（2,000 / 200）
舊值 5 點 → 出場毛利 1,000 NTD < 成本 2,000 → 每次淨損 -1,000/口
```

**實證**：v1.11.0 的 5 筆 BE 出場淨損益全部精確等於 -2,000 NTD（2 口），無一例外。
反推 10 筆交易的隱含成本亦全部精確 4,000 NTD。

修正後每筆 BE 出場 net 0。129 筆中僅 5 筆變動，Net 2,478,000 → 2,488,000。

> ⚠️ **CLAUDE.md 技術規格「滑價：1,000 NTD round-trip（單邊 500）」與實際回測設定不符，
> 差 2 倍。其他策略可能同樣受影響，需獨立審查。**

## 3. Decision Trail（含兩次錯誤修正）

### 3.1 MFE 分析預測「有效」→ 被實跑推翻

以 129 筆的 MFE/MAE 分析，判定 S16_S 大贏家是「乾淨單向噴出」
（Top-10 回吐率 0.4%~28.5%，MAE 極小），推論 30% 移動停利不會碰到它們。

**實跑 0.30/35：Net 1,026,800（-59%），Top-10 存活率 1/10，
27 筆 TimeStop 贏家被攔截 24 筆（-2,787,600）。**

根因：MFE 只記錄終點回吐率，**看不見中途回撤後再創新高的路徑**。
2026-06-06 那筆終點回吐 0.4%，實際中途曾從 209 點峰值深度回撤。

### 3.2 統計檢定用錯方法 → 用戶質疑後修正

初判「+144,800 = 0.104 sigma = 雜訊」，用的是非配對檢定。
兩版本跑同一批進場，是 **paired data**，正確標準誤 995,352（非 1,386,494）。

### 3.3 範圍質疑 → 逼出完整曲面

用戶質疑「是不是合理的最佳化範圍」。補跑完整 42 組窮舉後：
- 曲面平滑、雙軸單調遞增，跨度 362,000 ~ 2,632,800（7.3 倍）→ **機制真實，非雜訊**
- Sanity anchor 1.2/90 = 2,518,400 如預測收斂回基準 → **程式接線正確**
